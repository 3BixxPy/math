Exact Values — the 30-60-90 and 45-45-90 Triangles

The unit circle tells you what cosine and sine mean. This chapter tells you their exact values at the angles that show up constantly — no calculator, no decimals, just clean fractions and radicals you can carry into an identity or an equation.

Why this matters

A decimal approximation like sin(30°) ≈ 0.5 hides the fact that it's exactly \(1/2\) — and "exactly \(1/2\)" is what lets you solve equations, prove identities, and simplify expressions cleanly later in this module. Two right triangles, both provable with the Pythagorean theorem you already know from Module 0, generate every exact value you'll need.

The two reference triangles

45-45-90 triangle (an isosceles right triangle): legs 1 and 1, hypotenuse \(\sqrt{1^2+1^2}=\sqrt{2}\). Both non-right angles are 45°, and by SOH-CAH-TOA (Chapter 5 formalizes this, but the ratio idea is intuitive now):

\[ \sin 45^\circ = \cos 45^\circ = \frac{1}{\sqrt2} = \frac{\sqrt2}{2} \]
(2.3.1)

30-60-90 triangle: sides 1, \(\sqrt3\), and hypotenuse 2 (drop an altitude in an equilateral triangle of side 2 and this is exactly the half you get — the short leg 1 is half the equilateral's side, and \(\sqrt{2^2-1^2}=\sqrt3\) is the altitude). Reading off the 30° and 60° angles:

\[ \sin 30^\circ = \frac12,\ \cos 30^\circ = \frac{\sqrt3}{2}, \qquad \sin 60^\circ = \frac{\sqrt3}{2},\ \cos 60^\circ = \frac12 \]
(2.3.2)

Notice 30° and 60° swap sine and cosine with each other — that's not a coincidence either; they're complementary angles (add to 90°), and a triangle's two non-right angles always share their opposite/adjacent legs in swapped roles.

Definition — Reference angle

The reference angle of \(\theta\) is the acute angle (always between 0° and 90°) formed between \(\theta\)'s terminal side and the x-axis. Every angle, in any quadrant, has a reference angle among \(\{30°, 45°, 60°, 0°, 90°\}\) for the "nice" angles this module uses — and \(\sin\theta\), \(\cos\theta\) always have the same magnitude as the sine/cosine of that reference angle. Only the sign can differ, and the sign is decided entirely by which quadrant \(\theta\) lands in.

Rule — Quadrant signs ("All Students Take Calculus")

Going counterclockwise from quadrant I: All (QI: sin, cos, tan all positive) → Sine (QII: only sin positive) → Tangent (QIII: only tan positive) → Cosine (QIV: only cos positive). Since \(\sin\theta\) is a y-coordinate and \(\cos\theta\) an x-coordinate on the unit circle (Chapter 2), this is really just "which coordinates are positive in each quadrant" restated as a mnemonic.

Worked example

Find sin(120°) exactly.

Step 1 — find the reference angle

120° is in quadrant II, \(180°-120°=60°\) from the negative x-axis... more directly: the reference angle is the acute angle to the nearest x-axis, which is \(180°-120°=60°\).

Step 2 — look up the reference angle's value (magnitude only)

\(\sin 60° = \sqrt3/2\) (equation 2.3.2) — so \(\sin 120°\) has magnitude \(\sqrt3/2\).

Step 3 — fix the sign using the quadrant

120° is in QII, where sine is positive ("All Students"). So the sign stays positive.

Result

\(\sin 120° = \dfrac{\sqrt3}{2}\)

Worked example — a quadrant III case

Find cos(225°) exactly.

Step 1 — reference angle

225° is in quadrant III; \(225°-180°=45°\) from the negative x-axis, so the reference angle is 45°.

Step 2 — magnitude from the reference angle

\(\cos 45° = \sqrt2/2\) (equation 2.3.1).

Step 3 — sign from the quadrant

225° is in QIII, where only tangent is positive ("Take Calculus" hasn't happened yet) — cosine is negative there.

Result

\(\cos 225° = -\dfrac{\sqrt2}{2}\)

Common mistake

Getting the reference-angle magnitude exactly right, then forgetting to check the sign — or worse, assuming everything is positive because "the triangle's sides are all positive lengths." The triangle only ever tells you the magnitude. The sign is a separate step that depends entirely on the quadrant, and it's easy to skip when you're confident about the arithmetic. Always do both steps, every time: magnitude from the reference angle, sign from the quadrant.

Practice

  1. Find cos(30°) exactly.
    \(\sqrt3/2\)
  2. Find sin(45°) exactly.
    \(\sqrt2/2\)
  3. Find the reference angle of 150°, then use it to find sin(150°).
    Reference angle 30°; QII sine is positive: \(\sin150°=1/2\)
  4. Find cos(300°) exactly.
    Reference angle 60°, QIV cosine positive: \(1/2\)
  5. Find sin(315°) exactly.
    Reference angle 45°, QIV sine negative: \(-\sqrt2/2\)
  6. Find cos(150°) exactly.
    Reference angle 30°, QII cosine negative: \(-\sqrt3/2\)
  7. bonus — Find sin(240°) exactly.
    Reference angle 60°, QIII sine negative: \(-\sqrt3/2\)
  8. bonus — Find cos(-60°) exactly. (Negative angle — measured clockwise, Chapter 1.)
    \(-60°\) lands in the same place as \(300°\) (QIV), reference angle 60°, cosine positive: \(1/2\)
  9. bonus — Which two quadrants give cos θ the same sign?
    QI and QIV — both positive (from "All Students Take Calculus": A has all positive, C is cosine's quadrant).
  10. bonus — Find sin(135°) and cos(135°) exactly.
    Reference angle 45°, QII: sine positive, cosine negative. \(\sin135°=\sqrt2/2\), \(\cos135°=-\sqrt2/2\)
  11. challenge — Without computing sign, explain why sin(150°) = sin(30°) exactly (not just approximately), using the unit circle picture from Chapter 2.
    150° and 30° are mirror images across the y-axis on the unit circle — same y-coordinate (height above the x-axis), opposite x-coordinates. Since \(\sin\theta\) is the y-coordinate (Chapter 2), reflecting across the y-axis leaves it unchanged, which is exactly what "same reference angle, same quadrant sign for sine in QI/QII" means geometrically.
