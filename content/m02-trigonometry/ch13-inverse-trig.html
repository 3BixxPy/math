Chapter 13 · concept:inverse-trig-functions

Inverse Trig Functions

Chapters 11–12 solved "given a value, find the angle(s)" using exact values you could recognize by eye. Inverse trig functions are what you reach for when you need a name for that "find the angle" operation itself — and Module 1 already told you the one catch that comes with it.

Why this matters

Module 1 defined an inverse function as the "undo" of a function (Chapter 1.11, concept:inverse-functions) — and immediately flagged a catch: a function only has a true inverse where it's one-to-one, checked with the horizontal line test. Sine, cosine, and tangent all fail that test badly over their full domains (they repeat forever), so before they can be inverted, their domains have to be artificially restricted to one "clean" piece. That restriction is the entire content of this chapter.

Definition — arcsin, arccos, arctan

Restrict each function to the interval where it's one-to-one (passes the horizontal line test), then invert on that restricted piece:

  • arcsin x (also written sin⁻¹x): inverse of sin, restricted to \([-\pi/2,\ \pi/2]\). Range: \([-\pi/2,\pi/2]\).
  • arccos x (cos⁻¹x): inverse of cos, restricted to \([0,\ \pi]\). Range: \([0,\pi]\).
  • arctan x (tan⁻¹x): inverse of tan, restricted to \((-\pi/2,\ \pi/2)\). Range: \((-\pi/2,\pi/2)\).

Just like Module 1's \(f^{-1}\), the -1 here is notation, not an exponent — \(\sin^{-1}x \ne 1/\sin x\).

Rule — Cancellation identities
\[ \sin(\arcsin x) = x, \qquad \cos(\arccos x) = x, \qquad \tan(\arctan x) = x \]
(2.13.1)

These hold for every \(x\) in the corresponding domain, directly from the "undo" definition of an inverse (Module 1, equation 1.11.1). The reverse-order versions — arcsin(sin θ) = θ, etc. — are not unconditional the same way; they only return \(\theta\) itself when \(\theta\) already lies inside the restricted range. Otherwise they return the equivalent angle that does lie in range — see the mistake below.

Worked example

Evaluate arcsin(1/2), arccos(-√2/2), and arctan(1).

Step 1 — arcsin(1/2): which angle in [-π/2, π/2] has sine 1/2?

\(\sin(\pi/6)=1/2\), and \(\pi/6\) is inside \([-\pi/2,\pi/2]\). \(\arcsin(1/2)=\pi/6\).

Step 2 — arccos(-√2/2): which angle in [0, π] has cosine -√2/2?

Reference angle 45° (\(\pi/4\)); cosine is negative in QII, and \(3\pi/4\) is inside \([0,\pi]\). \(\arccos(-\sqrt2/2)=3\pi/4\).

Step 3 — arctan(1): which angle in (-π/2, π/2) has tangent 1?

\(\tan(\pi/4)=1\), and \(\pi/4\) is inside \((-\pi/2,\pi/2)\). \(\arctan(1)=\pi/4\).

Worked example — the reverse-order trap, worked correctly

Evaluate arcsin(sin(5π/6)). (Careful: this is not automatically 5π/6.)

Step 1 — first find the inner value

\(\sin(5\pi/6) = 1/2\) (reference angle \(\pi/6\), QII).

Step 2 — now apply arcsin to that number

\(\arcsin(1/2)\) asks: which angle in \([-\pi/2,\pi/2]\) has sine \(1/2\)? Not \(5\pi/6\) — that's outside the restricted range entirely.

Result

\(\arcsin(\sin(5\pi/6)) = \pi/6\) — the equivalent angle that is inside arcsin's range, not the original \(5\pi/6\) you started with.

Common mistake

Giving an answer outside the function's restricted range — for instance, saying arcsin(1/2) = 5π/6 because \(\sin(5\pi/6)=1/2\) too. That's a true statement about sine, but arcsin is defined to return only the one angle inside its restricted range (\([-\pi/2,\pi/2]\) for arcsin), and \(5\pi/6\) isn't in it — the correct answer is \(\pi/6\). Whenever multiple angles share the same sine/cosine/tangent value, the inverse function's job is to pick the one that lives in the restricted range, never any of the others, no matter how "natural" they look.

Try it yourself

Evaluate arctan(1).

Practice

  1. Evaluate arcsin(√2/2).
    \(\pi/4\)
  2. Evaluate arccos(1/2).
    \(\pi/3\)
  3. Evaluate arctan(√3).
    \(\pi/3\)
  4. Evaluate arcsin(-1/2). (Careful with the sign and the restricted range.)
    \(-\pi/6\) — arcsin's range includes negative angles, unlike arccos's.
  5. Evaluate arccos(0).
    \(\pi/2\)
  6. State the range of arccos x, and explain why it's different from arcsin's range.
    \([0,\pi]\) — different because cosine isn't one-to-one on \([-\pi/2,\pi/2]\) (it repeats values there), so a different restricted interval had to be chosen for cosine specifically.
  7. bonus — Evaluate arccos(-1).
    \(\pi\)
  8. bonus — Evaluate arctan(0).
    \(0\)
  9. bonus — Evaluate cos(arccos(0.7)) without finding the angle numerically.
    \(0.7\) directly, by the cancellation identity (equation 2.13.1) — no need to ever find the actual angle.
  10. bonus — Evaluate arccos(cos(5π/3)). (Same trap as the worked example — don't assume it's 5π/3.)
    \(\cos(5\pi/3)=1/2\); \(\arccos(1/2)=\pi/3\), which is inside \([0,\pi]\) — that's the answer, not \(5\pi/3\).
  11. bonus — Why is arctan's domain all real numbers, unlike arcsin and arccos, which are restricted to [-1, 1]?
    tan θ is unbounded (Chapter 8) — it takes every real value somewhere in its restricted piece, so its inverse's domain is all of ℝ. sin/cos are bounded to [-1,1] (Chapter 2, equation 2.2.2), so their inverses can only accept inputs in that range.
  12. challenge — Evaluate sin(arccos(3/5)) without ever finding the angle numerically. (Hint: arccos(3/5) is some angle θ in [0, π] with cos θ = 3/5 — use Chapter 9's identity to find sin θ directly.)
    Let \(\theta=\arccos(3/5)\), so \(\cos\theta=3/5\) with \(\theta\in[0,\pi]\), meaning \(\sin\theta\ge0\) throughout that range. By the Pythagorean identity, \(\sin^2\theta=1-9/25=16/25\), and since sin θ ≥ 0 here, \(\sin\theta=4/5\). So \(\sin(\arccos(3/5))=4/5\) — found entirely algebraically, no angle needed.
