Solving Basic Trig Equations

Everything from Chapters 2–4 (exact values, the unit circle, reference angles) was building toward this: actually solving an equation with a trig function in it, instead of just evaluating one at a given angle.

Why this matters

A trig equation like sin θ = 1/2 is really asking "which angles land on this y-coordinate?" — and because the unit circle is a closed loop, the honest answer is usually more than one angle, not just one. This chapter restricts to one trip around the circle ([0, 2π)) to keep the answer set finite and manageable; Chapter 12 removes that restriction.

Method — Solving on a restricted interval
  1. Isolate the trig function on one side (basic algebra).
  2. Find the reference angle whose function value has that magnitude (Chapter 3's exact values, run in reverse).
  3. Use the equation's sign to determine which quadrant(s) the actual solutions are in.
  4. Write down every solution in the given interval — don't stop at the first one you find.
Worked example

Solve 2cos θ − 1 = 0 on [0, 2π).

Step 1 — isolate cos θ

\(2\cos\theta=1 \Rightarrow \cos\theta = \dfrac12\)

Step 2 — reference angle

\(\cos(\pi/3) = 1/2\) (Chapter 3), so the reference angle is \(\pi/3\).

Step 3 — which quadrants? cosine is positive here, so QI and QIV

QI solution: the reference angle itself, \(\theta=\pi/3\). QIV solution: \(2\pi-\pi/3=5\pi/3\).

Result

\(\theta = \dfrac{\pi}{3}\) or \(\theta=\dfrac{5\pi}{3}\)

Worked example — a negative value

Solve sin θ = −√2/2 on [0, 2π).

Step 1 — already isolated

\(\sin\theta = -\sqrt2/2\)

Step 2 — reference angle

\(\sin(\pi/4)=\sqrt2/2\), so the reference angle is \(\pi/4\).

Step 3 — which quadrants? sine is negative, so QIII and QIV

QIII: \(\pi+\pi/4=5\pi/4\). QIV: \(2\pi-\pi/4=7\pi/4\).

Result

\(\theta = \dfrac{5\pi}{4}\) or \(\theta=\dfrac{7\pi}{4}\)

Common mistake

Finding one solution, sanity-checking it, and stopping — missing that the interval usually contains a second solution in a different quadrant. Because sine and cosine each take every value in [-1,1] (other than exactly 1 or -1) at two different angles per revolution, a typical equation like sin θ = k has two answers on [0, 2π), not one. Always run the "which quadrants" step (step 3 above) explicitly and check both.

The exception worth knowing: at the very peak or trough — sin θ = 1, sin θ = -1, cos θ = 1, or cos θ = -1 — there's genuinely only one solution per revolution, because the unit circle only touches that extreme y- or x-value at a single point. Don't force a second solution to exist where the geometry says there isn't one.

Try it yourself

Solve sin θ = 1 on [0, 2π). (How many solutions does this one actually have?)

Practice

  1. Solve sin θ = 1/2 on [0, 2π).
    \(\theta=\pi/6\) or \(5\pi/6\)
  2. Solve cos θ = −1/2 on [0, 2π).
    \(\theta=2\pi/3\) or \(4\pi/3\)
  3. Solve 2sin θ + √3 = 0 on [0, 2π).
    \(\sin\theta=-\sqrt3/2 \Rightarrow \theta=4\pi/3\) or \(5\pi/3\)
  4. Solve cos θ = 1 on [0, 2π). How many solutions?
    Only one: \(\theta=0\) — the "single-solution" exception, cosine's peak value.
  5. Solve √2 cos θ − 1 = 0 on [0, 2π).
    \(\cos\theta=1/\sqrt2=\sqrt2/2 \Rightarrow \theta=\pi/4\) or \(7\pi/4\)
  6. Solve tan θ = 1 on [0, 2π). (Careful — tan's period is π, not 2π, so check both "expected" quadrants.)
    \(\theta=\pi/4\) or \(5\pi/4\) (QI and QIII, where tan is positive)
  7. bonus — Solve sin θ = −1 on [0, 2π).
    Only one solution: \(\theta=3\pi/2\)
  8. bonus — Solve 2cos θ + √2 = 0 on [0, 2π).
    \(\cos\theta=-\sqrt2/2 \Rightarrow \theta=3\pi/4\) or \(5\pi/4\)
  9. bonus — Solve sin θ = 0 on [0, 2π). How many solutions, and why does this case also break the usual "two solutions" pattern?
    \(\theta=0\) and \(\pi\) — two solutions, but they're not mirror images in the usual sense; \(\sin\theta=0\) happens exactly where the terminal side crosses the x-axis, which happens twice per revolution (not at an extreme value, so the normal two-solution rule still applies here).
  10. bonus — Solve tan θ = −1 on [0, 2π).
    \(\theta=3\pi/4\) or \(7\pi/4\) (QII and QIV, where tan is negative)
  11. challenge — Solve sec θ = 2 on [0, 2π). (Hint: rewrite in terms of cos θ first, using Chapter 4.)
    \(\sec\theta=2 \Rightarrow \cos\theta=1/2 \Rightarrow \theta=\pi/3\) or \(5\pi/3\)
