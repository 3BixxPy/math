The Rank-Nullity Theorem

Chapter 10 introduced rank and null space as two separate numbers attached to a matrix. This chapter reveals they were never independent at all — one determines the other, given only the matrix's number of columns.

Why this matters

This is the theorem that finally explains, in one clean equation, exactly why Module 10's three solution-type cases for a linear system — unique solution, no solution, infinitely many solutions — show up in the pattern they do. It isn't a coincidence tied to specific numbers; it's this identity, every single time.

Definition — Nullity

The nullity of a matrix \(A\) is \(\operatorname{nullity}(A)=\dim(\operatorname{Null}(A))\) — the dimension of its null space (Chapter 10).

Theorem — Rank-nullity
\[ \operatorname{rank}(A)+\operatorname{nullity}(A)=n \]
(11.11.1)

For an \(m\times n\) matrix \(A\), where \(n\) is the number of columns — the dimension of the space \(A\) maps from. Worked example — predicting nullity, then verifying it directly

A 2×5 matrix has rank 2 (found via RREF, Module 10). Use the theorem to find its nullity, then verify with a concrete matrix.

Step 1 — apply the theorem directly

\(n=5\) (columns), \(\operatorname{rank}(A)=2\), so \(\operatorname{nullity}(A)=n-\operatorname{rank}(A)=5-2=3\) — no elimination needed for this step.

Step 2 — verify directly with a concrete matrix

Take \(A=\begin{bmatrix}1&0&1&0&1\\0&1&-1&1&0\end{bmatrix}\) — already in a row-reduced form with rank 2 (pivots in columns 1 and 2). Solve \(A\mathbf x=\mathbf 0\): \(x_1+x_3+x_5=0\) and \(x_2-x_3+x_4=0\).

Step 3 — count the free variables

\(x_3,x_4,x_5\) are free (three of them); \(x_1=-x_3-x_5\) and \(x_2=x_3-x_4\) are determined by them. Three free variables means \(\dim(\operatorname{Null}(A))=3\) — matching the theorem's prediction exactly, with no separate elimination-counting surprise.

Common mistake

Forgetting that \(n\) in the formula is the number of columns, not rows — a genuinely easy index to swap under time pressure. For a 5×2 matrix (5 rows, 2 columns) with rank 2, the nullity is \(n-\operatorname{rank}=2-2=0\), not \(5-2=3\) — mixing up which dimension "\(n\)" refers to gives a completely different, wrong answer. Anchor it the same way Module 10 anchors matrix dimensions: \(n\) is always the number of unknowns in \(A\mathbf x=\mathbf 0\), i.e. how many columns \(A\) has, regardless of how many rows (equations) there are.

Practice

  1. A 4×4 matrix has rank 4. Find its nullity.
    \(4-4=0\).
  2. A 3×6 matrix has rank 3. Find its nullity.
    \(6-3=3\).
  3. A 5×2 matrix has rank 2. Find its nullity.
    \(2-2=0\) (\(n=2\), the number of columns).
  4. A 4×4 matrix has nullity 0. What does that tell you about solutions to \(A\mathbf x=\mathbf 0\), and about whether \(A\) is invertible?
    Only the trivial solution to \(A\mathbf x=\mathbf 0\) (since \(\operatorname{rank}=n-0=4\), full rank) — and \(A\) is invertible.
  5. A 3×3 matrix has nullity 1. Find its rank.
    \(\operatorname{rank}=n-\operatorname{nullity}=3-1=2\).
  6. A homogeneous system in 4 unknowns has 2 free variables in its RREF. Find the coefficient matrix's rank and nullity.
    Nullity \(=2\) (the number of free variables, directly); rank \(=n-\operatorname{nullity}=4-2=2\).
  7. bonus — A 2×4 matrix has rank 2 (full row rank). Find its nullity.
    \(4-2=2\).
  8. bonus — True or false: rank-nullity guarantees a matrix's rank can never exceed its number of columns.
    True — since \(\operatorname{nullity}\geq0\) always, \(\operatorname{rank}=n-\operatorname{nullity}\leq n\).
  9. bonus — A 6×3 matrix has all 3 columns independent (rank 3). Find its nullity, and state what that means about solutions to \(A\mathbf x=\mathbf 0\).
    Nullity \(=3-3=0\), so \(A\mathbf x=\mathbf 0\) has only the trivial solution — matching Chapter 10's link between independent columns and a trivial null space.
  10. bonus — A 3×5 matrix's null space is spanned by exactly 2 vectors. Find its rank without any elimination.
    Nullity \(=2\), \(n=5\), so \(\operatorname{rank}=5-2=3\).
  11. challenge — A student row-reduces a 4×7 matrix and counts 3 pivot columns. Using rank-nullity alone (not elimination), find both the rank and nullity, and explain why you can be certain of the nullity's value without separately solving for and counting free variables.
    Rank equals the number of pivot columns: \(\operatorname{rank}=3\) (a Module 10 fact). Nullity \(=n-\operatorname{rank}=7-3=4\). Certainty follows directly from the theorem itself: nullity is defined as \(n\) minus rank once rank is known, so no separate count of free variables is needed for the number to be correct — though Chapter 10's worked example shows you'd get the identical count if you did solve for them explicitly.
