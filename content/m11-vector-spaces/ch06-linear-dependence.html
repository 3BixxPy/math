Chapter 6 · concept:linear-dependence

Linear Dependence

Chapter 5 defined independence in terms of the homogeneous system having only the trivial solution. This chapter restates dependence from the other direction — as an actual formula for one vector in terms of the rest — because both framings get used constantly, in different situations.

Why this matters

Knowing a set is dependent is only half useful until you know which vector is redundant and how to write it in terms of the others — that's often the more practically important fact, especially when you want to trim a spanning set down to something more efficient (Chapter 7's job).

Theorem — Dependence as a combination
\[ \{\mathbf v_1,\ldots,\mathbf v_k\}\text{ is linearly dependent} \iff \text{some } \mathbf v_i \text{ is a linear combination of the others} \]
(11.6.1)

This is the direct flip side of Chapter 5's definition, restated as its own explicit equivalence. Geometrically: in \(\mathbb R^2\), two dependent vectors are parallel — they lie on the same line through the origin. In \(\mathbb R^3\), three dependent vectors lie in a common plane through the origin.

Worked example — finding the redundant vector

The set \(\{\langle1,1\rangle,\langle2,2\rangle,\langle1,0\rangle\}\) is dependent (three vectors is more than the 2 needed to span \(\mathbb R^2\) — Chapter 8 makes this precise). Write one vector explicitly as a combination of the others.

Step 1 — notice the shortcut first

\(\langle2,2\rangle=2\langle1,1\rangle\) already, using only the first two vectors. Only two of the three even need to be related for the whole set to count as dependent — the third vector, \(\langle1,0\rangle\), doesn't have to be involved at all.

Step 2 — write the explicit combination

\(\langle2,2\rangle=2\langle1,1\rangle+0\langle1,0\rangle\) — a genuine linear combination of the other two, confirming \(\langle2,2\rangle\) is the redundant one here (though it's not the only vector you could have singled out).

Common mistake

Assuming a set is independent just because no two vectors are obviously parallel. That check alone isn't enough once you have three or more vectors: dependence can come from a combination of three or more vectors, with no single pair being multiples of each other. For instance, \(\langle1,0\rangle\), \(\langle0,1\rangle\), and \(\langle1,1\rangle\) — no two of these are parallel — yet \(\langle1,1\rangle=1\langle1,0\rangle+1\langle0,1\rangle\), so the set is dependent anyway. Pairwise-parallel-checking is a useful quick scan, never a substitute for Chapter 5's actual homogeneous-system test.

Try it yourself

If \(\mathbf v_3=2\mathbf v_1+\mathbf v_2\), is \(\{\mathbf v_1,\mathbf v_2,\mathbf v_3\}\) linearly independent?

Practice

  1. Is \(\{\langle1,2\rangle,\langle2,4\rangle\}\) dependent? If so, write one as a combination of the other.
    Yes — \(\langle2,4\rangle=2\langle1,2\rangle\).
  2. Is \(\{\langle1,0\rangle,\langle0,1\rangle,\langle3,5\rangle\}\) dependent?
    Yes — \(\langle3,5\rangle=3\langle1,0\rangle+5\langle0,1\rangle\).
  3. Three vectors in \(\mathbb R^3\) are dependent. What does that say about their geometric arrangement?
    They're coplanar — they all lie in a common plane through the origin.
  4. Is \(\{\langle1,0\rangle,\langle0,1\rangle,\langle1,1\rangle\}\) dependent? If so, express one vector as a combination of the other two.
    Yes — \(\langle1,1\rangle=1\langle1,0\rangle+1\langle0,1\rangle\).
  5. Two vectors in \(\mathbb R^2\) are dependent. What must be true of them geometrically?
    They're parallel — one is a scalar multiple of the other, both lying on the same line through the origin.
  6. Given \(\mathbf v_1=\langle1,1,1\rangle\), \(\mathbf v_2=\langle2,2,2\rangle\), \(\mathbf v_3=\langle0,1,0\rangle\), is \(\{\mathbf v_1,\mathbf v_2,\mathbf v_3\}\) dependent? Show the redundant relationship.
    Yes — \(\mathbf v_2=2\mathbf v_1\), which alone is enough to make the full three-vector set dependent; \(\mathbf v_3\) doesn't need to be involved at all.
  7. bonus — True or false: if no vector in a set is a scalar multiple of any single other vector, the set is automatically independent.
    False — this chapter's whole point. Dependence can come from a joint combination of three or more vectors, as in \(\{\langle1,0\rangle,\langle0,1\rangle,\langle1,1\rangle\}\), where no pair is parallel yet the set is still dependent.
  8. bonus — Can a set containing a single vector \(\{\langle1,2,3\rangle\}\) ever be linearly dependent?
    Only if that vector is the zero vector; a single nonzero vector is always independent (Chapter 5's challenge problem).
  9. bonus — If \(\{\mathbf v_1,\mathbf v_2\}\) is independent, and \(\mathbf v_3=\mathbf v_1+\mathbf v_2\), can \(\{\mathbf v_1,\mathbf v_2,\mathbf v_3\}\) still be independent?
    No — \(\mathbf v_3\) is by construction a linear combination of \(\mathbf v_1,\mathbf v_2\), so by this chapter's theorem the enlarged set is automatically dependent, regardless of what \(\mathbf v_1,\mathbf v_2\) were.
  10. bonus — Are the two rows of \(\begin{bmatrix}2&4\\1&2\end{bmatrix}\), viewed as vectors \(\langle2,4\rangle\) and \(\langle1,2\rangle\), dependent? What might that suggest about the matrix itself?
    Yes, dependent (\(\langle2,4\rangle=2\langle1,2\rangle\)) — this foreshadows Chapter 10: a matrix whose rows are dependent will turn out to be "rank-deficient," not full rank.
  11. challenge — Prove the theorem's "if" direction directly: show that if some \(\mathbf v_i\) equals a linear combination of the others, the whole set must be dependent by Chapter 5's definition (produce an explicit nontrivial combination summing to \(\mathbf 0\)).
    Suppose \(\mathbf v_i=\sum_{j\neq i}c_j\mathbf v_j\). Moving \(\mathbf v_i\) to the other side: \(\left(\sum_{j\neq i}c_j\mathbf v_j\right)-\mathbf v_i=\mathbf 0\). This is a linear combination of all the vectors in the set, with the coefficient on \(\mathbf v_i\) equal to \(-1\) — nonzero. A nontrivial solution to \(c_1\mathbf v_1+\cdots+c_k\mathbf v_k=\mathbf 0\) exists, so by Chapter 5's definition the set is dependent.
