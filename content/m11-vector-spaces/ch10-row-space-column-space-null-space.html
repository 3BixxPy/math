Row Space, Column Space & Null Space

Modules 9 and 10 mostly treated matrices as machines for solving systems, or (Chapter 1 here) as vectors in their own right. This chapter shows that every matrix quietly carries three subspaces around with it at all times — each one built from ideas already in this module.

Why this matters

Row space, column space, and null space aren't new inventions — they're just span (Chapter 4) and linear independence (Chapter 5) applied directly to a matrix's rows or columns, plus one direct callback to Module 10's homogeneous systems. Once you see a matrix this way, questions like "how many genuinely independent equations does this system have" and "is this coefficient matrix invertible" both become plain dimension questions.

Definition — Row space, column space, null space

For an \(m\times n\) matrix \(A\):

Row space, \(\operatorname{Row}(A)\): the span of \(A\)'s rows — a subspace of \(\mathbb R^n\).

Column space, \(\operatorname{Col}(A)\): the span of \(A\)'s columns — a subspace of \(\mathbb R^m\).

Null space, \(\operatorname{Null}(A)\): the set of all solutions to \(A\mathbf x=\mathbf 0\) — a direct callback to Module 10's homogeneous systems. Notice: asking whether \(\operatorname{Null}(A)\) contains only the zero vector is exactly Chapter 5's independence test, applied to \(A\)'s columns — a null space bigger than just \(\{\mathbf 0\}\) means \(A\)'s columns are dependent.

Each of these three is a genuine subspace in its own right (a span always is, Chapter 4; the null space passes Chapter 2's test directly — it contains \(\mathbf 0\) since \(A\mathbf 0=\mathbf 0\) always, and is closed under addition and scalar multiplication since \(A(\mathbf x+\mathbf y)=A\mathbf x+A\mathbf y\) and \(A(c\mathbf x)=cA\mathbf x\)).

Definition — Rank

The rank of \(A\) is \(\operatorname{rank}(A)=\dim(\operatorname{Row}(A))\). Stated here as a fact, not proven: this always equals \(\dim(\operatorname{Col}(A))\) too — the row space and column space of the same matrix always have the same dimension, even though they generally live in different-sized spaces (\(\mathbb R^n\) versus \(\mathbb R^m\)).

Worked example — finding a null space and a rank

For \(A=\begin{bmatrix}1&2\\2&4\end{bmatrix}\), find \(\operatorname{Null}(A)\) and \(\operatorname{rank}(A)\).

Step 1 — set up Ax = 0

\(x_1+2x_2=0\), \(2x_1+4x_2=0\). The second equation is exactly twice the first — Gaussian elimination (Module 10) collapses it to a single independent equation.

Step 2 — solve, with a free variable

From \(x_1+2x_2=0\): \(x_1=-2x_2\). Let \(x_2=t\) (free); then \(x_1=-2t\). Every solution has the form \(\langle-2t,t\rangle=t\langle-2,1\rangle\).

Step 3 — express as a span

\(\operatorname{Null}(A)=\operatorname{span}\{\langle-2,1\rangle\}\) — a line, not just the single point \(\langle0,0\rangle\); \(\dim(\operatorname{Null}(A))=1\).

Step 4 — rank, from the rows

\(A\)'s rows are \(\langle1,2\rangle\) and \(\langle2,4\rangle\) — dependent (the second is twice the first), so \(\operatorname{Row}(A)\) is spanned by just one independent direction: \(\dim(\operatorname{Row}(A))=1\), so \(\operatorname{rank}(A)=1\).

Common mistake

Confusing the null space with the zero vector itself. \(\operatorname{Null}(A)\) is the set of input vectors \(\mathbf x\) that \(A\) sends to the output \(\mathbf 0\) — as the worked example just showed, it's typically an entire subspace (here, a whole line of inputs), not just one point, unless the null space happens to be trivial (\(\{\mathbf 0\}\) only). "The null space contains the zero vector" and "the null space is the zero vector" are very different claims — the first is always true, the second is only sometimes true.

Practice

  1. Find \(\operatorname{Null}(A)\) for \(A=\begin{bmatrix}1&0\\0&0\end{bmatrix}\).
    \(x_1=0\), \(x_2\) free → \(\operatorname{Null}(A)=\operatorname{span}\{\langle0,1\rangle\}\) (the \(y\)-axis).
  2. Find \(\operatorname{Row}(A)\) for \(A=\begin{bmatrix}1&2\\3&4\end{bmatrix}\) — are the rows independent?
    \(\langle1,2\rangle\) and \(\langle3,4\rangle\) are independent (not parallel), so \(\operatorname{Row}(A)=\mathbb R^2\), dimension 2.
  3. Find \(\operatorname{Col}(A)\) for \(A=\begin{bmatrix}1&0\\0&0\end{bmatrix}\).
    Columns are \(\langle1,0\rangle\) and \(\langle0,0\rangle\); the zero column contributes nothing, so \(\operatorname{Col}(A)=\operatorname{span}\{\langle1,0\rangle\}\) (the \(x\)-axis).
  4. What is \(\operatorname{rank}\begin{bmatrix}1&2\\3&4\end{bmatrix}\)?
    2 — full rank, matching problem 2's independent rows.
  5. What is \(\operatorname{rank}\begin{bmatrix}1&0\\0&0\end{bmatrix}\)?
    1 — only one independent row (and one independent column).
  6. If a 2×2 matrix has rank 2, what must its null space be?
    Just \(\{\mathbf 0\}\), the trivial subspace — a full-rank square matrix's columns are independent, so only the zero vector maps to zero. (This is exactly Chapter 11's rank-nullity theorem, previewed.)
  7. bonus — Find \(\operatorname{Null}(A)\) for \(A=\begin{bmatrix}2&4\\1&2\end{bmatrix}\).
    Both rows give the same equation \(x_1+2x_2=0\) → \(\operatorname{Null}(A)=\operatorname{span}\{\langle-2,1\rangle\}\), same as the worked example.
  8. bonus — True or false: the null space of an invertible (square, full-rank) matrix is always just \(\{\mathbf 0\}\).
    True.
  9. bonus — For \(A=\begin{bmatrix}1&1\\1&1\end{bmatrix}\), find \(\operatorname{Row}(A)\), \(\operatorname{rank}(A)\), and \(\operatorname{Null}(A)\).
    Both rows are \(\langle1,1\rangle\): \(\operatorname{Row}(A)=\operatorname{span}\{\langle1,1\rangle\}\), \(\operatorname{rank}(A)=1\). \(\operatorname{Null}(A)\): \(x_1+x_2=0\Rightarrow x_1=-x_2\) → \(\operatorname{span}\{\langle-1,1\rangle\}\).
  10. bonus — Can the column space of a matrix with only 2 rows ever equal all of \(\mathbb R^3\)?
    No — a 2-row matrix's columns are 2-component vectors, so \(\operatorname{Col}(A)\subseteq\mathbb R^2\); it can never reach \(\mathbb R^3\), no matter how many columns the matrix has.
  11. challenge — A 3×3 matrix has two identical rows. Without any further computation, what can you immediately conclude about its rank, and about whether it's invertible?
    Two identical rows means \(\operatorname{Row}(A)\) is spanned by at most 2 independent vectors, so \(\operatorname{rank}(A)\leq2<3\) — not full rank. A square matrix that isn't full rank is not invertible.
