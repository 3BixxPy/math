Chapter 7 · concept:basis

Basis

Chapter 4 asked what a set spans; Chapter 5 asked whether it's independent. This chapter asks for both at once — the single most important combination in the whole module.

Why this matters

A basis is the smallest possible spanning set — no redundant vectors, thanks to independence — and simultaneously the largest possible independent set for that space — nothing missing, thanks to spanning. It's the most efficient way to describe every vector in a space, and it's what makes both "dimension" (Chapter 8) and "coordinates" (Chapter 9) well-defined ideas at all.

Definition — Basis
\[ B=\{\mathbf b_1,\ldots,\mathbf b_n\}\text{ is a basis for }V \iff \begin{cases} B\text{ is linearly independent} \\ \operatorname{span}(B)=V \end{cases} \]
(11.7.1)

Both conditions, always. The obvious default example is the standard basis of \(\mathbb R^n\): for \(\mathbb R^2\), that's \(\langle1,0\rangle,\langle0,1\rangle\); for \(\mathbb R^3\), \(\langle1,0,0\rangle,\langle0,1,0\rangle,\langle0,0,1\rangle\); and so on. It's independent (each vector is nonzero in a coordinate none of the others touch) and it spans (any \(\langle a_1,\ldots,a_n\rangle\) is trivially \(a_1\langle1,0,\ldots\rangle+\cdots\)).

Worked example — a non-standard basis for R²

Verify that \(\langle1,1\rangle\) and \(\langle1,-1\rangle\) form a basis for \(\mathbb R^2\).

Step 1 — check independence

\(c_1\langle1,1\rangle+c_2\langle1,-1\rangle=\langle0,0\rangle \Rightarrow c_1+c_2=0,\ c_1-c_2=0\). Adding: \(2c_1=0\Rightarrow c_1=0\), then \(c_2=0\). Only the trivial solution — independent.

Step 2 — check spanning

For an arbitrary target \(\langle a,b\rangle\): \(c_1+c_2=a\), \(c_1-c_2=b\) gives \(c_1=\frac{a+b}{2}\), \(c_2=\frac{a-b}{2}\) — a solution for every \(a,b\), no exceptions. So \(\operatorname{span}\{\langle1,1\rangle,\langle1,-1\rangle\}=\mathbb R^2\).

Result

Both conditions hold, so \(\{\langle1,1\rangle,\langle1,-1\rangle\}\) is a basis for \(\mathbb R^2\) — a perfectly valid alternative to the standard basis.

Common mistake

Checking only independence, or only spanning, and stopping there — a basis genuinely needs both. \(\{\langle1,0\rangle,\langle0,1\rangle,\langle1,1\rangle\}\) spans \(\mathbb R^2\) but has three vectors, so it must be dependent (indeed \(\langle1,1\rangle=\langle1,0\rangle+\langle0,1\rangle\)) — too large, fails independence. \(\{\langle2,0\rangle\}\) is independent (a single nonzero vector always is) but only spans a line — too small, fails spanning. A spanning set that's too big and an independent set that's too small each fail to be a basis, for two genuinely different reasons.

Try it yourself

Assuming they're chosen well (independent and spanning), does a basis for \(\mathbb R^2\) need exactly 2 vectors?

Practice

  1. Is \(\{\langle1,0\rangle,\langle0,1\rangle\}\) a basis for \(\mathbb R^2\)?
    Yes — the standard basis: clearly independent, and \(\langle a,b\rangle=a\langle1,0\rangle+b\langle0,1\rangle\) always, so it spans.
  2. Is \(\{\langle1,0\rangle,\langle0,1\rangle,\langle1,1\rangle\}\) a basis for \(\mathbb R^2\)?
    No — it spans \(\mathbb R^2\), but three vectors in a 2-dimensional setting must be dependent; fails independence.
  3. Is \(\{\langle2,0\rangle\}\) a basis for \(\mathbb R^2\)?
    No — independent, but only spans the \(x\)-axis, not all of \(\mathbb R^2\); fails spanning.
  4. Is \(\{\langle1,1\rangle,\langle2,2\rangle\}\) a basis for \(\mathbb R^2\)?
    No — dependent (parallel vectors), and consequently only spans a line rather than all of \(\mathbb R^2\).
  5. Is \(\{\langle1,0,0\rangle,\langle0,1,0\rangle,\langle0,0,1\rangle\}\) a basis for \(\mathbb R^3\)?
    Yes — the standard basis for \(\mathbb R^3\).
  6. Verify whether \(\{\langle1,1,0\rangle,\langle0,1,1\rangle,\langle1,0,1\rangle\}\) is a basis for \(\mathbb R^3\) (test independence with the homogeneous system).
    Matching coordinates gives \(c_1+c_3=0\), \(c_1+c_2=0\), \(c_2+c_3=0\). From the first two, \(c_3=-c_1\) and \(c_2=-c_1\); substituting both into the third, \((-c_1)+(-c_1)=-2c_1=0\Rightarrow c_1=0\), so \(c_2=c_3=0\) too — only the trivial solution, independent. Three independent vectors in \(\mathbb R^3\) automatically span it too (Chapter 8), so yes, a basis.
  7. bonus — Can a basis for \(\mathbb R^2\) ever have only 1 vector?
    No — one vector can span at most a line, never all of \(\mathbb R^2\).
  8. bonus — Can a basis for \(\mathbb R^2\) ever have 3 or more vectors?
    No — any 3 vectors in \(\mathbb R^2\) are automatically dependent, so they can never be independent, which disqualifies them regardless of spanning.
  9. bonus — True or false: every vector space has exactly one basis.
    False — typically infinitely many valid bases exist (e.g. both \(\{\langle1,0\rangle,\langle0,1\rangle\}\) and \(\{\langle1,1\rangle,\langle1,-1\rangle\}\) are bases for \(\mathbb R^2\)). What's fixed is only the number of vectors a basis needs — Chapter 8's dimension.
  10. bonus — Is \(\{\langle1,0\rangle,\langle2,0\rangle\}\) a basis for \(\mathbb R^2\)?
    No — dependent (parallel), so it spans only the \(x\)-axis.
  11. challenge — A friend claims that since \(\{\langle1,0\rangle,\langle0,1\rangle,\langle0,0\rangle\}\) spans \(\mathbb R^2\) (the zero vector contributes nothing new, but doesn't hurt spanning either), it must be a basis. Explain the flaw.
    Including the zero vector always breaks independence (Chapter 5's practice: a set containing \(\mathbf 0\) is never independent, since a nonzero coefficient on \(\mathbf 0\) and zero elsewhere gives a nontrivial combination summing to \(\mathbf 0\)). So the set fails condition (1) of the basis definition even though it does satisfy condition (2) — spanning alone was never sufficient on its own; both conditions are required together.
