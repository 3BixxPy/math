Coordinates Relative to a Basis

Chapters 7 and 8 established that a basis is the right "ruler" for a vector space, and that its size — the dimension — doesn't depend on which basis you pick. This chapter asks: for one fixed basis, how do you actually read off a vector's position on that ruler?

Why this matters

The components you're used to writing, like \(\langle3,4\rangle\), are secretly already coordinates relative to one particular basis — the standard one. Relative to any other, equally valid, basis, the exact same geometric vector gets completely different numbers. Recognizing this now avoids a very natural confusion later, once bases besides the standard one start appearing regularly (Module 12's eigenbasis, for one).

Definition — Coordinates relative to a basis

Given a basis \(B=\{\mathbf b_1,\ldots,\mathbf b_n\}\) for a vector space \(V\), every vector \(\mathbf v\in V\) can be written as

\[ \mathbf v=c_1\mathbf b_1+c_2\mathbf b_2+\cdots+c_n\mathbf b_n \]

for a unique choice of scalars \(c_1,\ldots,c_n\). (Uniqueness follows directly from \(B\)'s independence: if two different coefficient lists both worked, subtracting one equation from the other would produce a nontrivial combination of \(B\) summing to \(\mathbf 0\) — impossible for an independent set, by Chapter 5.) The scalars \((c_1,\ldots,c_n)\) are the coordinates of \(\mathbf v\) relative to \(B\), written \([\mathbf v]_B=(c_1,\ldots,c_n)\).

Worked example — coordinates on Chapter 7's non-standard basis

Find the coordinates of \(\langle5,1\rangle\) relative to \(B=\{\langle1,1\rangle,\langle1,-1\rangle\}\).

Step 1 — set up the equation

Want \(c_1\langle1,1\rangle+c_2\langle1,-1\rangle=\langle5,1\rangle \Rightarrow c_1+c_2=5,\ c_1-c_2=1\).

Step 2 — solve

Adding the two equations: \(2c_1=6\Rightarrow c_1=3\), then \(c_2=5-3=2\).

Step 3 — check

\(3\langle1,1\rangle+2\langle1,-1\rangle=\langle3,3\rangle+\langle2,-2\rangle=\langle5,1\rangle\) ✓

Result

\([\langle5,1\rangle]_B=(3,2)\) — genuinely different numbers than the vector's plain components \((5,1)\), even though it's the exact same arrow.

Common mistake

Assuming a vector's "coordinates" are always just its plain components. They're only that simple relative to the standard basis \(\{\langle1,0\rangle,\langle0,1\rangle\}\) — there, \(\langle5,1\rangle=5\langle1,0\rangle+1\langle0,1\rangle\), so its coordinates genuinely are \((5,1)\), matching the components exactly. Relative to any other valid basis, like \(\{\langle1,1\rangle,\langle1,-1\rangle\}\) above, the same vector's coordinates are a completely different pair of numbers, \((3,2)\). "Components" is really just a nickname for "coordinates relative to the standard basis" — a special case, not the general rule.

Try it yourself

True or false: relative to the standard basis, the coordinates of \(\langle3,4\rangle\) are simply its plain components, \((3,4)\).

Practice

  1. Find \([\mathbf v]_B\) for \(\mathbf v=\langle4,2\rangle\), \(B=\{\langle1,0\rangle,\langle0,1\rangle\}\) (standard).
    \((4,2)\) — trivial, since \(B\) is the standard basis.
  2. Find \([\mathbf v]_B\) for \(\mathbf v=\langle7,1\rangle\), \(B=\{\langle1,1\rangle,\langle1,-1\rangle\}\).
    \(c_1+c_2=7\), \(c_1-c_2=1\) → \(c_1=4,\ c_2=3\). \([\mathbf v]_B=(4,3)\).
  3. Find \([\mathbf v]_B\) for \(\mathbf v=\langle0,4\rangle\), \(B=\{\langle1,1\rangle,\langle1,-1\rangle\}\).
    \(c_1+c_2=0\), \(c_1-c_2=4\) → adding, \(2c_1=4\Rightarrow c_1=2,\ c_2=-2\). \([\mathbf v]_B=(2,-2)\).
  4. Given \([\mathbf v]_B=(2,-1)\) with \(B=\{\langle1,1\rangle,\langle1,-1\rangle\}\), find \(\mathbf v\) in standard components.
    \(\mathbf v=2\langle1,1\rangle+(-1)\langle1,-1\rangle=\langle2,2\rangle+\langle-1,1\rangle=\langle1,3\rangle\).
  5. Why is the coordinate list \((c_1,\ldots,c_n)\) guaranteed unique for a given \(\mathbf v\) and basis \(B\), but would not be guaranteed unique if \(B\) were merely a spanning set (not necessarily independent)?
    Uniqueness comes from independence: if two different coefficient lists both worked, subtracting them would give a nontrivial combination of \(B\) equal to \(\mathbf 0\), which independence forbids. Without independence, that contradiction disappears — a merely spanning (but dependent) set can represent the same vector multiple different ways.
  6. Find \([\mathbf v]_B\) for \(\mathbf v=\langle6,0,0\rangle\), \(B=\{\langle2,0,0\rangle,\langle0,1,0\rangle,\langle0,0,1\rangle\}\).
    \(2c_1=6\Rightarrow c_1=3\); \(c_2=0,\ c_3=0\). \([\mathbf v]_B=(3,0,0)\).
  7. bonus — Find \([\mathbf v]_B\) for \(\mathbf v=\langle10,2\rangle\), \(B=\{\langle1,1\rangle,\langle1,-1\rangle\}\).
    \(c_1+c_2=10\), \(c_1-c_2=2\) → \(c_1=6,\ c_2=4\). \((6,4)\).
  8. bonus — True or false: \([\mathbf v]_B\) always has the same number of entries as \(\mathbf v\)'s usual components.
    True only when \(V=\mathbb R^n\) with an \(n\)-vector basis — more precisely, \([\mathbf v]_B\) always has exactly \(\dim(V)\) entries. For other vector spaces (like the 4-dimensional 2×2-matrix space from Chapter 8), that needn't match "how the vector is normally written" at all.
  9. bonus — Can \([\mathbf v]_B=[\mathbf w]_B\) for two different vectors \(\mathbf v\neq\mathbf w\) (same basis \(B\))?
    No — since \(\mathbf v=\sum c_i\mathbf b_i\) is a specific correspondence, identical coordinates force identical vectors; different vectors always get different coordinate tuples relative to the same basis.
  10. bonus — Find \([\mathbf v]_B\) for \(\mathbf v=\langle3,-3\rangle\), \(B=\{\langle1,1\rangle,\langle1,-1\rangle\}\).
    \(c_1+c_2=3\), \(c_1-c_2=-3\) → \(c_1=0,\ c_2=3\). \((0,3)\).
  11. challenge — Find the coordinates of the polynomial \(4x+7\) (as a "vector" in Chapter 1's polynomial vector space) relative to the basis \(\{x,1\}\), then relative to the unusual — but valid — basis \(\{x+1,\ x-1\}\).
    Relative to \(\{x,1\}\): \(4x+7=4\cdot x+7\cdot1\), so coordinates \((4,7)\). Relative to \(\{x+1,x-1\}\): \(c_1(x+1)+c_2(x-1)=(c_1+c_2)x+(c_1-c_2)\), matching \(4x+7\) gives \(c_1+c_2=4\), \(c_1-c_2=7\) → \(c_1=5.5,\ c_2=-1.5\). Check: \(5.5(x+1)-1.5(x-1)=5.5x+5.5-1.5x+1.5=4x+7\) ✓. Same polynomial, two completely different coordinate pairs — "coordinates" generalizes exactly as far beyond arrows as "vector" itself did back in Chapter 1.
