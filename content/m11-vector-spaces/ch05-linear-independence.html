Chapter 5 · concept:linear-independence

Linear Independence

Chapter 4 asked what a set of vectors can reach — its span. This chapter asks something different: is every vector in the set actually pulling its own weight, or is one of them redundant, reachable from the others alone?

Why this matters

Independence is what makes a spanning set efficient — no wasted vectors, nothing that could be deleted without shrinking what it can reach. It's also exactly the second ingredient (alongside spanning) of what Chapter 7 will call a basis — the single most useful kind of set in the whole module.

Definition — Linear independence
\[ c_1\mathbf v_1+c_2\mathbf v_2+\cdots+c_k\mathbf v_k=\mathbf 0 \ \Longrightarrow\ c_1=c_2=\cdots=c_k=0 \]
(11.5.1)

Vectors \(\mathbf v_1,\ldots,\mathbf v_k\) are linearly independent if the only solution to \(c_1\mathbf v_1+\cdots+c_k\mathbf v_k=\mathbf 0\) is the "trivial" one, every \(c_i=0\). If some other, nontrivial solution exists, the set is linearly dependent instead (Chapter 6 covers this side in full). Notice what this connects to directly: setting up \(c_1\mathbf v_1+\cdots+c_k\mathbf v_k=\mathbf 0\) and solving for the \(c_i\) is exactly Module 10's homogeneous system. A unique (trivial) solution means independent; infinitely many solutions means dependent. Testing independence is solving a homogeneous system by Gaussian elimination — nothing new is needed beyond Module 10's own tools.

Worked example — one dependent pair, one independent pair

Test \(\langle1,2\rangle,\langle2,4\rangle\) for independence, then test \(\langle1,2\rangle,\langle2,1\rangle\).

Step 1 — set up the homogeneous system for the first pair

\(c_1\langle1,2\rangle+c_2\langle2,4\rangle=\langle0,0\rangle \Rightarrow c_1+2c_2=0,\ \ 2c_1+4c_2=0\). The second equation is exactly twice the first — it carries no new information.

Step 2 — solve it

One equation, two unknowns: \(c_1=-2c_2\), with \(c_2\) free. Nontrivial solutions exist, e.g. \(c_2=1,\ c_1=-2\): check \(-2\langle1,2\rangle+1\langle2,4\rangle=\langle-2,-4\rangle+\langle2,4\rangle=\langle0,0\rangle\) ✓. Since a nontrivial solution exists, \(\langle1,2\rangle,\langle2,4\rangle\) are dependent.

Step 3 — now the second pair

\(c_1\langle1,2\rangle+c_2\langle2,1\rangle=\langle0,0\rangle \Rightarrow c_1+2c_2=0,\ \ 2c_1+c_2=0\). From the first, \(c_1=-2c_2\); substituting: \(2(-2c_2)+c_2=-4c_2+c_2=-3c_2=0\Rightarrow c_2=0\), then \(c_1=0\).

Result

Only the trivial solution works for the second pair — \(\langle1,2\rangle\) and \(\langle2,1\rangle\) are independent.

Common mistake

Trying to eyeball independence for vectors with three or more components, the way you might glance at two 2D vectors and guess whether they look parallel. That visual shortcut stops being reliable past two dimensions — three vectors in \(\mathbb R^3\) can look scattered and unrelated while still being dependent. The only reliable method, every time, is to actually set up \(c_1\mathbf v_1+\cdots+c_k\mathbf v_k=\mathbf 0\) as a homogeneous system and solve it via Gaussian elimination (Module 10). If it has only the trivial solution, they're independent; if it has infinitely many, they're not. No amount of staring replaces this.

Try it yourself

Are \(\langle1,0\rangle\) and \(\langle0,1\rangle\) linearly independent?

Practice

  1. Are \(\langle3,0\rangle\) and \(\langle0,5\rangle\) independent?
    Yes — \(3c_1=0\) and \(5c_2=0\) force \(c_1=c_2=0\) directly; only the trivial solution.
  2. Are \(\langle1,1\rangle\) and \(\langle-2,-2\rangle\) independent?
    No — \(\langle-2,-2\rangle=-2\langle1,1\rangle\), so \(2\langle1,1\rangle+1\langle-2,-2\rangle=\langle0,0\rangle\) is a nontrivial solution.
  3. Set up (you don't need to solve it yet) the homogeneous system for testing whether \(\langle1,1,0\rangle,\langle0,1,1\rangle,\langle1,0,-1\rangle\) are independent.
    \(c_1\langle1,1,0\rangle+c_2\langle0,1,1\rangle+c_3\langle1,0,-1\rangle=\langle0,0,0\rangle\) gives \(c_1+c_3=0\), \(c_1+c_2=0\), \(c_2-c_3=0\).
  4. Now solve the system from the previous problem. Independent or dependent?
    From the equations: \(c_3=-c_1\), \(c_2=-c_1\), and the third equation \(c_2-c_3=-c_1-(-c_1)=0\) holds automatically for any \(c_1\) — so \(c_1\) is free (e.g. \(c_1=1,c_2=-1,c_3=-1\)). Nontrivial solutions exist: dependent.
  5. Are \(\langle2,0,0\rangle,\langle0,3,0\rangle,\langle0,0,4\rangle\) independent?
    Yes — each equation \(2c_1=0\), \(3c_2=0\), \(4c_3=0\) forces its own coefficient to 0 directly (a nonzero entry in a coordinate no other vector touches).
  6. True or false: a set that includes the zero vector can never be linearly independent.
    True — put a nonzero coefficient on \(\mathbf 0\) and zero everywhere else: \(1\cdot\mathbf 0+0\cdot\mathbf v_2+\cdots=\mathbf 0\) is a nontrivial solution, so the set is automatically dependent.
  7. bonus — Are \(\langle1,2\rangle\) and \(\langle3,6\rangle\) independent?
    No — \(\langle3,6\rangle=3\langle1,2\rangle\).
  8. bonus — Are \(\langle1,0,0\rangle,\langle0,1,0\rangle,\langle0,0,1\rangle,\langle1,1,1\rangle\) (four vectors in \(\mathbb R^3\)) independent?
    No — you can never have 4 independent vectors sitting in \(\mathbb R^3\) (a fact Chapter 8's "dimension" makes precise); indeed \(\langle1,1,1\rangle\) is a combination of the first three.
  9. bonus — Set up and solve the homogeneous system to test \(\langle5,2\rangle\) and \(\langle10,4\rangle\) for independence.
    \(5c_1+10c_2=0\), \(2c_1+4c_2=0\) (the second is \(\frac25\) times the first — dependent equations). Nontrivial solution e.g. \(c_1=2,c_2=-1\): dependent (they're parallel, \(\langle10,4\rangle=2\langle5,2\rangle\)).
  10. bonus — Are \(\langle1,-1\rangle\) and \(\langle-3,3\rangle\) independent?
    No — \(\langle-3,3\rangle=-3\langle1,-1\rangle\).
  11. challenge — Prove that any single nonzero vector \(\mathbf v\) is always linearly independent by itself, and explain why the same is never true of the zero vector alone.
    For a single vector, the equation is \(c\mathbf v=\mathbf 0\). If \(\mathbf v\neq\mathbf 0\), the only scalar making this true is \(c=0\) — only the trivial solution, so \(\{\mathbf v\}\) is independent. If \(\mathbf v=\mathbf 0\) instead, \(c\cdot\mathbf 0=\mathbf 0\) holds for every \(c\), so nontrivial solutions (any \(c\neq0\)) exist — the zero vector alone is always dependent.
