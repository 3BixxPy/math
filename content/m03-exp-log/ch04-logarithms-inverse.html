Logarithms — The Inverse of Exponentials

This is the word the diagnostic came back completely blank on. Here's the whole secret: a logarithm isn't a new kind of math — it's Module 1, Chapter 11's inverse-function idea, applied to the one function family (exponentials) that's guaranteed to actually have one.

Why this matters

concept:inverse-functions (Module 1, Chapter 11) is "the function that undoes another function" — swap x and y, solve for y. Every step of that procedure still applies here. The only reason exponentials get a whole new name and symbol for their inverse, instead of just writing f⁻¹(x), is that logarithms come up constantly enough to deserve their own shorthand. Once you see log as nothing but "the inverse of an exponential," every rule in this module (Chapters 5–9) is really just an exponent rule wearing a different name.

Definition — Logarithm

log_b(x) = y means exactly the same thing as bʸ = x. In words: log_b(x) asks "what power do I raise b to, to get x?" The base b plays the same role it did in Chapter 1 (b > 0, b ≠ 1); x must be positive, since a positive base raised to any real power is always positive (Chapter 1's asymptote fact, restated as a domain restriction).

Rule — Cancellation identities
\[ b^{\log_b x} = x \]
(3.4.1)
\[ \log_b(b^x) = x \]
(3.4.2)

These are exactly the inverse-function cancellation property from Module 1, equation 1.11.1 (f(f⁻¹(x))=x and f⁻¹(f(x))=x), rewritten with f(x)=bˣ and f⁻¹(x)=\log_b x. Apply a function and then its inverse (in either order) and you land back where you started — that's the entire content of both lines above.

y = 2ˣy = log₂(x)

The dashed line is y=x. Just like every inverse pair in Module 1, log₂(x) is the mirror image of 2ˣ across it — swap x and y on the exponential, and you get the logarithm.

Worked example — converting between the two forms

Convert 2³ = 8 to log form, and log_5(25) = 2 to exponential form.

Step 1 — 2³ = 8: identify base, exponent, result

Base \(2\), exponent \(3\), result \(8\). In \(\log_b(x)=y\) form, the base stays the base, the result becomes the log's argument, and the exponent becomes the log's value: \(\log_2(8) = 3\).

Step 2 — log₅(25) = 2: same three parts, other direction

Base \(5\), log's value \(2\), argument \(25\). Converting to \(b^y=x\) form: \(5^2 = 25\).

Common mistake

Mixing up which number is the base and which is the argument when converting. Anchor on this: in log_b(x) = y, the little subscript b is always the base — same role it played as the base of the exponential. When you rewrite as bʸ = x, that same subscript number is what gets raised to a power; the number that was inside the log's parentheses (x) is what comes out on its own on the other side. If you can't remember which way it goes, convert a value you already know cold — like log_2(8)=3 — back to exponential form first, as a template.

Practice

  1. Convert to log form: 3² = 9
    \(\log_3(9)=2\)
  2. Convert to log form: 4³ = 64
    \(\log_4(64)=3\)
  3. Convert to exponential form: log_2(16) = 4
    \(2^4=16\)
  4. Convert to exponential form: log_10(1000) = 3
    \(10^3=1000\)
  5. Use the cancellation identity to simplify 2^(log₂ 7) without computing anything.
    \(7\) (equation 3.4.1)
  6. Use the cancellation identity to simplify log₅(5⁹) without computing anything.
    \(9\) (equation 3.4.2)
  7. bonus — Convert to log form: 6⁰ = 1
    \(\log_6(1)=0\) — true for every valid base, since \(b^0=1\) always
  8. bonus — Convert to exponential form: log_3(1/9) = -2
    \(3^{-2}=1/9\)
  9. bonus — Why must the argument of a logarithm always be positive? Connect it to Chapter 1's asymptote fact.
    Because \(b^y\) (a positive base to any real power) is always positive — it can get arbitrarily close to 0 but never reach or cross it (Chapter 1's asymptote). So there's no real y with \(b^y\leq0\), meaning \(\log_b(x)\) is undefined for \(x\leq0\).
  10. bonus — Why is b = 1 excluded as a logarithm base, the same way it was excluded as an exponential base in Chapter 1?
    Because \(1^y=1\) for every y — every input would map to the single output 1, which isn't invertible (fails the horizontal line test from Module 1, Chapter 11), so \(\log_1(x)\) can't be defined as a function.
  11. challenge — Using only the definition (not a calculator), explain why log_2(0) and log_2(-8) are both undefined, but for two different-sounding reasons that are actually the same reason.
    \(\log_2(0)=y\) would need \(2^y=0\) — impossible, since powers of 2 shrink toward 0 but never hit it. \(\log_2(-8)=y\) would need \(2^y=-8\) — also impossible, since powers of 2 are always positive. Both boil down to the same fact: \(2^y>0\) for every real y, so no exponent ever produces a result that's zero or negative — the log's domain is exactly \(x>0\).
