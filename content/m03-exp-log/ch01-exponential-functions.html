Exponential Functions — f(x) = a·bˣ

The original diagnostic never touched logarithms at all — "untested/unknown." Exponentials are the half of that gap that comes first: put the variable in the exponent instead of the base, and Module 0's exponent laws stop being arithmetic tricks and start being a whole new shape of graph.

Why this matters

Every polynomial you graphed in Module 1 has the variable in the base: x², x³. An exponential function flips that — the variable moves into the exponent: 2ˣ. That single swap changes everything about how the function behaves: instead of growing at a steady, describable rate, it grows (or shrinks) by repeated multiplication, which is exactly how populations, interest, radioactive decay, and — eventually — every continuous rate of change in calculus actually behave. Nothing else in this course grows this fast, or this predictably.

Definition — Exponential function

An exponential function has the form f(x) = a·bˣ, where b is the base (a fixed positive number, b ≠ 1) and a is a nonzero constant multiplier. The variable x lives in the exponent — that's the entire definition. b > 0 so that bˣ is always defined and positive for every real x (a negative base would make bˣ undefined for exponents like 1/2, since you'd be taking an even root of a negative number); b ≠ 1 because 1ˣ is just the constant 1 — flat, not exponential.

Rule — Growth vs. decay
\[ f(x) = a\cdot b^{x}, \qquad b>0,\ b\neq1 \]
(3.1.1)

For a > 0: if b > 1, the function is exponential growth — it climbs, faster and faster, as x increases. If 0 < b < 1, it's exponential decay — it shrinks toward zero as x increases. The base alone decides which shape you get; nothing else about the formula needs to change.

Rule — Horizontal asymptote
\[ y = 0 \]
(3.1.2)

Every basic exponential f(x) = a·bˣ (with a > 0) has horizontal asymptote y = 0 — the x-axis. The graph gets arbitrarily close to it but never touches or crosses it, because a positive base raised to any real power is always strictly positive: bˣ can shrink toward 0, but never reach or pass it.

y = 2.0ˣ — growth (b > 1)

Watch the curve flip its whole shape as b crosses 1 — everything left of the y-axis and everything right of it trade places between growth and decay.

Worked example — evaluating, then comparing growth vs. decay

Evaluate f(x) = 2·3ˣ at x = 0, 1, 2, then compare a growth curve (b=2) against a decay curve (b=0.5).

Step 1 — f(0)

\(f(0) = 2\cdot3^0 = 2\cdot1 = 2\)

Step 2 — f(1)

\(f(1) = 2\cdot3^1 = 2\cdot3 = 6\)

Step 3 — f(2)

\(f(2) = 2\cdot3^2 = 2\cdot9 = 18\)

Contrast — growth vs. decay side by side

For y = 2ˣ (growth): \(x=0\to1,\ x=1\to2,\ x=2\to4\) — each step to the right doubles the output. For y = 0.5ˣ (decay): \(x=0\to1,\ x=1\to0.5,\ x=2\to0.25\) — each step halves it. Same mechanism (repeated multiplication by the base), opposite direction, purely because \(2>1\) and \(0.5<1\).

Common mistake

Expecting exponential growth to behave like polynomial growth — treating 2ˣ like x² because "they both get bigger." They don't stay close for long. Compare them directly: at x=1, \(2^1=2\) vs \(1^2=1\); at \(x=3\), \(2^3=8\) vs \(3^2=9\) — still close. But at x=10, \(2^{10}=1024\) vs \(10^2=100\) — the exponential has pulled miles ahead, and it never stops widening the gap. Worse, the two behave oppositely for negative x: \((-3)^2=9\) grows as x gets more negative, but \(2^{-3}=1/8=0.125\) shrinks toward 0. A polynomial's exponent is a fixed number applied to a changing base; an exponential's base is fixed and the exponent is what changes — that's a structurally different kind of growth, not just a "steeper" version of the same one.

Practice

  1. Evaluate f(x) = 3ˣ at x = 2.
    \(3^2=9\)
  2. Evaluate f(x) = 5·2ˣ at x = 0.
    \(5\cdot2^0=5\cdot1=5\)
  3. Is y = (1/4)ˣ growth or decay?
    Decay — \(0 < 1/4 < 1\)
  4. Is y = 6ˣ growth or decay?
    Growth — \(6 > 1\)
  5. What is the horizontal asymptote of y = 4ˣ?
    \(y=0\)
  6. Evaluate f(x) = 10·(0.5)ˣ at x = 3.
    \(10\cdot0.5^3=10\cdot0.125=1.25\)
  7. bonus — Evaluate f(x) = 2ˣ at x = -2.
    \(2^{-2}=1/4\)
  8. bonus — Which is bigger, 2⁵ or 5²?
    \(2^5=32\) is bigger than \(5^2=25\)
  9. bonus — For y = bˣ, what happens to the graph's shape as b gets closer and closer to 1 (without equaling it)?
    It flattens — the curve approaches the horizontal line \(y=1\), since \(1^x=1\) for every x.
  10. bonus — Describe the relationship between the graphs of y = 2ˣ and y = (1/2)ˣ.
    Mirror images of each other across the y-axis: \((1/2)^x = 2^{-x}\), so one is the other with x negated.
  11. challenge — For which of x = 1, 2, 3, 4, 5 is 2ˣ > x² true? What does that tell you about assuming one always beats the other for small x?
    \(x=1\): \(2>1\) true. \(x=2\): \(4=4\) equal. \(x=3\): \(8<9\) false. \(x=4\): \(16=16\) equal. \(x=5\): \(32>25\) true again — and true for every integer \(x\geq5\) after that. So the comparison actually flips more than once for small x before the exponential wins for good; "exponential eventually beats every polynomial" is true, but "eventually" can take a few tries to kick in, which is exactly why testing a couple of small values isn't enough to trust a pattern.
