Log Laws I — Product & Quotient Rules

Module 0, Chapter 3 derived the exponent product and quotient rules from nothing but counting factors. Because a log is just an exponent by another name (Chapter 4), those same two rules translate directly into log rules — this chapter is that translation, done explicitly.

Why this matters

These aren't independent facts to memorize — they're concept:exponent-product-rule and concept:exponent-quotient-rule (Module 0, Chapter 3) seen from the other side of the inverse relationship. Multiplying two numbers with the same base adds their exponents; taking the log of a product should therefore add the logs. If that connection ever fades, the two-line derivation below rebuilds both rules from scratch in seconds — no separate memorization required.

Rule — Product rule (derived)
\[ \log_b(MN) = \log_b M + \log_b N \]
(3.6.1)
Derivation — let x = log_b M and y = log_b N

By the definition of log (Chapter 4): \(b^x=M\) and \(b^y=N\). Then \(MN = b^x\cdot b^y\).

Apply the exponent product rule (Module 0, Chapter 3)

\(b^x\cdot b^y = b^{x+y}\), so \(MN = b^{x+y}\).

Convert back to log form

\(MN=b^{x+y}\) means \(\log_b(MN) = x+y = \log_b M + \log_b N\) — exactly equation 3.6.1, built entirely from the exponent rule you already had.

Rule — Quotient rule (derived)
\[ \log_b\!\left(\frac MN\right) = \log_b M - \log_b N \]
(3.6.2)

Same derivation, using the exponent quotient rule instead: with \(x=\log_b M\), \(y=\log_b N\), \(\dfrac MN = \dfrac{b^x}{b^y} = b^{x-y}\) (Module 0, Chapter 3's quotient rule), so \(\log_b(M/N) = x-y = \log_b M - \log_b N\).

Worked example — expanding and combining

Expand log(5x/3) fully, then combine log₂(9) + log₂(x) into a single log.

Step 1 — apply the quotient rule to log(5x/3)

\(\log\!\left(\dfrac{5x}{3}\right) = \log(5x) - \log(3)\)

Step 2 — the numerator is itself a product; apply the product rule

\(\log(5x) = \log5 + \log x\), so overall: \(\log5+\log x-\log3\)

Step 3 — combine log₂(9) + log₂(x), running the product rule in reverse

\(\log_2(9)+\log_2(x) = \log_2(9x)\)

Common mistake — the classic false rule

Believing log(M + N) = log M + log N. This is false — there is no rule for the log of a sum; addition inside a log doesn't simplify at all. The real rule (equation 3.6.1) is about a product: log(MN) = log M + log N. Test it with numbers to see the false version fail immediately: log(2+2) = log(4) ≈ 0.602, but log(2)+log(2) ≈ 0.301+0.301 = 0.602 — wait, those happen to match because \(2+2=2\cdot2\) here. Try log(3+5) against log(3)+log(5) instead: \(\log(8)\approx0.903\) vs. \(\log3+\log5\approx0.477+0.699=1.176\) — clearly different. The product rule works because multiplying bases adds exponents; addition inside the log has no such exponent-counting structure to exploit.

Practice

  1. Expand: log(3x)
    \(\log3+\log x\)
  2. Expand: log_2(x/5)
    \(\log_2 x-\log_2 5\)
  3. Combine into one log: log(x) + log(y)
    \(\log(xy)\)
  4. Combine into one log: ln(a) − ln(b)
    \(\ln(a/b)\)
  5. Expand fully: log(2xy)
    \(\log2+\log x+\log y\)
  6. Is log(10) + log(10) equal to log(20) or log(100)?
    \(\log(100)\) — the product rule adds logs for a product, and \(10\cdot10=100\), not \(10+10=20\).
  7. bonus — Expand fully: log(x/(3y))
    \(\log x-\log3-\log y\)
  8. bonus — Combine into one log: log₅(12) − log₅(4) + log₅(2)
    \(\log_5(12/4\cdot2)=\log_5(6)\)
  9. bonus — Show numerically that log(2+3) ≠ log(2) + log(3) (compute both sides to 3 decimals).
    \(\log(5)\approx0.699\); \(\log(2)+\log(3)\approx0.301+0.477=0.778\). Different — confirms the sum rule is false.
  10. bonus — Rewrite ln(x) + ln(x-1) as a single log (careful with the implied domain).
    \(\ln(x(x-1))\), valid only where both original arguments are positive: \(x>1\).
  11. challenge — Derive the quotient rule yourself from scratch (don't reread the theorem box): starting from x = log_b M and y = log_b N, show log_b(M/N) = x - y.
    \(b^x=M\), \(b^y=N\) by definition. \(M/N = b^x/b^y = b^{x-y}\) (exponent quotient rule). Converting back: \(\log_b(M/N)=x-y=\log_b M-\log_b N\).
