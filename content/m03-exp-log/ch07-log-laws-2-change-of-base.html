Log Laws II — Power Rule & Change of Base

One more exponent rule to translate (Module 0's power-of-a-power rule), plus a genuinely new, purely practical tool: a way to evaluate any base's logarithm using only the ln button on a calculator.

Why this matters

The power rule finishes the translation Chapter 6 started — every exponent law from Module 0 now has a log-law counterpart. The change-of-base formula is different in kind: it's not a translated exponent rule, it's a practical bridge. Calculators and computers only ever implement log and ln directly; change of base is how you evaluate log_7(50) or any other base without needing a "base 7" button that doesn't exist.

Rule — Power rule (derived)
\[ \log_b(M^k) = k\cdot\log_b M \]
(3.7.1)

Why: let \(x=\log_b M\), so \(b^x=M\). Then \(M^k = (b^x)^k = b^{xk}\) (Module 0's power-of-a-power rule: multiply the exponents). Converting back: \(\log_b(M^k) = xk = k\cdot\log_b M\) — the exponent \(k\) moves out front as a multiplier.

Rule — Change of base
\[ \log_b(x) = \frac{\ln(x)}{\ln(b)} \]
(3.7.2)

Any base's logarithm can be rewritten as a ratio of two natural logs (or two common logs — log(x)/log(b) works identically). This is how you compute a logarithm in a base your calculator doesn't have a direct button for.

Worked example

Simplify log(x³), then evaluate log_2(10) using change of base.

Step 1 — apply the power rule to log(x³)

\(\log(x^3) = 3\log(x)\) — the exponent 3 comes straight out front.

Step 2 — set up log₂(10) with change of base

\(\log_2(10) = \dfrac{\ln(10)}{\ln(2)}\)

Step 3 — evaluate numerically

\(\ln(10)\approx2.3026\), \(\ln(2)\approx0.6931\), so \(\log_2(10)\approx\dfrac{2.3026}{0.6931}\approx3.3219\). Sanity check: \(2^3=8\) and \(2^4=16\), and 10 sits between them — 3.32 is right where it should be.

Common mistake

Confusing log(Mᵏ) with (log M)ᵏ — these are two completely different expressions. The power rule (equation 3.7.1) only applies to the first one: the exponent is inside the log's argument. Once a whole log expression is itself raised to a power on the outside, like (log M)², there's no rule to pull that exponent anywhere — it just stays an exponent on the log's output. Check with numbers: log(10²) = log(100) = 2, while (log 10)² = 1² = 1 — genuinely different values, not two forms of the same thing.

Practice

  1. Simplify: log(x⁴)
    \(4\log x\)
  2. Simplify: ln(x²)
    \(2\ln x\)
  3. Rewrite as a single log with exponent 1: 3·log₂(x)
    \(\log_2(x^3)\) — the power rule run in reverse
  4. Use change of base to write log_5(x) in terms of natural logs.
    \(\dfrac{\ln x}{\ln 5}\)
  5. Evaluate log_3(20) using change of base (round to 3 decimals).
    \(\ln(20)/\ln(3)\approx2.9957/1.0986\approx2.727\)
  6. Is log(x²) the same as (log x)²? Justify with a number.
    No. E.g. \(x=10\): \(\log(10^2)=\log(100)=2\), but \((\log10)^2=1^2=1\).
  7. bonus — Simplify: log(√x) (hint: rewrite the root as a rational exponent first — Module 0, Chapter 5)
    \(\sqrt x=x^{1/2}\), so \(\log(x^{1/2})=\tfrac12\log x\)
  8. bonus — Evaluate log_7(100) using change of base (round to 3 decimals).
    \(\ln(100)/\ln(7)\approx4.6052/1.9459\approx2.366\)
  9. bonus — Simplify fully: 2·ln(x) + ln(x) into a single log with one exponent.
    \(\ln(x^2)+\ln(x)=\ln(x^3)\) (power rule to combine the first term, then product rule from Chapter 6)
  10. bonus — Explain why change of base works using only the cancellation identities from Chapter 4 (don't just cite the formula).
    Let \(y=\log_b x\), so \(b^y=x\). Take \(\ln\) of both sides: \(\ln(b^y)=\ln x\), and the power rule gives \(y\ln b=\ln x\), so \(y=\dfrac{\ln x}{\ln b}\) — exactly the formula, derived rather than memorized.
  11. challenge — Simplify log_2(8ˣ) two different ways — first using the power rule directly, then by rewriting 8 as 2³ first — and confirm both give the same answer.
    Power rule directly: \(\log_2(8^x)=x\log_2(8)=x\cdot3=3x\) (since \(\log_2 8=3\)). Rewriting first: \(8^x=(2^3)^x=2^{3x}\), so \(\log_2(2^{3x})=3x\) by the cancellation identity (equation 3.4.2). Both give \(3x\).
