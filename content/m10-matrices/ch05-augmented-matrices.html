Chapter 5 · concept:augmented-matrices

Augmented Matrices

Chapters 2–4 built matrix vocabulary and operations in the abstract. This chapter is the actual bridge back to Chapter 1's problem: turning a messy system of equations into one single matrix object that can be manipulated systematically.

Why this matters

Chapter 1's ad hoc elimination was hard to track precisely because the equations lived as separate lines of algebra, each with its own variables spelled out. An augmented matrix strips away the repeated \(x\), \(y\), \(z\) labels and the \(+\) and \(=\) signs, keeping only the numbers — in fixed positions. Once the system lives as a grid, "which equation have I used" becomes "which row have I used," and rows don't wander the way lines of handwritten algebra can. This is the single representational shift that makes Chapters 6–8's systematic procedure possible.

Definition — Augmented matrix
\[ \left[\begin{array}{ccc|c} a_{11} & a_{12} & a_{13} & b_1 \\ a_{21} & a_{22} & a_{23} & b_2 \\ a_{31} & a_{32} & a_{33} & b_3 \end{array}\right] \]
(10.5.1)

The coefficient matrix (left of the bar) holds every variable's coefficient, one column per variable, one row per equation — and the constants column (right of the bar) holds each equation's right-hand side. The vertical bar is purely visual, a reminder of where "the equation" ends and "equals what" begins; it carries no computational meaning of its own.

Worked example — equations to matrix, and back

Convert to an augmented matrix: x + y + z = 6, 2x + y − z = 1, x − y + 2z = 5 (the same system from Chapters 1 and — later — 7 and 8).

Step 1 — one row per equation, one column per variable, in a fixed order (x, y, z)

Row 1 from x+y+z=6: coefficients \(1,1,1\), constant \(6\). Row 2 from 2x+y-z=1: coefficients \(2,1,-1\), constant \(1\). Row 3 from x-y+2z=5: coefficients \(1,-1,2\), constant \(5\).

Result

\(\left[\begin{array}{ccc|c} 1&1&1&6 \\ 2&1&-1&1 \\ 1&-1&2&5 \end{array}\right]\) — three rows, four columns (3 variables + 1 constant column), commonly described as \(3\times4\) augmented, or "\(3\times3\) coefficient matrix augmented with a constant column."

Going the other way — reading a matrix back as equations

Given \(\left[\begin{array}{cc|c}3&-2&7\\1&5&-4\end{array}\right]\), each row rebuilds one equation: row 1 is \(3x-2y=7\), row 2 is \(x+5y=-4\) — just reattach the variable names and the equals sign, in the same column order used to build the matrix.

Common mistake

Misaligning a column when a variable is missing from one of the equations. For the system x + z = 4, y − z = 1, 2x + y = 5 (y missing from eq. 1, x missing from eq. 2, z missing from eq. 3), the augmented matrix still needs three coefficient columns — for the missing variable in each row, write \(0\), don't skip the column: \(\left[\begin{array}{ccc|c}1&0&1&4\\0&1&-1&1\\2&1&0&5\end{array}\right]\). Skipping a column instead of zero-padding it shifts every later coefficient one column left, silently turning the matrix into a completely different (and wrong) system.

Try it yourself

For the system x + y = 4, x − y = 2, write the augmented matrix. What is the second (bottom) entry of the constants column?

Practice

  1. Write the augmented matrix for 2x + 3y = 7, x − y = 1
    \(\left[\begin{array}{cc|c}2&3&7\\1&-1&1\end{array}\right]\)
  2. Write the augmented matrix for x + y + z = 3, 2x − y + z = 4, x + 2y − z = 0
    \(\left[\begin{array}{ccc|c}1&1&1&3\\2&-1&1&4\\1&2&-1&0\end{array}\right]\)
  3. Write the equations represented by \(\left[\begin{array}{cc|c}1&2&5\\3&-1&4\end{array}\right]\)
    x + 2y = 5, 3x − y = 4
  4. Write the augmented matrix for x + 2z = 6, y − z = 1, 3x + y = 8 (careful with missing variables)
    \(\left[\begin{array}{ccc|c}1&0&2&6\\0&1&-1&1\\3&1&0&8\end{array}\right]\)
  5. Write the equations represented by \(\left[\begin{array}{ccc|c}1&0&0&5\\0&1&0&-2\\0&0&1&3\end{array}\right]\)
    x = 5, y = -2, z = 3 — the solution is already sitting right there in the constants column (this exact shape is the target of Chapter 8).
  6. What are the dimensions of the augmented matrix for a system of 4 equations in 3 unknowns?
    \(4\times4\) — 4 rows (one per equation), and \(3+1=4\) columns (3 variables plus the constant column).
  7. bonus — Write the augmented matrix for y = 2x + 1, 3x − y = 5 (rearrange to standard form first)
    Rearranged: -2x + y = 1, 3x - y = 5. Matrix: \(\left[\begin{array}{cc|c}-2&1&1\\3&-1&5\end{array}\right]\)
  8. bonus — Write the equations represented by \(\left[\begin{array}{ccc|c}2&0&-1&3\\0&1&0&4\\1&1&1&0\end{array}\right]\)
    2x − z = 3, y = 4, x + y + z = 0
  9. bonus — Write the augmented matrix for x + y + z + w = 10, x − y = 2, z + w = 6, 2x + w = 5 (4 variables — same idea, one more column)
    \(\left[\begin{array}{cccc|c}1&1&1&1&10\\1&-1&0&0&2\\0&0&1&1&6\\2&0&0&1&5\end{array}\right]\)
  10. bonus — True or false: the vertical bar in an augmented matrix changes how row operations (Chapter 6) are allowed to be applied to that column.
    False — the bar is a visual label only. Every row operation applies to the entire row, constants column included (this becomes a specific common mistake in Chapter 6).
  11. challenge — A system has 5 equations in 5 unknowns, but one equation is missing two of the variables entirely. What are the dimensions of its augmented matrix, and how many zero entries does that one row contain (not counting whether other entries happen to also be zero)?
    Dimensions: \(5\times6\) (5 rows, 5 variable columns + 1 constant column) — missing variables don't change the matrix's shape, they just force explicit \(0\)s. That one row has at least 2 zero entries (one per missing variable), guaranteed by the zero-placeholder rule regardless of what the other coefficients happen to be.
