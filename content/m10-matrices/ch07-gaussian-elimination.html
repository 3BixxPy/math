Chapter 7 · concept:gaussian-elimination

Gaussian Elimination

This is the payoff promised back in Chapter 1: the same system that took four separate improvised decisions to solve by hand now gets solved by one fixed procedure — the same procedure regardless of how many variables it has.

Why this matters

Gaussian elimination is just Chapters 5 and 6 combined into an actual algorithm: write the system as an augmented matrix, then apply row operations in a systematic left-to-right, top-to-bottom sweep until the matrix reaches row echelon form, then read the answer out from the bottom up. No step requires spotting a clever combination of equations — every step is "look at the next column, use it to zero out everything below the staircase." This is precisely what scales past three variables to ten, or a hundred.

Method — Gaussian elimination
  1. Write the system as an augmented matrix (Chapter 5).
  2. Use row operations (Chapter 6) to create zeros below the leading entry of column 1, working row by row down the matrix.
  3. Move to column 2, and repeat — create zeros below its leading entry, using only the rows below the one already fixed.
  4. Continue column by column until the matrix is in row echelon form (Chapter 6).
  5. Back-substitute, starting from the bottom row (which now involves only the last variable) and working upward, plugging each newly-found value into the row above.

Steps 1–4 are called forward elimination; step 5 is back-substitution. Together they replace every ad hoc decision from Chapter 1 with a fixed left-to-right sweep.

Worked example — start to finish

Solve via Gaussian elimination: x + y + z = 6, 2x + y − z = 1, x − y + 2z = 5 (Chapter 1's system, ad hoc solution was \((1,2,3)\)).

Step 1 — augmented matrix

\(\left[\begin{array}{ccc|c}1&1&1&6\\2&1&-1&1\\1&-1&2&5\end{array}\right]\)

Step 2 — clear column 1 below row 1: R2 → R2 − 2R1, R3 → R3 − R1

\(R_2-2R_1 = [0,-1,-3\ |\ -11]\). \(R_3-R_1=[0,-2,1\ |\ -1]\). Matrix becomes \(\left[\begin{array}{ccc|c}1&1&1&6\\0&-1&-3&-11\\0&-2&1&-1\end{array}\right]\)

Step 3 — clear column 2 below row 2: R3 → R3 − 2R2

\(R_3-2R_2 = [0-0,\ -2-2(-1),\ 1-2(-3)\ |\ -1-2(-11)] = [0,0,7\ |\ 21]\). Matrix becomes \(\left[\begin{array}{ccc|c}1&1&1&6\\0&-1&-3&-11\\0&0&7&21\end{array}\right]\) — row echelon form.

Step 4 — back-substitute from the bottom row

Row 3: \(7z=21 \Rightarrow z=3\). Row 2: \(-y-3z=-11 \Rightarrow -y-9=-11 \Rightarrow y=2\). Row 1: \(x+y+z=6 \Rightarrow x+2+3=6 \Rightarrow x=1\).

Result
\[ (x,y,z) = (1,\ 2,\ 3) \]
(10.7.1)

Same answer Chapter 1 found by improvisation — reached here by a fixed sweep with no decisions to make about which equation to combine with which.

Common mistake

Back-substituting in the wrong order — starting from row 1 (top) instead of the last row (bottom). Row echelon form is shaped specifically so that the bottom row involves the fewest variables (often just one), which is exactly what makes it solvable first. Row 1 in the worked example above still has all three variables in it (\(x+y+z=6\)) — there's no way to solve it alone. Always solve the bottom row first, then substitute upward one row at a time; going top to bottom leaves you with one equation in three unknowns and nothing to plug in yet.

Try it yourself

A system's row echelon form ends in the row \([0\ \ 0\ \ 5\ \ |\ \ 15]\) (representing \(5z=15\)). What is \(z\)?

Practice

  1. Solve via Gaussian elimination: x + y = 5, 2x − y = 1
    \(\left[\begin{array}{cc|c}1&1&5\\2&-1&1\end{array}\right]\), \(R_2-2R_1=[0,-3|-9]\Rightarrow y=3\); back-sub: \(x=2\). \((x,y)=(2,3)\)
  2. Solve via Gaussian elimination: x − y = 1, 3x + y = 7
    \(\left[\begin{array}{cc|c}1&-1&1\\3&1&7\end{array}\right]\), \(R_2-3R_1=[0,4|4]\Rightarrow y=1\); back-sub: \(x=2\). \((x,y)=(2,1)\)
  3. Solve via Gaussian elimination: x + y + z = 4, x − y + z = 2, 2x + y − z = 1
    \(\left[\begin{array}{ccc|c}1&1&1&4\\1&-1&1&2\\2&1&-1&1\end{array}\right]\). \(R_2-R_1=[0,-2,0|-2]\); \(R_3-2R_1=[0,-1,-3|-7]\). New matrix rows 2,3: \([0,-2,0|-2]\), \([0,-1,-3|-7]\). \(R_3 - \tfrac12 R_2 = [0,0,-3|-6]\Rightarrow z=2\). From row 2: \(-2y=-2\Rightarrow y=1\). From row 1: \(x+1+2=4\Rightarrow x=1\). \((x,y,z)=(1,1,2)\)
  4. A row-echelon augmented matrix has bottom row \([0\ 0\ 1\ |\ -4]\). What does this row alone tell you?
    The last variable directly: \(z=-4\) — no further work needed for this row, it's ready to plug into the row above.
  5. Solve via Gaussian elimination: 2x + y = 8, x + 3y = 9
    Swap first for convenience: \(\left[\begin{array}{cc|c}1&3&9\\2&1&8\end{array}\right]\), \(R_2-2R_1=[0,-5|-10]\Rightarrow y=2\); back-sub: \(x+6=9\Rightarrow x=3\). \((x,y)=(3,2)\)
  6. Given row echelon form \(\left[\begin{array}{ccc|c}1&2&-1&3\\0&1&1&4\\0&0&2&6\end{array}\right]\), find \((x,y,z)\) by back-substitution.
    Row 3: \(2z=6\Rightarrow z=3\). Row 2: \(y+z=4\Rightarrow y=1\). Row 1: \(x+2y-z=3\Rightarrow x+2-3=3\Rightarrow x=4\). \((x,y,z)=(4,1,3)\)
  7. bonus — Solve via Gaussian elimination: x − 2y = -1, 3x + y = 10
    \(\left[\begin{array}{cc|c}1&-2&-1\\3&1&10\end{array}\right]\), \(R_2-3R_1=[0,7|13]\Rightarrow y=13/7\)... to keep this clean, verify by re-checking: \(3x+y=10\) with \(x=-1+2y\): \(3(-1+2y)+y=10\Rightarrow -3+7y=10\Rightarrow y=\tfrac{13}{7}\), \(x=-1+\tfrac{26}{7}=\tfrac{19}{7}\). \((x,y)=(19/7,\ 13/7)\) — a reminder that Gaussian elimination doesn't require clean integers, it just requires following the procedure.
  8. bonus — Given row echelon form \(\left[\begin{array}{ccc|c}2&1&3&5\\0&-1&1&2\\0&0&4&8\end{array}\right]\), find \((x,y,z)\).
    Row 3: \(4z=8\Rightarrow z=2\). Row 2: \(-y+z=2\Rightarrow -y+2=2\Rightarrow y=0\). Row 1: \(2x+y+3z=5\Rightarrow 2x+0+6=5\Rightarrow x=-0.5\). \((x,y,z)=(-0.5,0,2)\)
  9. bonus — Solve via Gaussian elimination: x + y + z = 0, x − y + z = 2, x + y − z = -4
    \(\left[\begin{array}{ccc|c}1&1&1&0\\1&-1&1&2\\1&1&-1&-4\end{array}\right]\). \(R_2-R_1=[0,-2,0|2]\Rightarrow y=-1\). \(R_3-R_1=[0,0,-2|-4]\Rightarrow z=2\). Row 1: \(x-1+2=0\Rightarrow x=-1\). \((x,y,z)=(-1,-1,2)\)
  10. bonus — Explain in one sentence why forward elimination always works column by column, left to right, rather than in a different order.
    Each column's elimination step relies on the leading entry already secured in the column(s) to its left staying fixed — working left to right guarantees you never disturb a column you've already finished.
  11. challenge — Solve via Gaussian elimination, showing every row operation explicitly: x + 2y + z = 9, 2x − y + 3z = 8, 3x + y − z = 4
    \(\left[\begin{array}{ccc|c}1&2&1&9\\2&-1&3&8\\3&1&-1&4\end{array}\right]\). \(R_2-2R_1=[0,-5,1|-10]\). \(R_3-3R_1=[0,-5,-4|-23]\). New: \(\left[\begin{array}{ccc|c}1&2&1&9\\0&-5&1&-10\\0&-5&-4&-23\end{array}\right]\). \(R_3-R_2=[0,0,-5|-13]\Rightarrow z=13/5=2.6\). Row 2: \(-5y+z=-10\Rightarrow -5y+2.6=-10\Rightarrow y=2.52\). Row 1: \(x+2(2.52)+2.6=9\Rightarrow x=9-5.04-2.6=1.36\). \((x,y,z)=(1.36,\ 2.52,\ 2.6)\) — deliberately unfriendly numbers, to emphasize that the procedure doesn't care whether the answer is clean.
