Module 10 Capstone — Mixed Review & Diagnostic Retake

Eleven chapters, shuffled together, plus a retake of Module 0's two-variable systems — the same problem type, now solvable at any scale by the exact machinery this module built.

Why mixed, not grouped by chapter

Same reasoning as every capstone since Module 0: a problem that doesn't announce its own chapter is the real test of whether the idea moved into durable memory, not just short-term pattern matching against a chapter title. This module makes that test especially pointed — nearly every chapter here reused the same running example system (Chapters 1, 5, 7, 8) and the same pair of matrices (Chapters 4, 10, 11), so shuffling forces you to recognize which tool a problem needs, not just which numbers looked familiar.

Mixed review (all of Module 10)

  1. Solve by ad hoc elimination or substitution: x + y = 8, x − y = 2
    Add: \(2x=10\Rightarrow x=5, y=3\) (Chapter 1)
  2. State the dimensions of \(\begin{bmatrix}1&2&3\\4&5&6\end{bmatrix}\), and identify entry \(a_{21}\).
    \(2\times3\); \(a_{21}=4\) (Chapter 2)
  3. Compute \(\begin{bmatrix}1&-2\\3&0\end{bmatrix}+2\begin{bmatrix}0&1\\-1&4\end{bmatrix}\)
    \(\begin{bmatrix}1&-2\\3&0\end{bmatrix}+\begin{bmatrix}0&2\\-2&8\end{bmatrix}=\begin{bmatrix}1&0\\1&8\end{bmatrix}\) (Chapter 3)
  4. Multiply \(\begin{bmatrix}1&2\\0&1\end{bmatrix}\begin{bmatrix}3&1\\2&4\end{bmatrix}\)
    \(\begin{bmatrix}1(3)+2(2)&1(1)+2(4)\\0(3)+1(2)&0(1)+1(4)\end{bmatrix}=\begin{bmatrix}7&9\\2&4\end{bmatrix}\) (Chapter 4)
  5. Write the augmented matrix for x + 2y = 5, 3x − y = 1
    \(\left[\begin{array}{cc|c}1&2&5\\3&-1&1\end{array}\right]\) (Chapter 5)
  6. Which row operation turns \(\begin{bmatrix}1&3\\2&4\end{bmatrix}\) into \(\begin{bmatrix}1&3\\0&-2\end{bmatrix}\) in the second row?
    \(R_2\to R_2-2R_1\) (Chapter 6)
  7. Solve via Gaussian elimination: x + y = 6, 2x − y = 3
    \(\left[\begin{array}{cc|c}1&1&6\\2&-1&3\end{array}\right]\), \(R_2-2R_1=[0,-3|-9]\Rightarrow y=3\); back-sub \(x=3\). \((x,y)=(3,3)\) (Chapter 7)
  8. Continue \(\left[\begin{array}{cc|c}1&2&7\\0&1&3\end{array}\right]\) to RREF and read the solution.
    \(R_1\to R_1-2R_2=[1,0|1]\). RREF: \(\left[\begin{array}{cc|c}1&0&1\\0&1&3\end{array}\right]\); \(x=1,y=3\) (Chapter 8)
  9. Classify: \(\left[\begin{array}{cc|c}1&0&4\\0&0&6\end{array}\right]\)
    No solution — bottom row reads \(0=6\), a contradiction (Chapter 9)
  10. Does \(AI=IA=A\) hold for every matrix \(A\) (with \(I\) of compatible size)?
    Yes — that's the defining property of the identity matrix (Chapter 10)
  11. Find \(\det\begin{bmatrix}4&1\\3&1\end{bmatrix}\), and state whether the matrix is invertible.
    \(4(1)-1(3)=1\), nonzero, so invertible (Chapter 11)
  12. Solve via Gaussian elimination: 2x + y = 7, x − y = -1
    \(\left[\begin{array}{cc|c}2&1&7\\1&-1&-1\end{array}\right]\); swap for convenience: \(\left[\begin{array}{cc|c}1&-1&-1\\2&1&7\end{array}\right]\), \(R_2-2R_1=[0,3|9]\Rightarrow y=3\); back-sub \(x=-1+3=2\). \((x,y)=(2,3)\) (Chapter 7, second pass)

Synthesis — concepts combining, not just shuffled

Two problems that each need multiple chapters' tools working together, not just one technique per problem.

Synthesis 1
Ch. 7 — Gaussian eliminationCh. 9 — solution types

Solve, and classify the solution type of: x + y + z = 2, 2x + y + z = 3, x + 2y + 2z = 4

Step 1 — set up the augmented matrix and clear column 1 (Ch. 7's forward elimination)

\(\left[\begin{array}{ccc|c}1&1&1&2\\2&1&1&3\\1&2&2&4\end{array}\right]\). \(R_2-2R_1=[0,-1,-1|-1]\). \(R_3-R_1=[0,1,1|2]\). Matrix: \(\left[\begin{array}{ccc|c}1&1&1&2\\0&-1&-1&-1\\0&1&1&2\end{array}\right]\)

Step 2 — clear column 2 using row 2

\(R_3+R_2 = [0,1-1,1-1\ |\ 2-1]=[0,0,0\ |\ 1]\). Matrix: \(\left[\begin{array}{ccc|c}1&1&1&2\\0&-1&-1&-1\\0&0&0&1\end{array}\right]\)

Step 3 — classify using Chapter 9's test

The bottom row reads \(0=1\) — a genuine contradiction, not a redundant \(0=0\) row.

Result

No solution. Gaussian elimination (Chapter 7) doesn't just produce answers — running it to completion and reading the bottom row is exactly how Chapter 9's classification gets applied in practice; the two chapters are really one workflow, not two separate skills.

Synthesis 2
Ch. 4 — matrix multiplicationCh. 10/11 — inverses

Find the inverse of \(A=\begin{bmatrix}1&4\\1&3\end{bmatrix}\) using the Chapter 11 shortcut, then verify it fully by computing both \(AA^{-1}\) and \(A^{-1}A\) using Chapter 4's row-by-column rule.

Step 1 — compute the determinant (Ch. 11)

\(\det(A) = 1(3)-4(1) = -1\). Nonzero, so \(A\) is invertible.

Step 2 — apply the 2×2 inverse formula

Swap \(a,d\); negate \(b,c\): \(A^{-1} = \frac{1}{-1}\begin{bmatrix}3&-4\\-1&1\end{bmatrix} = \begin{bmatrix}-3&4\\1&-1\end{bmatrix}\)

Step 3 — verify AA⁻¹ using row-by-column multiplication (Ch. 4)

\(\begin{bmatrix}1&4\\1&3\end{bmatrix}\begin{bmatrix}-3&4\\1&-1\end{bmatrix}=\begin{bmatrix}1(-3)+4(1)&1(4)+4(-1)\\1(-3)+3(1)&1(4)+3(-1)\end{bmatrix}=\begin{bmatrix}1&0\\0&1\end{bmatrix}\) ✓

Step 4 — verify A⁻¹A the other order

\(\begin{bmatrix}-3&4\\1&-1\end{bmatrix}\begin{bmatrix}1&4\\1&3\end{bmatrix}=\begin{bmatrix}-3(1)+4(1)&-3(4)+4(3)\\1(1)+(-1)(1)&1(4)+(-1)(3)\end{bmatrix}=\begin{bmatrix}1&0\\0&1\end{bmatrix}\) ✓

Result

\(A^{-1}=\begin{bmatrix}-3&4\\1&-1\end{bmatrix}\), confirmed both ways — the determinant test (Ch. 11) says an inverse exists, the shortcut formula (Ch. 11) produces it, and Chapter 4's multiplication rule is what actually certifies it's correct. Three chapters, one clean workflow.

Diagnostic retake

Module 0's two-variable systems (Chapter 14) were solvable by hand with no real bookkeeping. The retake below deliberately stays small enough to solve either way — the point isn't that the answer changed, it's that the same systematic procedure now scales to problems Module 0 never could have handled.

1. Write the augmented matrix for 2x + y = 7, x − 3y = -7, and classify (without fully solving) whether you'd expect a unique solution.

Originally (Module 0, Ch. 14): solved by hand with elimination — no matrix representation available yet.

\(\left[\begin{array}{cc|c}2&1&7\\1&-3&-7\end{array}\right]\). Two independent equations in two unknowns, no obvious row-proportionality between the coefficient rows, so a unique solution is expected (confirmed by row-reducing: \(x=2, y=3\)). See Chapters 5 and 9.

2. This RREF matrix came from a 3-variable system: \(\left[\begin{array}{ccc|c}1&0&2&5\\0&1&-1&3\\0&0&0&0\end{array}\right]\). Classify the solution type and, if applicable, write the parametrized solution.

Originally (Module 0, Ch. 14): only two-variable systems existed — a free-variable, infinite-solutions system had no equivalent yet.

Infinitely many solutions — column 3 has no pivot, so \(z\) is free. Let \(z=t\): \(x=5-2t\), \(y=3+t\). Solution: \((x,y,z)=(5-2t,\ 3+t,\ t)\). See Chapters 8 and 9.

3. Find the inverse of \(\begin{bmatrix}5&2\\3&1\end{bmatrix}\).

Originally (Module 0, Ch. 14): solving by substitution/elimination was the only tool — the idea of solving a system by multiplying by an inverse matrix didn't exist yet.

\(\det=5(1)-2(3)=-1\). \(A^{-1}=\frac{1}{-1}\begin{bmatrix}1&-2\\-3&5\end{bmatrix}=\begin{bmatrix}-1&2\\3&-5\end{bmatrix}\). Check: \(\begin{bmatrix}5&2\\3&1\end{bmatrix}\begin{bmatrix}-1&2\\3&-5\end{bmatrix}=\begin{bmatrix}-5+6&10-10\\-3+3&6-5\end{bmatrix}=\begin{bmatrix}1&0\\0&1\end{bmatrix}\) ✓. See Chapter 11.
