What Is a Limit?

The diagnostic found zero calculus exposure — not a gap to patch, because there's nothing here yet to be rusty on. This is the first genuinely new kind of idea in the whole curriculum: every module so far has been new notation on things you basically already understood (counting, algebra, shapes, angles, logic gates). A limit is a different kind of question entirely — not "what is this?" but "what is this heading toward?"

Why this matters

Every function chapter in Module 1 asked one question: given an input, what's the output? That question is f(a) — direct evaluation, plug in and compute. A limit asks something subtly but completely different: as x gets closer and closer to some value a, what value does f(x) get closer and closer to? Those two questions usually have the same answer. They don't have to. And the entire reason calculus needs its own new vocabulary is that some of the most important quantities in mathematics and physics — instantaneous speed, the slope of a curve at a single point, the exact area under a curve — are only expressible as the answer to a "getting arbitrarily close to" question, never as a single plug-in-and-compute one. Everything for the rest of this module, and everything Module 6 builds on top of it, rests on getting comfortable with that distinction starting right now.

Definition — Limit (informal)
\[ \lim_{x \to a} f(x) = L \]
(5.1.1)

Read this as: "the limit of f(x), as x approaches a, is L." It means f(x) gets arbitrarily close to L as x gets arbitrarily close to a, from either side. Crucially: f does not need to be defined at a itself for this statement to be true, or even to make sense. The limit describes behavior near a — it never once looks at a.

Worked example — estimating a limit from a table of values

Estimate limx→2 (x²−4)/(x−2).

Step 1 — try direct substitution first

Plugging in \(x=2\) gives \(\dfrac{2^2-4}{2-2} = \dfrac{0}{0}\) — undefined. Direct evaluation fails. That does not mean the limit fails; it means we need another approach. (Chapter 5 gives the algebraic shortcut for exactly this situation — for now, we estimate.)

Step 2 — approach from the left (x < 2)
x f(x)
1.93.9
1.993.99
1.9993.999

From the left, f(x) is climbing steadily toward 4.

Step 3 — approach from the right (x > 2)
x f(x)
2.14.1
2.014.01
2.0014.001

From the right, f(x) is descending steadily toward 4 as well.

Result

Both sides converge on the same number: \(\displaystyle\lim_{x\to2}\frac{x^2-4}{x-2} = 4\) — even though \(f(2)\) itself is undefined. The function has no value at \(x=2\) (it's literally \(0/0\) there), but it absolutely has a limit there. That gap between "what f does at 2" and "what f approaches near 2" is not a flaw in the problem — it's the entire point of this chapter.

Common mistake

Assuming a limit requires f(a) to be defined, or that limx→a f(x) must equal f(a) whenever both exist. Neither is true in general. The worked example above is the cleanest possible counterexample to the first assumption: f(2) doesn't exist, and the limit exists anyway and equals 4. The second assumption — that when both do exist they must match — is also false in general (a function can have a limit at a point that differs from its actual value there); the special case where they do always agree gets its own name, continuity, and that's the entire subject of Chapter 8. Until then, keep "the value of f at a" and "the limit of f as x approaches a" as two separate questions in your head, even when their answers happen to coincide.

Practice

  1. Evaluate limx→1 (2x+3) (this function has no gap — direct substitution is fine here).
    \(5\)
  2. Does (x-1)/(x-1) have a limit as x→1? What is it? (Think about what the expression equals for any x≠1.)
    Yes — for every \(x\neq1\), \(\frac{x-1}{x-1}=1\), so the limit is \(1\), even though the expression itself is undefined (\(0/0\)) exactly at \(x=1\).
  3. True or false: if f(3) is undefined, then limx→3 f(x) cannot exist. Justify your answer.
    False — the worked example is a direct counterexample. The limit only depends on values near 3, never on the value at 3.
  4. For the constant function f(x) = 5, what is limx→10 f(x)?
    \(5\) — a constant function's output never changes, so it "approaches" the same constant everywhere.
  5. Using the same reasoning as the worked example, evaluate limx→4 (x²−16)/(x−4) (simplify the expression for x≠4 first, rather than building a full table).
    For \(x\neq4\), \(\frac{x^2-16}{x-4}=\frac{(x-4)(x+4)}{x-4}=x+4\), which approaches \(8\) as \(x\to4\). So the limit is \(8\).
  6. In your own words, explain the difference between the questions "f(a) = ?" and "limx→a f(x) = ?."
    "\(f(a)\)" asks for the function's actual output when you plug in exactly \(a\) — a single evaluation. "\(\lim_{x\to a}f(x)\)" asks what value \(f(x)\) is trending toward as \(x\) sweeps in from both sides of \(a\), without ever actually reaching or using \(x=a\) itself. They can agree or disagree, and either one can exist without the other.
  7. bonus — Does limx→a f(x) require that a be in the domain of f?
    No — the worked example's \(a=2\) is not in the domain of \(f(x)=(x^2-4)/(x-2)\) at all, and the limit exists there anyway.
  8. bonus — For g(x) = (x²−1)/(x+1), what is limx→−1 g(x)? (Simplify first, same idea as problem 5.)
    \(\frac{(x-1)(x+1)}{x+1}=x-1\) for \(x\neq-1\), which approaches \(-2\). So the limit is \(-2\).
  9. bonus — If two functions agree everywhere except at x=a, do they necessarily have the same limit as x→a?
    Yes — the limit only depends on values near \(a\), never the value at \(a\) itself, so disagreeing at that single point changes nothing about the limit.
  10. bonus — Estimate limx→5 (x²−25)/(x−5) by listing at least two x-values approaching 5 from each side and the corresponding f(x) values.
    E.g. \(x=4.9\to f(x)=9.9\), \(x=4.99\to9.99\) from the left; \(x=5.1\to10.1\), \(x=5.01\to10.01\) from the right. Both sides trend to \(10\), so the limit is \(10\).
  11. challenge — Construct your own example of a function f and a point a where f(a) is undefined but limx→a f(x) clearly exists. Explain how you know the limit exists without ever evaluating at a.
    One example: \(f(x)=\dfrac{x^2-9}{x-3}\) at \(a=3\). \(f(3)\) is \(0/0\), undefined. But for every \(x\neq3\), \(f(x)=x+3\), a plain line with no gap — so as \(x\) sweeps toward 3 from either side, \(f(x)\) sweeps toward \(6\), regardless of the fact that \(x=3\) itself is never actually plugged in.
