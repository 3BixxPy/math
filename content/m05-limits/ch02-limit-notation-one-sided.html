Limit Notation & One-Sided Limits

Chapter 1 built the intuition informally with tables. This chapter adds notation precise enough to talk about approaching from just one side — essential the moment a function behaves differently on the left than on the right, exactly like Module 1's piecewise functions.

Why this matters

So far "approaching a" meant sweeping in from both directions at once and asking if they agree. Most functions don't care which side you approach from — but some genuinely do, and a limit statement needs a way to say precisely which side is meant. That's all one-sided notation is: a way to ask "what happens just to the left of a?" and "what happens just to the right of a?" as two separate, answerable questions, before ever combining them back into a single two-sided answer.

Definition — One-sided limits

The left-hand limit, written limx→a⁻ f(x), is the value f(x) approaches as x approaches a using only values less than a (from the left). The right-hand limit, written limx→a⁺ f(x), is the value f(x) approaches using only values greater than a (from the right). The small ⁻ and ⁺ are not exponents — they're a compact way of saying "from below" and "from above."

Theorem — Existence of the two-sided limit
\[ \lim_{x\to a} f(x) = L \iff \lim_{x\to a^-} f(x) = \lim_{x\to a^+} f(x) = L \]
(5.2.1)

The ordinary (two-sided) limit exists exactly when both one-sided limits exist and agree. If either one-sided limit fails to exist, or they exist but disagree, the two-sided limit does not exist — full stop, regardless of what either side individually does.

Worked example — one-sided limits of a piecewise function

For f(x) = {x+1 if x<2; x²−3 if x≥2} (Module 1, Chapter 9's notation), find both one-sided limits at x=2 and determine whether limx→2 f(x) exists.

Step 1 — left-hand limit: which piece applies as x→2⁻?

Values just below 2 satisfy \(x<2\), so use the first piece: \(x+1\). As \(x\to2^-\), \(x+1\to3\). So \(\lim_{x\to2^-}f(x)=3\).

Step 2 — right-hand limit: which piece applies as x→2⁺?

Values just above 2 satisfy \(x\geq2\), so use the second piece: \(x^2-3\). As \(x\to2^+\), \(x^2-3\to4-3=1\). So \(\lim_{x\to2^+}f(x)=1\).

Step 3 — compare

\(3\neq1\). By (5.2.1), the two one-sided limits disagree, so \(\lim_{x\to2}f(x)\) does not exist.

A note on f(2) itself

By the piecewise rule, \(f(2)=2^2-3=1\) (the \(\geq2\) piece owns the boundary — Module 1, Chapter 9). That value happens to match the right-hand limit here, but notice it was completely irrelevant to answering "does the limit exist?" — the existence question is only ever about the two one-sided limits agreeing with each other, never about the actual defined value at the point.

Common mistake

Computing only one side — say, the left-hand limit — and reporting it as "the limit," without ever checking the other side. limx→a⁻ f(x) and limx→a f(x) are different statements with different symbols for a reason. Whenever a function's rule could plausibly change near the point in question (a piecewise breakpoint, an absolute value, anywhere the graph might have a corner or a break), check both sides before ever writing the two-sided limit down.

Try it yourself

For h(x) = {x if x<0; x+2 if x≥0}, does limx→0 h(x) exist? (yes/no)

Practice

Using f(x) = {x+1 if x<2; x²−3 if x≥2} from the worked example for problems 1–3:

  1. Find limx→2⁻ f(x).
    \(3\)
  2. Find limx→2⁺ f(x).
    \(1\)
  3. Does limx→2 f(x) exist?
    No — the one-sided limits disagree (\(3\neq1\)).
  4. For g(x) = {3x if x≤1; x+4 if x>1}, find limx→1⁻ g(x).
    \(3(1)=3\)
  5. For the same g, find limx→1⁺ g(x).
    \(1+4=5\)
  6. For the same g, does limx→1 g(x) exist? Why or why not?
    No — \(3\neq5\), so the one-sided limits disagree.
  7. bonus — For k(x) = {x² if x<0; x if x≥0}, find both one-sided limits at x=0 and state whether the two-sided limit exists.
    Left: \(x^2\to0\). Right: \(x\to0\). Both equal 0, so \(\lim_{x\to0}k(x)=0\) exists.
  8. bonus — In words, describe what the graph looks like near x=a when the left-hand and right-hand limits disagree.
    A jump or break — the graph "teleports" from one height to a different height right at \(x=a\), instead of approaching a single height from both sides.
  9. bonus — True or false: if limx→a⁻ f(x) exists and limx→a⁺ f(x) exists, then limx→a f(x) automatically exists too.
    False — both existing is necessary but not sufficient; by (5.2.1) they must also be equal.
  10. bonus — For m(x) = 5 everywhere except m(3)=9, find limx→3⁻ m(x), limx→3⁺ m(x), and limx→3 m(x).
    Both one-sided limits are \(5\) (the single point \(x=3\) never gets used while approaching), so the two-sided limit is also \(5\) — \(m(3)=9\) is simply irrelevant, same lesson as Chapter 1.
  11. challenge — Construct a piecewise function with a breakpoint at x=1 where both one-sided limits exist, are unequal, and f(1) itself equals neither of them. Explain why that's possible.
    E.g. \(f(x) = \{x \text{ if } x<1;\ x+10 \text{ if } x>1;\ 100 \text{ if } x=1\}\). Left-hand limit \(\to1\), right-hand limit \(\to11\), and \(f(1)=100\) — matching neither. This is possible because the two-sided limit doesn't exist here anyway (\(1\neq11\)), so there's no constraint at all forcing \(f(1)\) to equal a limit that was never going to exist in the first place; \(f(a)\) and the limit are simply independent pieces of information (Chapter 1).
