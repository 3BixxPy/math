Chapter 3 · concept:nonexistent-limits

Three Ways a Limit Can Fail to Exist

Chapter 2 showed one way a limit can fail to exist — disagreeing one-sided limits. This chapter finishes the list. There are exactly two more distinct failure modes, so from here on "the limit doesn't exist" always means one specific thing out of exactly three.

Why this matters

"The limit doesn't exist" sounds like a dead end, but it's actually specific, useful information about how a function is misbehaving near a point — and each of the three ways looks completely different on a graph and calls for a different response later. Being able to name which one you're looking at (a jump, a blow-up, or an oscillation) is exactly the skill Chapter 9 needs to classify discontinuities, and Chapter 7 needs to handle infinite limits precisely instead of just waving at "no."

Rule — The three failure modes
  • Disagreement — the left-hand and right-hand limits both exist as ordinary numbers, but aren't equal (a jump). This is exactly Chapter 2's case.
  • Unbounded behavior — f(x) grows without bound (toward +∞ or −∞) as x approaches a from one or both sides, instead of settling near any finite number. Chapter 7 gives this its own careful notation.
  • Oscillation — f(x) stays bounded (it doesn't blow up) but never settles down at all, swinging between different values infinitely often as x→a. The standard example is sin(1/x) as x→0: as x shrinks toward 0, 1/x grows without bound, so sin(1/x) keeps cycling through every value between −1 and 1 over and over, faster and faster, forever — it never approaches any single number.

Every function with limx→a f(x) failing to exist fails for exactly one of these three reasons.

Worked example — classify the failure mode

For each function, decide which of the three failure modes (if any) applies as x approaches the given point.

(a) f(x) = 1/(x−1)² as x→1

As \(x\to1\) from either side, \((x-1)^2\) is a tiny positive number, so \(1/(x-1)^2\) grows without bound — from both sides. This is unbounded behavior.

(b) g(x) = {x if x<0; x+3 if x≥0} as x→0

Left-hand limit \(\to0\); right-hand limit \(\to3\). Both are ordinary finite numbers, but they disagree. This is disagreement (a jump) — Chapter 2's case.

(c) h(x) = sin(1/x) as x→0

\(h(x)\) never leaves the range \([-1,1]\) — it doesn't blow up — but as \(x\to0\), \(1/x\) races off toward \(\pm\infty\), so \(\sin(1/x)\) cycles through every value in \([-1,1]\) infinitely many times, with no tendency to settle near any particular one. This is oscillation.

Common mistake

Treating "the limit is infinity" as though the limit exists in the ordinary sense, just with an unusual value. It doesn't. When we write something like limx→1 1/(x−1)² = ∞, that's shorthand for "the function grows without bound" — ∞ is not a number the function actually reaches or settles near, so strictly speaking this limit still doesn't exist; the "=∞" is a convention describing which way it fails, not a genuine numeric answer. Chapter 7 makes this notation precise and explains exactly what it is and isn't allowed to mean.

Try it yourself

Which failure mode applies to f(x) = 1/(x−4) as x→4?

Practice

  1. Classify: f(x) = 1/(x−2)² as x→2.
    Unbounded — both sides grow toward \(+\infty\).
  2. Classify: g(x) = {2x if x≤0; x+5 if x>0} as x→0.
    Disagreement (jump) — left-hand \(\to0\), right-hand \(\to5\).
  3. Classify: h(x) = cos(1/x) as x→0.
    Oscillation — same reasoning as \(\sin(1/x)\): stays bounded in \([-1,1]\) but cycles infinitely often with no settling value.
  4. Classify: k(x) = {x² if x<3; x²+1 if x≥3} as x→3.
    Disagreement (jump) — left-hand \(\to9\), right-hand \(\to10\).
  5. Classify: f(x) = 1/(x+1) as x→−1.
    Unbounded — one side \(\to+\infty\), the other \(\to-\infty\).
  6. True or false, with justification: "sin(1/x) as x→0 is unbounded, so it fits the 'unbounded' case, not oscillation."
    False. \(\sin(1/x)\) never leaves \([-1,1]\) — it never blows up. The failure is that it cycles through that bounded range infinitely often without settling, which is specifically the oscillation case, not the unbounded one.
  7. bonus — Classify: f(x) = |x|/x as x→0. (Consider what this equals for x>0 versus x<0 separately.)
    Disagreement (jump) — for \(x>0\), \(|x|/x=1\); for \(x<0\), \(|x|/x=-1\). Left-hand limit \(-1\), right-hand limit \(1\); both finite but unequal.
  8. bonus — Can a function fail to have a limit at a point for two of the three reasons at once? Explain your reasoning.
    No, not in a meaningful sense — at a given point, the behavior is either (both one-sided limits finite but unequal), (at least one side unbounded), or (bounded but never settling). These three descriptions of "how it fails" are mutually exclusive ways of characterizing the same single failure, so exactly one applies at any one point.
  9. bonus — Classify: f(x) = 1/x as x→0 (consider both sides).
    Unbounded — left-hand \(\to-\infty\), right-hand \(\to+\infty\).
  10. bonus — A graph has a single missing point (a hole) at x=5 but otherwise looks like a smooth, ordinary curve there. Does limx→5 f(x) exist? Does any of the three failure modes apply?
    The limit does exist, equal to the height where the hole sits — none of the three failure modes applies. A single missing point doesn't stop the nearby values from converging (Chapter 1); this case gets its own name, a "removable" gap, in Chapter 9.
  11. challenge — For each of the three failure modes, invent your own one-line example function (different from every example already used in this chapter) that demonstrates it, and briefly justify each classification.
    Answers vary. E.g. disagreement: \(f(x)=\{x-1 \text{ if } x<2;\ x+1 \text{ if } x\geq2\}\) at \(x=2\) (left\(\to1\), right\(\to3\)). Unbounded: \(f(x)=1/(x-5)^2\) at \(x=5\) (grows to \(+\infty\) both sides). Oscillation: \(f(x)=\cos(1/x)\) at \(x=0\) (bounded in \([-1,1]\), cycles forever without settling).
