Chapter 10 · concept:squeeze-theorem

The Squeeze Theorem

Every technique so far needed to actually manipulate f — factor it, rationalize it, divide it by a power of x. This one proves a limit exists, and pins down its exact value, without ever directly simplifying f at all, by trapping it between two functions you already know how to handle.

Why this matters

If a quantity is always sandwiched between two other quantities that both converge to the same place, it has no room to go anywhere else — it's forced to converge there too, whether or not you can say anything else about it directly. This is a genuinely new kind of argument in this module: an indirect one. Chapter 11's two essential trig limits — which become the literal foundation of every derivative involving sine and cosine in Module 6 — exist specifically because sin(x)/x can't be factored or rationalized into anything simpler, and this theorem is the only tool in this module that can still pin it down.

Theorem — The Squeeze Theorem
\[ \text{If } g(x)\le f(x)\le h(x) \text{ near } a \text{ (except possibly at } a\text{ itself), and } \lim_{x\to a}g(x)=\lim_{x\to a}h(x)=L,\ \text{then}\ \lim_{x\to a}f(x)=L. \]
(5.10.1)

Both bounding functions have to converge to the exact same value L — that's what leaves f nowhere else to go.

Worked example — the classic squeeze

Evaluate limx→0 x²sin(1/x). (Direct substitution and factoring are both useless here — sin(1/x) doesn't even have a limit at x=0, Chapter 3.)

Step 1 — bound sin(1/x)

For every \(x\neq0\), \(-1\le\sin(1/x)\le1\) — sine is always between \(-1\) and \(1\), no matter what's inside it.

Step 2 — multiply through by x² (safe, since x²≥0 never flips an inequality)

\(-x^2 \le x^2\sin(1/x) \le x^2\)

Step 3 — evaluate the two bounding limits

\(\lim_{x\to0}(-x^2)=0\) and \(\lim_{x\to0}x^2=0\) — both are ordinary polynomial limits, direct substitution (Chapter 4).

Result

Both bounds squeeze to \(0\), so by (5.10.1), \(\lim_{x\to0}x^2\sin(1/x)=0\) — even though \(\sin(1/x)\) itself oscillates infinitely and never settles anywhere as \(x\to0\). The \(x^2\) factor shrinks the oscillation's amplitude down to nothing, and the squeeze theorem is precisely the tool that turns that intuition into a proof.

x²sin(1/x) ±x² (the squeeze)

The wild oscillation is squeezed flatter and flatter as it nears x=0, trapped between the two smooth bounds — with nowhere left to go but 0.

Common mistake

Trying to apply the theorem with bounding functions that don't actually converge to the same limit at the point in question. For example, bounding some f(x) between 0 and x+1 near x=0 gives bounds converging to 0 and 1 respectively — different values — so (5.10.1) simply doesn't apply, and no conclusion about f's limit can be drawn from it. Both bounds converging to the same L isn't a technicality; it's the entire mechanism that traps f.

Try it yourself

If −x⁴ ≤ f(x) ≤ x⁴ for all x near 0, what is limx→0 f(x)?

Practice

  1. If 2−x² ≤ f(x) ≤ 2+x² near x=0, find limx→0 f(x).
    Both bounds \(\to2\), so the limit is \(2\).
  2. If −|x| ≤ g(x) ≤ |x| near x=0, find limx→0 g(x).
    Both bounds \(\to0\), so the limit is \(0\).
  3. Given −1≤cos(x)≤1 for all x, state a squeeze bound for x²cos(x) and use it to find limx→0 x²cos(x).
    Bounds: \(-x^2\le x^2\cos(x)\le x^2\); both \(\to0\), so the limit is \(0\).
  4. Explain why limx→0 sin(1/x) (without the x² factor) can not be evaluated with the squeeze theorem using bounds −1 and 1.
    Because \(-1\) and \(1\) are constants that "converge" to two different values (\(-1\) and \(1\)) as \(x\to0\), not the same \(L\) — the squeeze theorem's hypothesis requires both bounds to converge to one common value, which fails here.
  5. If 5x−1 ≤ h(x) ≤ 5x+1 near x=3, find limx→3 h(x).
    Both bounds \(\to14\), so the limit is \(14\).
  6. True or false: the squeeze theorem can prove a limit exists even when you can't directly evaluate or simplify the function in the middle.
    True — that's exactly its purpose, as in the \(x^2\sin(1/x)\) worked example.
  7. bonus — If −x² ≤ k(x)−3 ≤ x² near x=0, find limx→0 k(x). (Add 3 through the whole inequality first.)
    \(3-x^2\le k(x)\le3+x^2\); both bounds \(\to3\), so the limit is \(3\).
  8. bonus — Find limx→0 x⁴sin(1/x²) using the same squeeze idea as the worked example (state your bounding functions).
    Bounds \(-x^4\le x^4\sin(1/x^2)\le x^4\); both \(\to0\), so the limit is \(0\).
  9. bonus — Why must the inequality g(x)≤f(x)≤h(x) only hold "near a," not necessarily everywhere?
    A limit is only ever about behavior near \(a\) (Chapter 1) — whatever happens far away from \(a\) is irrelevant to whether the limit at \(a\) is squeezed correctly.
  10. bonus — If you only know g(x)≤f(x) near a and limx→a g(x)=5, with no upper bound at all, can you conclude limx→a f(x)=5?
    No — a lower bound alone only tells you that the limit, if it exists, is at least \(5\); you need both a matching lower and upper bound converging to the same value to pin the limit down exactly.
  11. challenge — Prove informally that limx→0 x·sin(1/x) = 0 by constructing a squeeze with different bounding functions than the x² example, and explain why an extra power of x wasn't actually necessary here.
    Since \(|\sin(1/x)|\le1\), multiplying by \(|x|\) gives \(-|x|\le x\sin(1/x)\le|x|\); both bounds \(\to0\) as \(x\to0\), so by the squeeze theorem the limit is \(0\). Only one factor of \(x\) is needed here because \(x\sin(1/x)\) already has just one factor of \(x\) multiplying a bounded quantity — the \(x^2\) in the earlier example was needed there because that problem had two factors of \(x\) built in, not because squeezing inherently requires a squared bound.
