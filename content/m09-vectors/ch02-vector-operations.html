Vector Addition, Subtraction & Scalar Multiplication

Chapter 1 gave vectors a precise notation. This chapter gives them arithmetic — and it's arithmetic you've already run millions of times, once per frame, inside a game loop.

Why this matters

Every physics-driven game loop runs a line that looks like position += velocity * deltaTime;. That single line is both operations in this chapter at once: scalar multiplication (stretching velocity by the small number deltaTime) followed by vector addition (adding the result onto position). A negative scalar — -velocity, or an impulse applied "backward" for knockback — reverses a vector's direction without changing its line of action. And "walk this displacement, then walk that one" — a patrol route, a multi-hit combo's total knockback, two forces acting on a body — is exactly vector addition, tip to tail.

Rule — component-wise addition and subtraction
\[ \langle u_1,u_2,\dots,u_n\rangle \pm \langle v_1,v_2,\dots,v_n\rangle \;=\; \langle u_1 \pm v_1,\ u_2 \pm v_2,\ \dots,\ u_n \pm v_n\rangle \]
(9.2.1)

Add or subtract matching components — first with first, second with second, and so on. Both vectors must have the same dimension; there's no "matching partner" for a component otherwise, exactly why a compiler refuses to compile Vector2 + Vector3.

Rule — scalar multiplication
\[ k\langle v_1,v_2,\dots,v_n\rangle \;=\; \langle kv_1,\ kv_2,\ \dots,\ kv_n\rangle \]
(9.2.2)

Multiply every component by the same number \(k\) (a scalar — an ordinary real number, as opposed to a vector). Geometrically, \(k\) stretches the vector when \(|k|>1\), shrinks it when \(0<|k|<1\), and flips its direction entirely when \(k\) is negative — the vector's line stays the same, but it now points the opposite way. This is exactly what -velocity or a knockback force scaled by -2 does.

u = ⟨3,1⟩, v = ⟨2,3⟩ → u + v = ⟨5,4⟩

Blue: \(u=\langle3,1\rangle\) (fixed). Green: \(v\) drawn tip-to-tail onto the end of \(u\) — this is "walk \(u\), then walk \(v\)." Faint dashed: \(v\) drawn from the origin instead — same vector, different starting point, exactly Chapter 1's lesson. Purple: the resultant \(u+v\), straight from the origin to \(v\)'s final tip.

Worked example — addition and scalar multiplication

Compute \(\langle 2,3\rangle + \langle -1,4\rangle\), then compute \(-2\langle 1,1\rangle\).

Step 1 — add component-wise (equation 9.2.1)

\(\langle 2,3\rangle + \langle -1,4\rangle = \langle 2+(-1),\ 3+4\rangle = \langle 1,7\rangle\)

Step 2 — scalar-multiply component-wise (equation 9.2.2)

\(-2\langle 1,1\rangle = \langle -2(1),\ -2(1)\rangle = \langle -2,-2\rangle\) — same line through the origin as \(\langle1,1\rangle\), twice as long, pointing the opposite way.

Result

\(\langle 2,3\rangle + \langle -1,4\rangle = \langle1,7\rangle\), and \(-2\langle1,1\rangle = \langle-2,-2\rangle\).

Common mistake

Two related errors show up constantly here. First: trying to add vectors of different dimensions (a Vector2 and a Vector3) — there's no rule for it, because there's no third component on one side to add to. Second, and sneakier: adding two vectors' magnitudes instead of their components, e.g. assuming a \(3\)-long vector plus a \(4\)-long vector must give a \(7\)-long vector. It doesn't, unless they point the exact same direction — direction matters, and equation 9.2.1 only ever combines matching components, never lengths directly. (Chapter 3 makes this precise once magnitude has a formula.)

Try it yourself

Compute \(\langle1,2\rangle + \langle3,-1\rangle\).

Practice

  1. Compute \(\langle5,-2\rangle + \langle1,1\rangle\).
    \(\langle6,-1\rangle\)
  2. Compute \(\langle3,4\rangle - \langle1,4\rangle\).
    \(\langle2,0\rangle\)
  3. Compute \(3\langle2,-1\rangle\).
    \(\langle6,-3\rangle\)
  4. Compute \(-\langle4,-2\rangle\).
    \(\langle-4,2\rangle\) — same length, reversed direction.
  5. Compute \(\langle1,0,2\rangle + \langle-3,5,1\rangle\).
    \(\langle-2,5,3\rangle\)
  6. An NPC's patrol moves it by \(\langle4,0\rangle\), then by \(\langle0,3\rangle\). What single displacement takes it directly from start to end?
    \(\langle4,0\rangle+\langle0,3\rangle=\langle4,3\rangle\) — the tip-to-tail sum.
  7. bonus — Explain why \(\langle1,2\rangle + \langle1,2,3\rangle\) is undefined, in terms of what a compiler would say about Vector2 + Vector3.
    Different dimensions have no matching third component to add on the 2D side — equation 9.2.1 requires both vectors to have the same number of components, same reason the types don't unify in code.
  8. bonus — A velocity of \(\langle2,0\rangle\) m/s is applied for one frame with \(\Delta t = 0.1\)s. What displacement is added to position this frame?
    \(0.1\langle2,0\rangle = \langle0.2,0\rangle\)
  9. bonus — Find one pair of vectors where \(|u|+|v| = |u+v|\), and one pair where it's false.
    True when \(u,v\) point the same way, e.g. \(u=\langle1,0\rangle,\ v=\langle2,0\rangle\): both sides equal 3. False in general, e.g. \(u=\langle1,0\rangle,\ v=\langle0,1\rangle\): \(|u|+|v|=2\) but \(|u+v|=\sqrt2\).
  10. bonus — Compute \(0\cdot\langle5,-3\rangle\). What is the result for any vector multiplied by the scalar 0?
    \(\langle0,0\rangle\) — the zero vector, always, regardless of which vector was multiplied.
  11. challenge — A ship at the origin applies displacement \(\langle3,4\rangle\), then applies a second displacement equal to exactly twice the reverse of the first. Write this as one combined vector expression, then find where the ship ends up.
    \(\langle3,4\rangle + 2\big({-}\langle3,4\rangle\big) = \langle3,4\rangle - 2\langle3,4\rangle = -\langle3,4\rangle = \langle-3,-4\rangle\). Net effect: as if it had only ever traveled backward once from the origin.
