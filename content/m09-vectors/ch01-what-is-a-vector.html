Chapter 1 · concept:vector-definition

What Is a Vector?

Module 8's capstone closed out Calculus I. This is a genuinely different branch of math — and, unlike every earlier module, it isn't starting from zero: the diagnostic that shaped this whole curriculum flagged real, working vector intuition from years of 3D game-dev code and physics. Module 9's job isn't to teach you what a vector is. You already know that. Its job is to attach the formal notation and rigor to something you've been computing correctly for a long time.

Why this matters

You've written this line more times than you can count: Vector2 dir = new Vector2(3, 4); or transform.position += velocity * Time.deltaTime;. Every time you did, you were using a vector — something with a magnitude (how much) and a direction (which way), packed into a small list of numbers. A movement vector, a velocity, a direction the camera is facing, the offset from the player to an enemy — all vectors, all along. This module gives that object a name, a precise definition, and a set of operations you can prove things about instead of just calling library functions on. The formal notation is new; the underlying idea has been sitting in your muscle memory the whole time.

Definition — Vector (component form)

A vector in \(n\) dimensions is an ordered list of \(n\) real numbers, written in component form using angle brackets:

\(\vec v = \langle v_1,\ v_2,\ \dots,\ v_n \rangle\)

In 2D that's \(\langle v_1, v_2\rangle\) — exactly a Vector2's (x, y). In 3D it's \(\langle v_1, v_2, v_3\rangle\) — exactly a Vector3's (x, y, z). The number of components (the dimension) is fixed for a given vector — you can't add a 2D vector to a 3D one, any more than a compiler would let you add a Vector2 to a Vector3 without an explicit cast.

The single most important fact about a vector: it has no fixed location. A vector only records "how far in each direction" — it can be drawn starting at the origin, at a game object's current position, at the tip of another vector, anywhere at all, and it's still the same vector as long as its components don't change. This is exactly why calling velocity a "vector" makes sense even though the object it's attached to is constantly moving to a new position — the velocity vector itself doesn't care where the object currently is.

Definition — Vector vs. point

A point like \((3,4)\) is a fixed location — one specific spot in space, written with parentheses. A vector like \(\langle 3,4\rangle\) is a displacement — "3 right, 4 up from wherever you start it," written with angle brackets. They use the same two numbers and look almost identical on paper, which is exactly why this chapter exists: keeping the notation distinct (parentheses for points, angle brackets for vectors) is what keeps the two ideas from blurring together, in math and in code alike. A game object's transform.position is stored as a Vector3, but conceptually it's playing the role of a position vector — a vector drawn from the origin whose tip happens to sit at a specific point. That's the one case where "point" and "vector" are two views of the same numbers; every other vector (a direction, a velocity, an offset) has no such fixed anchor.

\[ \overrightarrow{PQ} \;=\; Q - P \;=\; \langle q_1-p_1,\ q_2-p_2,\ \dots,\ q_n-p_n\rangle \]
(9.1.1)

Equation 9.1.1 is the vector from point \(P\) to point \(Q\): subtract the tail point's coordinates from the head point's coordinates, component by component — head minus tail, always in that order. This is exactly target.position - transform.position, the line of code behind essentially every "face the enemy," "move toward the objective," or "aim at the cursor" behavior you've ever written.

Worked example — the vector between two points

Find the vector from \(A = (-2, 3)\) to \(B = (4, -1)\).

Step 1 — identify which point is the tail and which is the head

"From \(A\) to \(B\)" means \(A\) is the tail (start) and \(B\) is the head (end) — same convention as target - current: the thing you're subtracting is where you currently are.

Step 2 — apply equation 9.1.1: head minus tail, component-wise

\(\overrightarrow{AB} = B - A = \langle 4-(-2),\ -1-3\rangle = \langle 6,\ -4\rangle\)

Result

\(\overrightarrow{AB} = \langle 6, -4\rangle\) — from \(A\), go 6 right and 4 down to land exactly on \(B\). Note this says nothing about where \(A\) or \(B\) actually are; the same displacement \(\langle 6,-4\rangle\) would carry any starting point 6 right and 4 down.

Common mistake

Treating \(\langle 3,4\rangle\) as "the point \((3,4)\)" instead of "a displacement of 3 right, 4 up from wherever you start it." This is the exact bug behind a certain class of game-dev glitch: adding a direction vector directly to a UI element's absolute screen position, or accidentally treating a Vector3 that represents a relative offset (like an attack range or a spawn offset) as if it were an absolute world position. The numbers are identical; the meaning is not. Before doing anything with a vector, ask: is this a location, or a "how far and which way"? Angle brackets vs. parentheses is the notation's way of forcing that question.

Try it yourself

Find the vector from point \((1,2)\) to point \((4,6)\).

Practice

  1. Find the vector from point \((0,0)\) to point \((5,-2)\).
    \(\langle 5,-2\rangle\)
  2. Find the vector from point \((3,3)\) to point \((1,1)\).
    \(\langle -2,-2\rangle\) — pointing back toward the origin.
  3. Let \(A=(2,-1)\), \(B=(2,4)\). Find \(\overrightarrow{AB}\).
    \(\langle 0,5\rangle\) — a purely vertical vector; a zero component is perfectly normal.
  4. The pair \((0,0)\)/\((3,4)\) and the pair \((1,1)\)/\((4,5)\) both produce the same vector. Compute both and explain why that isn't a coincidence.
    Both give \(\langle 3,4\rangle\). A vector has no fixed location — sliding both points by the same amount (here, \(\langle1,1\rangle\)) doesn't change the displacement between them.
  5. In 3D, find the vector from \((1,2,3)\) to \((4,0,-1)\).
    \(\langle 3,-2,-4\rangle\) — same head-minus-tail rule, one more component.
  6. Is "the origin" a vector or a point? Is "5 units right and 2 units down" a vector or a point? Explain the difference in one sentence each.
    The origin, \((0,0)\), is a point — one fixed location. "5 units right and 2 units down" is a vector, \(\langle5,-2\rangle\) — a displacement with no location of its own until you choose where to start drawing it.
  7. bonus — A game object at position \((10,4)\) needs to end up at \((13,9)\) after exactly 5 frames of constant movement. What displacement vector should be added to its position once per frame?
    Total displacement: \(\langle 13-10,\ 9-4\rangle=\langle3,5\rangle\). Per frame: \(\langle 3,5\rangle/5=\langle0.6,1\rangle\), added once each frame.
  8. bonus — What is the vector from a point to itself, e.g. from \((2,2)\) to \((2,2)\)? What does that mean physically?
    \(\langle 0,0\rangle\), the zero vector — zero magnitude and, meaningfully, no defined direction. It represents "no displacement at all."
  9. bonus — In your own words: why is a Vector3 field storing a game object's position a special case of "vector" rather than a fully general one?
    It's a position vector — implicitly anchored to start at the origin, so its tip lands exactly on the object's location. A general vector (a velocity, an offset) carries no such anchor; it can be drawn starting anywhere and still mean the same thing.
  10. bonus — Ship 1 moves from \((0,0)\) to \((6,8)\). Ship 2 starts at \((10,10)\) and applies that exact same displacement. Where does ship 2 end up?
    Displacement is \(\langle6,8\rangle\). Applied to \((10,10)\): \((10+6,\ 10+8)=(16,18)\).
  11. challenge — Quadrilateral \(ABCD\) has \(A=(0,0)\), \(B=(4,0)\), \(C=(6,3)\), \(D=(2,3)\). Compute \(\overrightarrow{AB}\) and \(\overrightarrow{DC}\). What do you notice, and what does it tell you about the shape?
    \(\overrightarrow{AB}=B-A=\langle4,0\rangle\). \(\overrightarrow{DC}=C-D=\langle4,0\rangle\) — the exact same vector. Two opposite sides of \(ABCD\) are equal as vectors (same length, same direction), which is precisely the defining property of a parallelogram.
