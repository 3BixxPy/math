Chapter 9 · concept:vector-equation-of-a-line

Lines in Space — Vector & Parametric Form

The first eight chapters built up a full vector toolkit in isolation. Starting here, that toolkit gets used to describe actual geometric objects — starting with the simplest one: a line.

Why this matters

This is the exact math behind a raycast: start at a point \(P_0\), pick a direction \(\vec d\), and step along it — \(P_0 + \vec d\), \(P_0 + 2\vec d\), \(P_0+3\vec d\), or any fractional step in between. Every point the ray ever touches is \(P_0\) plus some multiple of \(\vec d\); nothing more is needed to describe the entire infinite line, because a line is exactly "a starting point, plus every possible amount of travel in one fixed direction."

Rule — vector (parametric) equation of a line
\[ \vec r(t) \;=\; P_0 + t\,\vec d \]
(9.9.1)

where \(P_0\) is any known point on the line, \(\vec d\) is a nonzero direction vector for the line, and \(t\) is a real-number parameter — one real number in, one point in space out. As \(t\) ranges over all real numbers, \(\vec r(t)\) traces out every point on the line. \(t=0\) always gives back \(P_0\) exactly; positive \(t\) moves forward along \(\vec d\), negative \(t\) moves backward (behind the starting point — usually excluded for an actual raycast, which only wants \(t\ge0\), but mathematically part of the full line).

t = 1.00 → r(t) = (3.00, 2.00)

Line: \(P_0=(1,1)\), \(\vec d=\langle2,1\rangle\). Green: the direction vector \(\vec d\), drawn from \(P_0\). Purple: the current point \(\vec r(t)=P_0+t\vec d\) as \(t\) slides — exactly one raycast step.

Worked example — the line through two points, and where it crosses the xy-plane

Find the vector equation of the line through \(A=(1,2,-3)\) and \(B=(3,0,3)\). Then find where it crosses the xy-plane (\(z=0\)).

Step 1 — find a direction vector (Chapter 1: head minus tail)

\(\vec d = \overrightarrow{AB} = B - A = \langle3-1,\ 0-2,\ 3-(-3)\rangle = \langle2,-2,6\rangle\)

Step 2 — plug \(A\) and \(\vec d\) into equation 9.9.1

\(\vec r(t) = \langle1,2,-3\rangle + t\langle2,-2,6\rangle = \langle1+2t,\ 2-2t,\ -3+6t\rangle\)

Step 3 — set the z-component to 0 and solve for t

\(-3+6t=0 \ \Rightarrow\ t=\dfrac12\)

Result

At \(t=\frac12\): \(x=1+2(\frac12)=2\), \(y=2-2(\frac12)=1\). The line crosses the xy-plane at \((2,1,0)\).

Common mistake

Plugging a point in for \(\vec d\) instead of a direction vector — writing \(\vec r(t)=A+tB\) instead of \(\vec r(t)=A+t(B-A)\). Equation 9.9.1 needs a displacement (Chapter 1's whole distinction between vectors and points), not a location. Using a raw point as if it were a direction gives a formula that doesn't actually pass through both \(A\) and \(B\) at any two values of \(t\) — always compute \(\vec d\) as head-minus-tail first.

Try it yourself

For \(\vec r(t) = (1,0,0) + t\langle2,1,0\rangle\), find the point at \(t=2\).

Practice

  1. Write the vector equation of the line through \(P_0=(2,-1,0)\) with direction \(\vec d=\langle1,3,-2\rangle\), and find the point at \(t=2\).
    \(\vec r(t)=\langle2+t,-1+3t,-2t\rangle\); at \(t=2\): \((4,5,-4)\).
  2. Find a direction vector for the line through \(A=(0,0,0)\) and \(B=(3,3,3)\), and write \(\vec r(t)\).
    \(\vec d = B-A=\langle3,3,3\rangle\); \(\vec r(t)=\langle3t,3t,3t\rangle\). (Any nonzero scalar multiple of \(\vec d\), like \(\langle1,1,1\rangle\), describes the exact same line.)
  3. At what value of \(t\) does \(\vec r(t)=(0,0,0)+t\langle1,2,3\rangle\) reach the point \((2,4,6)\)?
    \(t=2\) — check all three components: \(1(2)=2\), \(2(2)=4\), \(3(2)=6\). All consistent, confirming the point is really on the line.
  4. Does the point \((1,1,1)\) lie on \(\vec r(t)=(0,0,0)+t\langle2,2,2\rangle\)?
    Yes, at \(t=0.5\): every component gives \(2(0.5)=1\), consistently.
  5. Find where \(\vec r(t)=(2,3,-6)+t\langle0,0,2\rangle\) crosses the xy-plane.
    \(-6+2t=0\Rightarrow t=3\). Point: \((2,3,0)\).
  6. A raycast starts at the origin with direction \(\langle0,0,-1\rangle\) (straight down). Write \(\vec r(t)\) and find where it hits the ground plane \(z=-5\).
    \(\vec r(t)=\langle0,0,-t\rangle\). Solve \(-t=-5\Rightarrow t=5\). Hit point: \((0,0,-5)\).
  7. bonus — Two different points on the same line can each serve as \(P_0\), giving equations that look different. Explain why that isn't a contradiction.
    A line is the full set of points it passes through, not a unique formula. Any point on it works as \(P_0\), and any nonzero scalar multiple of a valid direction vector works as \(\vec d\) — different-looking \((P_0,\vec d)\) pairs can trace out the identical set of points.
  8. bonus — Can \(t\) be negative in equation 9.9.1? What does a negative \(t\) represent for a raycast?
    Yes, mathematically — negative \(t\) gives points behind \(P_0\), opposite \(\vec d\)'s direction. An actual raycast usually restricts to \(t\ge0\) since it only cares about what's ahead of the ray's start.
  9. bonus — Show that \(P_0\) itself always satisfies equation 9.9.1, and name the value of \(t\) it corresponds to.
    \(\vec r(0)=P_0+0\cdot\vec d=P_0\) — always true at \(t=0\), regardless of what \(\vec d\) is.
  10. bonus — What goes wrong if \(\vec d=\langle0,0,0\rangle\) is used in equation 9.9.1?
    \(\vec r(t)=P_0\) for every \(t\) — it doesn't trace a line at all, just sits at the single point \(P_0\). A valid direction vector for a line must be nonzero.
  11. challenge — Lines \(\vec r_1(t)=(1,0,0)+t\langle1,1,0\rangle\) and \(\vec r_2(s)=(0,1,0)+s\langle1,-1,0\rangle\) — find their intersection point by setting the two forms equal and solving for \(t\) and \(s\).
    \(x\): \(1+t=s\). \(y\): \(t=1-s\). Substituting \(s=1+t\) into the second: \(t=1-(1+t)=-t\Rightarrow t=0\), so \(s=1\). Both give the point \((1,0,0)\): \(\vec r_1(0)=(1,0,0)\) and \(\vec r_2(1)=(0+1,\ 1-1,\ 0)=(1,0,0)\). ✓
