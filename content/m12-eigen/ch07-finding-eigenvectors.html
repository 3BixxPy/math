Chapter 7 · concept:finding-eigenvectors

Finding Eigenvectors

Chapter 6 found the eigenvalues. Now find the actual directions they belong to — solve the homogeneous system (A − λI)v = 0 for each one, using Module 10's Gaussian elimination.

Method — Finding eigenvectors

For each eigenvalue \(\lambda\) found from the characteristic equation (Chapter 6), substitute it back into:

\[ (A-\lambda I)v = \vec 0 \]

and solve this homogeneous system exactly like any other \(Ax=\vec0\) system (Module 10's Gaussian elimination). Its solution set is a subspace — Module 11, Chapter 10's null space, this time of \(A-\lambda I\) instead of \(A\) itself — and every nonzero vector in it is a valid eigenvector for that \(\lambda\).

  1. Substitute \(\lambda\) into \(A-\lambda I\).
  2. Row-reduce. Since \(\lambda\) was chosen precisely to make \(A-\lambda I\) singular, expect at least one free variable.
  3. Express the solution set as a span of one (or more) vectors — these span the eigenvectors for that \(\lambda\).
  4. Repeat for every eigenvalue found in Chapter 6.
Worked example

Continue the running example, \(A=\begin{bmatrix}3&-2\\2&-2\end{bmatrix}\), with eigenvalues \(\lambda=2\) and \(\lambda=-1\) from Chapter 6.

Step 1 — λ = 2

\(A-2I = \begin{bmatrix}1&-2\\2&-4\end{bmatrix}\). Row 2 minus 2×row 1 gives \(\begin{bmatrix}0&0\end{bmatrix}\), collapsing to one equation: \(x-2y=0 \Rightarrow x=2y\). Eigenvectors: \(v = t\langle2,1\rangle\) for any \(t\neq0\) — matches the exact vector verified by hand in Chapter 5.

Step 2 — λ = −1

\(A+I = \begin{bmatrix}4&-2\\2&-1\end{bmatrix}\). Row 2 is half of row 1, collapsing to \(2x-y=0 \Rightarrow y=2x\). Eigenvectors: \(v = t\langle1,2\rangle\) for any \(t\neq0\).

Result

For \(\lambda=2\): any nonzero multiple of \(\langle2,1\rangle\). For \(\lambda=-1\): any nonzero multiple of \(\langle1,2\rangle\). These two directions are the running example's "spine," reused in Chapters 8–10.

Common mistake

Reporting "the" eigenvector for a given \(\lambda\) as if it were unique. It isn't — there are infinitely many, since any nonzero scalar multiple of an eigenvector is also an eigenvector with the exact same eigenvalue. For \(\lambda=2\) above, \(\langle2,1\rangle\), \(\langle4,2\rangle\), and \(\langle-2,-1\rangle\) are all equally valid — none is "more correct" than another. It's the direction (formalized as the eigenspace, Chapter 8) that's the real invariant here, not any one specific vector.

Try it yourself

If \(v\) is an eigenvector of \(A\) with eigenvalue \(\lambda\), is \(3v\) also an eigenvector of \(A\) with the same eigenvalue?

Practice

  1. Find the eigenvector(s) of \(A=\begin{bmatrix}5&0\\0&3\end{bmatrix}\) for \(\lambda=5\).
    \((A-5I)v=0\): \(\begin{bmatrix}0&0\\0&-2\end{bmatrix}v=0 \Rightarrow y=0\), \(x\) free. Eigenvectors: \(t\langle1,0\rangle\).
  2. Find the eigenvector(s) of the same \(A=\begin{bmatrix}5&0\\0&3\end{bmatrix}\) for \(\lambda=3\).
    Eigenvectors: \(t\langle0,1\rangle\).
  3. Find the eigenvector(s) of \(A=\begin{bmatrix}2&1\\1&2\end{bmatrix}\) for \(\lambda=1\).
    \(A-I=\begin{bmatrix}1&1\\1&1\end{bmatrix} \Rightarrow x+y=0\). Eigenvectors: \(t\langle1,-1\rangle\).
  4. Find the eigenvector(s) of the same \(A=\begin{bmatrix}2&1\\1&2\end{bmatrix}\) for \(\lambda=3\).
    \(A-3I=\begin{bmatrix}-1&1\\1&-1\end{bmatrix} \Rightarrow x=y\). Eigenvectors: \(t\langle1,1\rangle\).
  5. Find the eigenvector(s) of \(A=\begin{bmatrix}1&2\\0&3\end{bmatrix}\) for \(\lambda=1\).
    \(A-I=\begin{bmatrix}0&2\\0&2\end{bmatrix} \Rightarrow y=0\), \(x\) free. Eigenvectors: \(t\langle1,0\rangle\).
  6. Find the eigenvector(s) of the same \(A=\begin{bmatrix}1&2\\0&3\end{bmatrix}\) for \(\lambda=3\).
    \(A-3I=\begin{bmatrix}-2&2\\0&0\end{bmatrix} \Rightarrow x=y\). Eigenvectors: \(t\langle1,1\rangle\).
  7. bonus — Find the eigenvector(s) of \(A=\begin{bmatrix}4&2\\1&3\end{bmatrix}\) for \(\lambda=5\) (from Chapter 6's practice).
    \(A-5I=\begin{bmatrix}-1&2\\1&-2\end{bmatrix} \Rightarrow x=2y\). Eigenvectors: \(t\langle2,1\rangle\).
  8. bonus — Find the eigenvector(s) of the same \(A=\begin{bmatrix}4&2\\1&3\end{bmatrix}\) for \(\lambda=2\).
    \(A-2I=\begin{bmatrix}2&2\\1&1\end{bmatrix} \Rightarrow x+y=0\). Eigenvectors: \(t\langle1,-1\rangle\).
  9. bonus — Is \(\langle4,2\rangle\) an eigenvector of the running example's \(A=\begin{bmatrix}3&-2\\2&-2\end{bmatrix}\)? If so, for which \(\lambda\)?
    Yes — it's a scalar multiple of \(\langle2,1\rangle\) (the worked example's eigenvector for \(\lambda=2\)), and scalar multiples always share the same eigenvalue: \(\lambda=2\).
  10. bonus — After solving \((A-\lambda I)v=0\), can \(v=\langle0,0\rangle\) ever legitimately be "the eigenvector found" for that λ?
    No — \(\vec0\) always technically solves the homogeneous system, but it's explicitly excluded from counting as an eigenvector (Chapter 5's definition requires \(v\neq\vec0\)). It's a trivial solution, never the interesting one.
  11. challenge — Suppose solving \((A-\lambda I)v=0\) for some eigenvalue \(\lambda\) produces TWO free variables instead of one. What does that say about the solution set's dimension, and what does it preview about Chapters 8 and 11?
    Two free variables means the null space of \(A-\lambda I\) is 2-dimensional — a whole plane's worth of eigenvectors for that single \(\lambda\), not just a line. This previews Chapter 8's eigenspace (which can have dimension greater than 1) and Chapter 11's repeated eigenvalues, where this is exactly the "good" outcome that still allows diagonalization.
