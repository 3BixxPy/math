Chapter 4 · concept:kernel-and-image

Kernel & Image

Two ideas you already have names for, wearing transformation-language costumes: the kernel is exactly the null space (Module 11, Chapter 10), the image is exactly the column space, and rank-nullity (Module 11, Chapter 11) already told you how their sizes trade off.

Definition — Kernel

The kernel of a linear transformation \(T\) (with standard matrix \(A\)) is the set of every vector that gets sent to the zero vector:

\[ \ker(T) = \{x : T(x) = \vec 0\} = \{x : Ax = \vec 0\} \]

This is nothing new — it's exactly the null space of \(A\) from Module 11, Chapter 10, wearing a transformation-flavored name. "Solve \(Ax=0\)" and "find \(T\)'s kernel" are literally the same computation.

Definition — Image

The image of \(T\) is the set of every vector that can actually come out of the transformation:

\[ \operatorname{im}(T) = \{T(x) : x \in \mathbb{R}^n\} = \{Ax : x \in \mathbb{R}^n\} \]

This is exactly the column space of \(A\): every output is some linear combination of \(A\)'s columns (since \(Ax\) is precisely \(x_1(\text{col }1)+\cdots+x_n(\text{col }n)\)), so the set of all possible outputs is exactly the span of \(A\)'s columns.

Rank-nullity, restated

Module 11, Chapter 11's rank-nullity theorem said \(\operatorname{rank}(A) + \operatorname{nullity}(A) = n\). In transformation language, that's:

\[ \dim(\operatorname{im}(T)) + \dim(\ker(T)) = n \]

where \(n\) is the dimension of \(T\)'s input space. Same theorem, same proof — just a reminder that "kernel/image" and "null space/column space" are the same objects under different names, so every tool from Module 11 Chapter 11 carries over unchanged.

Worked example

Let \(A=\begin{bmatrix}1&2\\2&4\end{bmatrix}\). Find \(\ker(T)\) and \(\operatorname{im}(T)\), and verify rank-nullity.

Step 1 — find the kernel: solve Ax = 0

Row 2 is exactly twice row 1, so Gaussian elimination (Module 10) collapses this to one equation: \(x+2y=0\), i.e. \(x=-2y\). Free variable \(y\): \(\ker(T) = \operatorname{span}\{\langle-2,1\rangle\}\), dimension 1.

Step 2 — find the image: span the columns

\(A\)'s columns are \(\langle1,2\rangle\) and \(\langle2,4\rangle=2\langle1,2\rangle\) — the second is a scalar multiple of the first, so together they only span a line: \(\operatorname{im}(T)=\operatorname{span}\{\langle1,2\rangle\}\), dimension 1.

Result — verify rank-nullity

\(\dim(\operatorname{im}(T))+\dim(\ker(T)) = 1+1 = 2 = n\) ✓. This matrix collapses the whole plane down onto a single line (the image) while an entire other line (the kernel) gets crushed to the origin — a very "lossy" transformation.

Common mistake

Assuming a transformation with a nontrivial kernel (containing more than just the zero vector) could still be invertible. It can't. An inverse function requires every output to trace back to exactly one input — but a nontrivial kernel means at least one nonzero vector gets sent to \(\vec 0\), the exact same place the zero vector itself goes. Two different inputs, one output: information has been permanently lost, and there's no way to invert that. This lines up exactly with Module 10, Chapter 11's determinant test: a nontrivial kernel forces \(\det(A)=0\), which is precisely the singular (non-invertible) case.

Try it yourself

If a transformation's kernel contains more than just the zero vector, is it invertible?

Practice

  1. Find the kernel of \(A=\begin{bmatrix}1&0\\0&0\end{bmatrix}\) (projection onto the x-axis).
    \(\operatorname{span}\{\langle0,1\rangle\}\) — every point on the y-axis gets crushed to the origin.
  2. Find the image of the same \(A=\begin{bmatrix}1&0\\0&0\end{bmatrix}\).
    \(\operatorname{span}\{\langle1,0\rangle\}\) — the x-axis; verify rank-nullity: \(1+1=2\) ✓.
  3. Find the kernel of \(A=\begin{bmatrix}2&4\\1&2\end{bmatrix}\).
    Row 2 is half of row 1: \(x+2y=0\Rightarrow x=-2y\). Kernel \(=\operatorname{span}\{\langle-2,1\rangle\}\).
  4. Is \(A=\begin{bmatrix}1&1\\1&1\end{bmatrix}\) invertible? Justify using its kernel.
    No. Solving \(Ax=0\) gives \(x+y=0\), so \(\ker(T)=\operatorname{span}\{\langle1,-1\rangle\}\) is nontrivial — a nontrivial kernel means \(\det(A)=0\), singular.
  5. If \(T:\mathbb{R}^3\to\mathbb{R}^2\) has a 2-dimensional kernel, what is \(\dim(\operatorname{im}(T))\)?
    \(n=3\), so \(\dim(\operatorname{im}(T)) = 3-2=1\).
  6. Find the kernel of the identity transformation \(I\).
    \(\{\vec 0\}\) only — the trivial kernel, consistent with \(I\) being invertible.
  7. bonus — If \(\dim(\ker(T))=0\) for a square matrix, is \(T\) guaranteed invertible?
    Yes — a trivial kernel means full rank, which means \(\det(A)\neq0\), which means invertible (for a square matrix).
  8. bonus — Find the image of \(A=\begin{bmatrix}1&2\\3&6\end{bmatrix}\).
    Columns \(\langle1,3\rangle\) and \(\langle2,6\rangle=2\langle1,3\rangle\) — image \(=\operatorname{span}\{\langle1,3\rangle\}\).
  9. bonus — For \(T:\mathbb{R}^4\to\mathbb{R}^3\) with a 1-dimensional kernel, find \(\dim(\operatorname{im}(T))\), and say whether \(T\) is onto (surjective).
    \(4-1=3\) — the image is all 3 dimensions of the codomain, so yes, \(T\) is onto.
  10. bonus — Can the image of a transformation \(\mathbb{R}^2\to\mathbb{R}^2\) ever be just \(\{\vec 0\}\)? What would that say about the kernel?
    Yes, if \(A\) is the zero matrix — then everything maps to \(\vec 0\), so \(\dim(\operatorname{im}(T))=0\) and by rank-nullity \(\dim(\ker(T))=2\): the kernel is the entire input space.
  11. challenge — A linear transformation \(T:\mathbb{R}^3\to\mathbb{R}^3\) has standard matrix \(A\) with \(\det(A)\neq0\). Without any further computation, what can you conclude about \(\ker(T)\) and \(\operatorname{im}(T)\), and why?
    \(\det(A)\neq0\) means \(A\) is invertible (Module 10, Chapter 11), which forces \(\ker(T)=\{\vec 0\}\) (trivial kernel — a nontrivial one would force \(\det(A)=0\), the contrapositive of this chapter's mistake block). By rank-nullity, \(\dim(\operatorname{im}(T))=3-0=3\), so the image is all of \(\mathbb{R}^3\). Together: \(T\) is a bijection — every output traces back to exactly one input.
