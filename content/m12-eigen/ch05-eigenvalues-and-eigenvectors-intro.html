Eigenvalues & Eigenvectors — The Idea

Every transformation in this module so far can rotate, stretch, reflect, or some tangled mix of all three. This chapter asks a sharper question: for a given transformation, are there any special directions it ONLY stretches — and never rotates at all?

Why this matters

Picture a transformation as deforming all of space — a physics simulation's stress tensor, a skinning matrix bending a mesh, any general linear map. Most directions get bent into some genuinely new direction. But for a huge number of transformations that actually show up in practice, there exist a couple of special axes that don't get bent — they just get longer, shorter, or flipped, while staying on the exact same line. Those special directions are eigenvectors, and the amount they get stretched by is the corresponding eigenvalue. Find them, and you've found the "spine" of a transformation — the handful of directions that describe its whole behavior, instead of needing to track what happens to every possible vector individually.

Definition — Eigenvalue & eigenvector

For a square matrix \(A\) (\(n\times n\)), a nonzero vector \(v\) is an eigenvector of \(A\) if there exists a scalar \(\lambda\) — the corresponding eigenvalue — such that:

\[ Av = \lambda v \]
(12.5.1)

Applying the transformation to \(v\) produces a vector pointing along the exact same line as \(v\) — only scaled by \(\lambda\). A negative \(\lambda\) flips \(v\) to point the opposite way but keeps it on the same line; \(\lambda=0\) is allowed too, meaning \(v\) gets sent straight to the zero vector. The vector \(v\) itself, though, is always required to be nonzero — the zero vector trivially satisfies \(A\vec0=\lambda\vec0\) for literally every \(\lambda\), which says nothing useful, so it's excluded from the definition by convention.

Worked example

Verify that \(v=\langle2,1\rangle\) is an eigenvector of \(A=\begin{bmatrix}3&-2\\2&-2\end{bmatrix}\), and find its eigenvalue. (This matrix and this eigenvector will be the running example for the next several chapters.)

Step 1 — compute Av

\(Av = \begin{bmatrix}3&-2\\2&-2\end{bmatrix}\begin{bmatrix}2\\1\end{bmatrix} = \begin{bmatrix}3(2)+(-2)(1)\\2(2)+(-2)(1)\end{bmatrix} = \begin{bmatrix}4\\2\end{bmatrix}\)

Step 2 — check whether the result is a scalar multiple of v

\(\langle4,2\rangle = 2\cdot\langle2,1\rangle\) — yes, exactly a scalar multiple.

Result

\(v=\langle2,1\rangle\) is an eigenvector of \(A\), with eigenvalue \(\lambda=2\). Applying \(A\) to this particular direction just doubles it — no rotation at all.

Common mistake

Assuming every vector is an eigenvector of a given matrix. Being an eigenvector is a special property that most vectors don't have — a typical transformation rotates most directions at least a little, and only a few special ones survive unrotated. Try \(v=\langle1,0\rangle\) on the same \(A=\begin{bmatrix}3&-2\\2&-2\end{bmatrix}\) from the worked example: \(Av = \langle3,2\rangle\), which is not a scalar multiple of \(\langle1,0\rangle\) (a multiple would need a zero second coordinate, and \(2\neq0\)) — so \(\langle1,0\rangle\) is not an eigenvector of this \(A\) at all, despite looking like an equally reasonable guess.

Try it yourself

If \(Av=5v\) for some nonzero vector \(v\), what is the eigenvalue?

Practice

  1. Is \(v=\langle1,1\rangle\) an eigenvector of \(A=\begin{bmatrix}2&0\\0&2\end{bmatrix}\)? Find \(\lambda\) if so.
    \(Av=\langle2,2\rangle=2\langle1,1\rangle\) — yes, \(\lambda=2\). (In fact, a scalar matrix like this has every nonzero vector as an eigenvector, all with the same \(\lambda\) — a special case worth remembering.)
  2. Is \(v=\langle1,-1\rangle\) an eigenvector of \(A=\begin{bmatrix}0&1\\1&0\end{bmatrix}\)?
    \(Av=\langle-1,1\rangle=-1\cdot\langle1,-1\rangle\) — yes, \(\lambda=-1\).
  3. Is \(v=\langle1,1\rangle\) an eigenvector of the same \(A=\begin{bmatrix}0&1\\1&0\end{bmatrix}\)?
    \(Av=\langle1,1\rangle=1\cdot\langle1,1\rangle\) — yes, \(\lambda=1\). (This "swap" matrix has a clean geometric picture: it leaves the line \(y=x\) untouched (\(\lambda=1\)) and flips the line \(y=-x\) (\(\lambda=-1\)).)
  4. Is \(v=\langle1,2\rangle\) an eigenvector of \(A=\begin{bmatrix}4&0\\0&7\end{bmatrix}\)?
    \(Av=\langle4,14\rangle\). For this to be a multiple of \(\langle1,2\rangle\) the scalar would need to be both 4 (from the first coordinate) and 7 (from the second) — contradiction. No.
  5. Is \(v=\langle1,0\rangle\) an eigenvector of \(A=\begin{bmatrix}4&0\\0&7\end{bmatrix}\)?
    \(Av=\langle4,0\rangle=4\langle1,0\rangle\) — yes, \(\lambda=4\).
  6. Is \(v=\langle3,0\rangle\) an eigenvector of the same \(A=\begin{bmatrix}4&0\\0&7\end{bmatrix}\)?
    \(Av=\langle12,0\rangle=4\langle3,0\rangle\) — yes, \(\lambda=4\), same eigenvalue as the previous problem (same line, so same eigenvalue).
  7. bonus — For the identity matrix \(I\), what is the eigenvalue for EVERY nonzero vector?
    \(\lambda=1\) always, since \(Iv=v=1\cdot v\) for any \(v\).
  8. bonus — If \(Av=\vec0\) for some nonzero \(v\), is \(v\) an eigenvector, and what is \(\lambda\)?
    Yes — \(\lambda=0\) is a perfectly valid eigenvalue, as long as \(v\) itself is nonzero.
  9. bonus — Is the zero vector \(\vec0\) ever itself called an eigenvector?
    No — by definition, eigenvectors must be nonzero, even though \(\vec0\) trivially satisfies \(A\vec0=\lambda\vec0\) for any \(\lambda\).
  10. bonus — Using the worked example's \(v=\langle2,1\rangle\), is it also an eigenvector of \(B=\begin{bmatrix}4&-2\\2&-1\end{bmatrix}\) (note: \(B=A+I\), adding the identity to the running example's matrix)? If so, find λ.
    \(Bv=\langle4(2)-2(1),\ 2(2)-1(1)\rangle=\langle6,3\rangle=3\langle2,1\rangle\) — yes, \(\lambda=3\). Interesting: adding \(I\) to \(A\) shifted the eigenvalue from 2 to 3 but kept the exact same eigenvector — a pattern worth noticing even before it's explained.
  11. challenge — If \(v\) is an eigenvector of \(A\) with eigenvalue \(\lambda\), prove algebraically that \(v\) is also an eigenvector of \(A^2\) (i.e. \(A\) applied twice), with eigenvalue \(\lambda^2\). (Hint: apply \(A\) to both sides of \(Av=\lambda v\).)
    Starting from \(Av=\lambda v\), apply \(A\) to both sides: \(A(Av) = A(\lambda v)\). The left side is \(A^2v\). The right side, using homogeneity (Chapter 1), is \(\lambda(Av) = \lambda(\lambda v) = \lambda^2 v\). So \(A^2v=\lambda^2v\) — \(v\) is an eigenvector of \(A^2\) with eigenvalue \(\lambda^2\). (This generalizes to any power, previewed fully in Chapter 10.)
