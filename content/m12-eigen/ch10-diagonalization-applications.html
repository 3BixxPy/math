Applications — Powers of a Matrix

Diagonalization isn't just elegant bookkeeping. It turns computing a huge power of a matrix from thousands of multiplications into three easy steps — and that shortcut is exactly how repeated transformations, applied over and over, get computed in practice.

Theorem — Matrix powers via diagonalization

If \(A=PDP^{-1}\), then for any positive integer \(k\):

\[ A^k = PD^kP^{-1} \]
(12.10.1)

where \(D^k\) just means raising each diagonal entry to the \(k\)-th power individually — no repeated matrix multiplication needed for that part at all. Quick proof by induction (Module 4): \(A^2=(PDP^{-1})(PDP^{-1})=PD(P^{-1}P)DP^{-1}=PD\cdot I\cdot DP^{-1}=PD^2P^{-1}\) — the middle \(P^{-1}P\) collapses to \(I\) and vanishes. Repeating the same collapse \(k-1\) more times gives \(A^k=PD^kP^{-1}\) for any \(k\).

Why this matters beyond the algebra: a discrete dynamical system — a population model applied year after year, or a game-world transformation applied frame after frame — computes exactly \(x_k = A^kx_0\). This theorem is the reason that's computed efficiently for large \(k\), instead of by looping the multiplication \(k\) times.

Worked example

Compute \(A^{10}\) for the running example, using Chapter 9's diagonalization: \(A=\begin{bmatrix}3&-2\\2&-2\end{bmatrix}\), \(P=\begin{bmatrix}2&1\\1&2\end{bmatrix}\), \(D=\begin{bmatrix}2&0\\0&-1\end{bmatrix}\), \(P^{-1}=\frac13\begin{bmatrix}2&-1\\-1&2\end{bmatrix}\).

Step 1 — raise D's diagonal entries to the 10th power

\(D^{10} = \begin{bmatrix}2^{10}&0\\0&(-1)^{10}\end{bmatrix} = \begin{bmatrix}1024&0\\0&1\end{bmatrix}\)

Step 2 — compute PD¹⁰ (scales each column of P)

\(PD^{10} = \begin{bmatrix}2&1\\1&2\end{bmatrix}\begin{bmatrix}1024&0\\0&1\end{bmatrix} = \begin{bmatrix}2048&1\\1024&2\end{bmatrix}\)

Step 3 — multiply by P⁻¹

\((PD^{10})P^{-1} = \dfrac13\begin{bmatrix}2048&1\\1024&2\end{bmatrix}\begin{bmatrix}2&-1\\-1&2\end{bmatrix} = \dfrac13\begin{bmatrix}4095&-2046\\2046&-1020\end{bmatrix} = \begin{bmatrix}1365&-682\\682&-340\end{bmatrix}\)

Result — verify with the trace/det trick

\(A^{10}=\begin{bmatrix}1365&-682\\682&-340\end{bmatrix}\). Check: \(\operatorname{trace}(A^{10})\) should equal \(2^{10}+(-1)^{10}=1025\); here \(1365+(-340)=1025\) ✓. \(\det(A^{10})\) should equal \(\det(A)^{10}=(-2)^{10}=1024\); here \(1365(-340)-(-682)(682)=-464100+465124=1024\) ✓. Contrast: computing \(A^{10}\) by hand via 9 successive matrix multiplications would be brutal. This shortcut took exactly 3 easy steps, and would take the same 3 steps even for \(A^{1000}\).

Common mistake

Applying the shortcut \(A^k=PD^kP^{-1}\) to a matrix that isn't actually diagonalizable in the first place. The formula requires Chapter 9's factorization to genuinely exist — skipping the diagonalizability check (\(n\) independent eigenvectors, or Chapter 11's repeated-eigenvalue failure case) and just guessing some \(P,D\) pair produces a meaningless, wrong result. Always confirm \(A=PDP^{-1}\) actually holds before using its powers.

Practice

  1. For \(D=\begin{bmatrix}4&0\\0&5\end{bmatrix}\), find \(D^3\).
    \(\begin{bmatrix}64&0\\0&125\end{bmatrix}\)
  2. Using Chapter 9's diagonalization of \(A=\begin{bmatrix}2&1\\1&2\end{bmatrix}\) (\(D=\begin{bmatrix}1&0\\0&3\end{bmatrix}\)), find \(D^2\) without recomputing any eigen-data.
    \(\begin{bmatrix}1&0\\0&9\end{bmatrix}\)
  3. Using the same data, set up (don't necessarily multiply out) \(A^2\) via the shortcut.
    \(A^2 = PD^2P^{-1} = \begin{bmatrix}1&1\\-1&1\end{bmatrix}\begin{bmatrix}1&0\\0&9\end{bmatrix}P^{-1}\)
  4. True or false: \(A^0=I\) always, using the diagonalization shortcut with \(k=0\).
    True — \(D^0=I\) (every diagonal entry raised to the 0th power is 1), so \(PD^0P^{-1}=PIP^{-1}=PP^{-1}=I\).
  5. If \(A\) is diagonalizable with eigenvalues 2 and \(\frac12\), describe qualitatively what happens to \(A^k\) as \(k\) gets very large.
    The \(\lambda=2\) direction grows without bound while the \(\lambda=\frac12\) direction shrinks toward 0 — for large \(k\), \(A^k\) behaves almost entirely like scaling along the \(\lambda=2\) eigenvector; the other direction becomes negligible.
  6. Using the already-computed \(A^{10}=\begin{bmatrix}1365&-682\\682&-340\end{bmatrix}\), predict \(A^{10}\langle2,1\rangle\) directly from the fact that \(\langle2,1\rangle\) is an eigenvector with \(\lambda=2\), then check against the matrix.
    Prediction: \(2^{10}\langle2,1\rangle=1024\langle2,1\rangle=\langle2048,1024\rangle\) (Chapter 5's challenge, generalized: eigenvectors keep scaling by \(\lambda\) each application, never changing direction). Check: \(\begin{bmatrix}1365&-682\\682&-340\end{bmatrix}\langle2,1\rangle=\langle1365(2)-682,\ 682(2)-340\rangle=\langle2048,1024\rangle\) ✓.
  7. bonus — For a scalar matrix \(A=cI\), what is \(A^k\)?
    \(c^kI\) — a trivial diagonalization case (P can be any invertible matrix, e.g. \(P=I\)).
  8. bonus — Can this shortcut also compute \(A^{-1}\) (a "negative first power")?
    Yes — \(A^{-1}=PD^{-1}P^{-1}\), as long as no eigenvalue is zero (so every diagonal entry of \(D^{-1}\) is defined). The theorem generalizes to negative integer powers too.
  9. bonus — The swap matrix \(A=\begin{bmatrix}0&1\\1&0\end{bmatrix}\) has eigenvalues 1 and −1 (Chapter 5). What is \(A^2\)?
    \(D^2=\begin{bmatrix}1&0\\0&1\end{bmatrix}=I\), so \(A^2=PIP^{-1}=PP^{-1}=I\) — squaring the swap matrix undoes itself, which makes total sense (swap twice = back to normal).
  10. bonus — In one sentence, explain why computing \(A^{100}\) directly (99 successive matrix multiplications) is impractical by hand, while \(PD^{100}P^{-1}\) is not.
    Direct multiplication needs 99 full matrix multiplications, each combining every entry; the diagonalized version needs only two numbers raised to the 100th power plus two fixed matrix multiplications, regardless of how large the exponent gets.
  11. challenge — A population model doubles an "urban" population each year (eigenvalue 2) and halves a "rural" population each year (eigenvalue ½), along two eigenvector directions describing a mixed starting population. Even if the rural (λ=½) direction starts as the large majority of the population, explain qualitatively what the makeup looks like after 20 years.
    After 20 years, \(2^{20}\) is astronomically larger than \((\frac12)^{20}\) (which is nearly 0), so the urban (\(\lambda=2\)) direction totally dominates the total, no matter how large the rural share started out — the long-run composition converges to being almost entirely along the urban eigenvector direction. This is the real payoff of diagonalization: it separates growing directions from shrinking ones and tells you which one wins in the long run, without simulating year by year.
