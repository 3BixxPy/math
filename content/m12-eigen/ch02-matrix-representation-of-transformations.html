The Standard Matrix of a Transformation

Chapter 1's challenge problem showed that every matrix gives a linear transformation. This chapter proves the converse: every linear transformation \(\mathbb{R}^n\to\mathbb{R}^m\) comes from exactly one matrix — and finding it only takes watching where two (or three, or \(n\)) vectors go.

Theorem — The standard matrix

Every linear transformation \(T:\mathbb{R}^n\to\mathbb{R}^m\) can be written as \(T(x) = Ax\) for a unique \(m\times n\) matrix \(A\), called its standard matrix. That matrix is built one column at a time: column \(i\) of \(A\) is \(T(e_i)\), the image of the \(i\)-th standard basis vector (Module 11, Chapter 7).

\[ A = \begin{bmatrix} \big| & & \big| \\ T(e_1) & \cdots & T(e_n) \\ \big| & & \big| \end{bmatrix} \]
(12.2.1)

Here's why it works: any vector \(x=\langle x_1,\dots,x_n\rangle\) can be written as \(x = x_1e_1+x_2e_2+\cdots+x_ne_n\) (Module 11, Chapter 7's basis representation — every vector is a unique combination of the standard basis vectors). Linearity (Chapter 1) then lets the transformation distribute right through that sum:

\[ T(x) = T(x_1e_1+\cdots+x_ne_n) = x_1T(e_1)+\cdots+x_nT(e_n) \]

and that last expression is exactly what matrix-vector multiplication computes when \(T(e_1),\dots,T(e_n)\) sit in the columns of \(A\). Linearity is what makes this shortcut legal — a transformation only needs to be tested on \(n\) vectors (the basis) to be known completely on all of \(\mathbb{R}^n\).

Worked example — the 90° rotation matrix

Find the standard matrix of \(T\): rotate every vector in \(\mathbb{R}^2\) by 90° counterclockwise.

Step 1 — find T(e₁), where e₁ = ⟨1,0⟩

Rotating \(\langle1,0\rangle\) (pointing right) by 90° counterclockwise lands it pointing straight up: \(T(e_1) = \langle0,1\rangle\).

Step 2 — find T(e₂), where e₂ = ⟨0,1⟩

Rotating \(\langle0,1\rangle\) (pointing up) by 90° counterclockwise lands it pointing left: \(T(e_2) = \langle-1,0\rangle\).

Result — assemble the columns

\(A = \begin{bmatrix}0&-1\\1&0\end{bmatrix}\) — first column \(T(e_1)=\langle0,1\rangle\), second column \(T(e_2)=\langle-1,0\rangle\). Check: \(A\langle1,0\rangle^T=\langle0,1\rangle\) ✓ and \(A\langle0,1\rangle^T=\langle-1,0\rangle\) ✓. This is the exact matrix behind a "rotate 90°" call in any engine's 2D transform code.

Common mistake

Building the matrix from the wrong orientation — stacking the images of the basis vectors as rows instead of columns. For the rotation above, that mistake would produce \(\begin{bmatrix}0&1\\-1&0\end{bmatrix}\) instead of the correct \(\begin{bmatrix}0&-1\\1&0\end{bmatrix}\) — and this isn't a harmless typo. Check what the wrong matrix actually does: it sends \(\langle1,0\rangle\) to \(\langle0,-1\rangle\), which is a 90° rotation clockwise — the exact opposite direction. Row-vs-column isn't bookkeeping; it silently flips which way the whole transformation turns. The rule to hold onto: images of the basis vectors are always columns of \(A\), never rows.

Practice

  1. Find the standard matrix of \(T(\langle x,y\rangle) = \langle 5x,\ -y\rangle\).
    \(\begin{bmatrix}5&0\\0&-1\end{bmatrix}\)
  2. Find the standard matrix of \(T(\langle x,y\rangle) = \langle x+y,\ x-y\rangle\).
    \(\begin{bmatrix}1&1\\1&-1\end{bmatrix}\)
  3. Find the standard matrix of reflection over the x-axis: \(T(\langle x,y\rangle)=\langle x,-y\rangle\).
    \(\begin{bmatrix}1&0\\0&-1\end{bmatrix}\)
  4. Find the standard matrix of \(T:\mathbb{R}^2\to\mathbb{R}^3\), \(T(\langle x,y\rangle)=\langle x,\ y,\ x+y\rangle\).
    \(\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix}\) — a 3×2 matrix, since the output has 3 components and the input has 2.
  5. Find the standard matrix of projection onto the x-axis: \(T(\langle x,y\rangle) = \langle x, 0\rangle\).
    \(\begin{bmatrix}1&0\\0&0\end{bmatrix}\)
  6. Find T(e₁) and T(e₂) for the 180° rotation, then assemble the standard matrix.
    \(T(e_1)=\langle-1,0\rangle\), \(T(e_2)=\langle0,-1\rangle\), so \(A=\begin{bmatrix}-1&0\\0&-1\end{bmatrix}\).
  7. bonus — Find the standard matrix of the identity transformation \(T(x)=x\).
    The identity matrix \(I=\begin{bmatrix}1&0\\0&1\end{bmatrix}\) (Module 10) — "do nothing" is itself a linear transformation.
  8. bonus — Find the standard matrix of a non-uniform 3D scale, exactly what setting transform.localScale = (2,3,4) does: \(T(\langle x,y,z\rangle)=\langle2x,3y,4z\rangle\).
    \(\begin{bmatrix}2&0&0\\0&3&0\\0&0&4\end{bmatrix}\)
  9. bonus — A transformation has standard matrix \(A=\begin{bmatrix}0&1\\1&0\end{bmatrix}\). Describe geometrically what it does.
    It swaps the two coordinates — reflection over the line \(y=x\).
  10. bonus — Without computing anything, explain why the standard matrix of any transformation \(\mathbb{R}^n\to\mathbb{R}^m\) must have exactly \(n\) columns and \(m\) rows.
    There's one column per input basis vector (\(n\) of them, one for each input dimension), and each column is an output vector, which lives in \(\mathbb{R}^m\) and so has \(m\) entries (rows).
  11. challenge — A linear transformation \(T:\mathbb{R}^2\to\mathbb{R}^2\) sends \(\langle1,0\rangle\) to \(\langle3,1\rangle\) and \(\langle0,1\rangle\) to \(\langle-2,5\rangle\). Compute \(T(\langle4,-2\rangle)\) two independent ways — (a) directly from linearity, decomposing \(\langle4,-2\rangle\) into basis vectors, and (b) by building the standard matrix and multiplying — and confirm they agree.
    (a) \(\langle4,-2\rangle = 4e_1-2e_2\), so \(T(\langle4,-2\rangle)=4T(e_1)-2T(e_2)=4\langle3,1\rangle-2\langle-2,5\rangle=\langle12,4\rangle+\langle4,-10\rangle=\langle16,-6\rangle\).
    (b) \(A=\begin{bmatrix}3&-2\\1&5\end{bmatrix}\), and \(A\langle4,-2\rangle^T=\langle3(4)+(-2)(-2),\ 1(4)+5(-2)\rangle=\langle12+4,\ 4-10\rangle=\langle16,-6\rangle\). Both methods agree — exactly Theorem 12.2.1's point: the matrix isn't a separate technique, it's a repackaging of the same linearity computation.
