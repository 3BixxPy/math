Composing Transformations

Module 10, Chapter 4 defined matrix multiplication by a row-times-column rule that probably felt arbitrary at the time. It wasn't. This chapter is the payoff: matrix multiplication is defined exactly so that "do one transformation, then another" becomes "multiply their matrices."

Theorem — Composition is multiplication

Suppose transformation \(T\) has standard matrix \(B\), and transformation \(S\) has standard matrix \(A\). The composite transformation "\(T\), then \(S\)" — written \(S\circ T\), meaning \((S\circ T)(x) = S(T(x))\) — has standard matrix \(AB\):

\[ S(T(x)) = A(Bx) = (AB)x \]
(12.3.1)

The middle step uses associativity of matrix multiplication (Module 10) — \(A(Bx)\) and \((AB)x\) are guaranteed to be the same vector for every \(x\). That means applying \(T\) and then \(S\) to any vector gives the exact same result as multiplying that vector by the single matrix \(AB\) — two transformations collapse into one matrix product. This is the real reason Module 10 defined matrix multiplication the way it did: not as an arbitrary rule, but as whatever rule makes Equation 12.3.1 true.

Worked example — rotate, then scale

Let \(T\) = "rotate 90°" with matrix \(B=\begin{bmatrix}0&-1\\1&0\end{bmatrix}\) (Chapter 2), and \(S\) = "scale by 2" with matrix \(A=\begin{bmatrix}2&0\\0&2\end{bmatrix}\). Find the matrix for "rotate 90°, then scale by 2."

Step 1 — identify which matrix goes on which side

"Rotate, then scale" means \(T\) happens first, \(S\) second — that's \(S\circ T\), so by Theorem 12.3.1 the combined matrix is \(AB\), with \(S\)'s matrix \(A\) on the left and \(T\)'s matrix \(B\) on the right (the order you'd read \(S(T(x))\), innermost function first).

Step 2 — compute AB

\(AB = \begin{bmatrix}2&0\\0&2\end{bmatrix}\begin{bmatrix}0&-1\\1&0\end{bmatrix} = \begin{bmatrix}2(0)+0(1) & 2(-1)+0(0)\\0(0)+2(1) & 0(-1)+2(0)\end{bmatrix} = \begin{bmatrix}0&-2\\2&0\end{bmatrix}\)

Result — and a subtlety worth noticing

Combined matrix: \(\begin{bmatrix}0&-2\\2&0\end{bmatrix}\). Check on \(e_1=\langle1,0\rangle\): rotating first gives \(\langle0,1\rangle\), then scaling by 2 gives \(\langle0,2\rangle\) — matches \(AB\langle1,0\rangle^T=\langle0,2\rangle\) ✓. Here, computing \(BA\) instead (scale first, then rotate) happens to give the same matrix — because uniform scaling by a scalar matrix (\(2I\)) commutes with absolutely everything. That's a special feature of uniform scaling, not a general fact — the mistake block below shows a case where order genuinely changes the answer.

Common mistake

Multiplying the two matrices in the wrong order, trusting that it won't matter. It usually does — matrix multiplication isn't commutative in general (Module 10, Chapter 4), so "\(T\) then \(S\)" and "\(S\) then \(T\)" are typically genuinely different transformations, and the product must be written with the second-applied transformation's matrix on the left.

Concrete proof it matters: let \(R=\begin{bmatrix}1&0\\0&-1\end{bmatrix}\) (reflect over the x-axis) and \(\text{Rot}=\begin{bmatrix}0&-1\\1&0\end{bmatrix}\) (rotate 90°).

"Rotate, then reflect" \(= R\cdot\text{Rot} = \begin{bmatrix}1&0\\0&-1\end{bmatrix}\begin{bmatrix}0&-1\\1&0\end{bmatrix} = \begin{bmatrix}0&-1\\-1&0\end{bmatrix}\)

"Reflect, then rotate" \(= \text{Rot}\cdot R = \begin{bmatrix}0&-1\\1&0\end{bmatrix}\begin{bmatrix}1&0\\0&-1\end{bmatrix} = \begin{bmatrix}0&1\\1&0\end{bmatrix}\)

Two genuinely different matrices from the same two transformations, just swapped in order — exactly the kind of bug that shows up as "my object rotated around the wrong point" when a rotation and a non-uniform transform get composed in the wrong sequence in engine code.

Try it yourself

\(T\) is applied first, then \(S\). \(S\)'s matrix is \(A\), \(T\)'s matrix is \(B\). Is the combined transformation's matrix \(AB\) or \(BA\)?

Practice

  1. \(S\) has matrix \(\begin{bmatrix}1&0\\0&2\end{bmatrix}\), \(T\) has matrix \(\begin{bmatrix}0&1\\1&0\end{bmatrix}\). Find the matrix for "\(T\), then \(S\)."
    \(AB=\begin{bmatrix}1&0\\0&2\end{bmatrix}\begin{bmatrix}0&1\\1&0\end{bmatrix}=\begin{bmatrix}0&1\\2&0\end{bmatrix}\)
  2. Using the same \(A,B\) as above, find the matrix for "\(S\), then \(T\)," and compare with the previous answer.
    \(BA=\begin{bmatrix}0&1\\1&0\end{bmatrix}\begin{bmatrix}1&0\\0&2\end{bmatrix}=\begin{bmatrix}0&2\\1&0\end{bmatrix}\) — different from \(AB\), confirming order matters here.
  3. Find the matrix for "reflect over the y-axis, then reflect over the x-axis," using \(\begin{bmatrix}-1&0\\0&1\end{bmatrix}\) and \(\begin{bmatrix}1&0\\0&-1\end{bmatrix}\).
    \(\begin{bmatrix}1&0\\0&-1\end{bmatrix}\begin{bmatrix}-1&0\\0&1\end{bmatrix}=\begin{bmatrix}-1&0\\0&-1\end{bmatrix}\) — a 180° rotation. Two perpendicular reflections compose into a rotation, a fact worth remembering.
  4. If \(S\)'s matrix is \(A\) and \(T\)'s matrix is the identity \(I\), what is the combined matrix for "\(T\), then \(S\)"?
    \(AI=A\) — composing with "do nothing" changes nothing.
  5. Find the matrix for "scale x by 3, then rotate 90°," using \(\begin{bmatrix}3&0\\0&1\end{bmatrix}\) and \(\begin{bmatrix}0&-1\\1&0\end{bmatrix}\).
    \(\begin{bmatrix}0&-1\\1&0\end{bmatrix}\begin{bmatrix}3&0\\0&1\end{bmatrix}=\begin{bmatrix}0&-1\\3&0\end{bmatrix}\)
  6. True or false: the composition of two linear transformations is always itself a linear transformation.
    True — the matrix product \(AB\) is still just a matrix, and Chapter 1's challenge showed every matrix defines a linear transformation.
  7. bonus — \(S\circ T\) has matrix \(\begin{bmatrix}2&0\\0&2\end{bmatrix}\), and \(T\)'s matrix is the identity \(I\). What must \(S\)'s matrix be?
    Also \(\begin{bmatrix}2&0\\0&2\end{bmatrix}\) — since \(T=I\) contributes nothing, \(S\circ T = S\).
  8. bonus — In one sentence, explain why matrix multiplication is defined row-times-column rather than some other, simpler-looking rule.
    Because row-times-column is precisely the rule that makes matrix multiplication compute function composition correctly (Theorem 12.3.1) — any "simpler" entrywise rule wouldn't have that property.
  9. bonus — Are two rotations about the same origin, by angles θ and φ, ever an exception to the "order matters" rule?
    Yes — rotations about the same point always commute with each other (rotating by θ then φ is the same as φ then θ, both give a single rotation by θ+φ). It's a genuine special case, alongside uniform scaling.
  10. bonus — If \(A\) and \(B\) are both diagonal matrices, does \(AB=BA\) always hold?
    Yes — diagonal matrices always commute with each other (multiplying diagonals just multiplies matching entries either way).
  11. challenge — Using \(A=\begin{bmatrix}1&0\\0&2\end{bmatrix}\) and \(B=\begin{bmatrix}0&1\\1&0\end{bmatrix}\) from problems 1–2, compute \(AB\) and \(BA\) and verify \((AB)^T=BA\). Is that a coincidence, or a consequence of a Module 10 transpose rule applied to this specific \(A,B\)?
    \(AB=\begin{bmatrix}0&1\\2&0\end{bmatrix}\), \(BA=\begin{bmatrix}0&2\\1&0\end{bmatrix}\), and indeed \((AB)^T=\begin{bmatrix}0&2\\1&0\end{bmatrix}=BA\). Not a coincidence: Module 10's rule \((AB)^T=B^TA^T\) applies to any \(A,B\), and here both \(A\) and \(B\) happen to be symmetric (\(A^T=A\), \(B^T=B\)), so \((AB)^T=B^TA^T=BA\) automatically. Whenever both matrices are symmetric, \((AB)^T=BA\) is guaranteed, not accidental.
