The Coordinate Plane & Graphing Basics

The last three chapters worked entirely with equations and notation. This one is pure picture-reading — the skill that makes everything after it visual instead of abstract.

Why this matters

A graph is just a picture of every input-output pair a function produces, plotted as points. Reading that picture fluently — where it crosses the axes, which direction it's heading, what a point on it means — is what lets you check your algebra by eye, and it's the entire visual language the rest of this module (and Calculus) is written in.

Definition — The coordinate plane

Two number lines crossing at a right angle: the horizontal x-axis and vertical y-axis, meeting at the origin (0,0). Every point is located by an ordered pair (x, y): move x units horizontally from the origin, then y units vertically. The four regions this divides the plane into are the quadrants, numbered I–IV counter-clockwise starting from the top right.

Quadrant I: both positive. II: x negative, y positive. III: both negative. IV: x positive, y negative.

Common mistake

Plotting (2, -3) by going down 2 then right 3 (or any other swap) — the order in an ordered pair is always x first, then y. "Along the hall, then up the stairs": move horizontally first (x), then vertically (y). Read the pair left to right, move in that same order.

Definition — Intercepts

The x-intercept is where a graph crosses the x-axis — the point(s) where y = 0. The y-intercept is where it crosses the y-axis — where x = 0. To find either algebraically: set the other variable to 0 and solve.

Worked example

Find the x- and y-intercepts of y = 2x − 4.

Step 1 — y-intercept: set x = 0

\(y = 2(0) - 4 = -4\). y-intercept: \((0, -4)\)

Step 2 — x-intercept: set y = 0

\(0 = 2x - 4 \Rightarrow x = 2\). x-intercept: \((2, 0)\)

Practice

  1. Which quadrant is (-5, 2) in?
    Quadrant II (x negative, y positive)
  2. Which quadrant is (3, -7) in?
    Quadrant IV
  3. Which quadrant is (-1, -1) in?
    Quadrant III
  4. Find the intercepts of y = 3x + 6.
    y-intercept \((0,6)\); x-intercept: \(0=3x+6 \Rightarrow x=-2\), so \((-2,0)\)
  5. Find the intercepts of y = -x + 5.
    y-intercept \((0,5)\); x-intercept \((5,0)\)
  6. A point lies exactly on the y-axis. What must be true about its x-coordinate?
    It must be 0.
  7. bonus — Find the y-intercept only: y = x² - 4
    \((0,-4)\)
  8. bonus — Find the x-intercept(s): y = x² - 4
    \(0=x^2-4 \Rightarrow x=\pm2\), so \((2,0)\) and \((-2,0)\) — a curve can have more than one x-intercept.
  9. bonus — Can a function's graph have more than one y-intercept? Why or why not?
    No — that would mean x=0 has two different outputs, which violates the definition of a function (Chapter 1).
  10. bonus — A graph passes through the origin. What does that tell you about both intercepts at once?
    The x-intercept and y-intercept are both \((0,0)\) — the same point.
  11. challenge — A line has x-intercept \((4,0)\) and y-intercept \((0,-2)\). Find its equation in the form \(y=mx+b\) (hint: you now have two points — Module 0's slope idea from Chapter 5 of this module will make this exact later, but see if you can reason it out with what you know now).
    Slope \(=\dfrac{0-(-2)}{4-0}=\dfrac12\); with b=-2 (the y-intercept): \(y=\tfrac12x-2\).
