Chapter 10 · concept:function-composition

Function Composition

Feeding the output of one function into another. This exact mechanic, run through a derivative, is the chain rule in Calculus I.

Why this matters

Most functions you'll differentiate later aren't simple — they're functions built out of other functions, like √(x²+1) (a square-root function wrapped around a polynomial). Composition is the formal name for "wrapped around," and being fluent at pulling a composite apart into its pieces (or building one from pieces) is exactly the skill the chain rule assumes you already have.

Definition — Composition
\[ (f \circ g)(x) = f(g(x)) \]
(1.10.1)

Read (f∘g)(x) as "f of g of x" — apply g first, then feed that result into f. Work inside-out: the innermost function always goes first.

Worked example

If f(x) = x+1 and g(x) = x², find f(g(2)).

Step 1 — inside-out: compute g(2) first

\(g(2) = 2^2 = 4\)

Step 2 — feed that result into f

\(f(4) = 4+1 = 5\)

Result
\[ f(g(2)) = 5 \]
(1.10.2)
Worked example — composing symbolically, and why order matters

If f(x) = 2x+1 and g(x) = x²-3, find (f∘g)(x) and (g∘f)(x).

Step 1 — (f∘g)(x): substitute the whole g(x) into every x in f

\(f(g(x)) = 2(x^2-3)+1 = 2x^2-6+1 = 2x^2-5\)

Step 2 — (g∘f)(x): substitute the whole f(x) into every x in g

\(g(f(x)) = (2x+1)^2-3 = 4x^2+4x+1-3 = 4x^2+4x-2\)

Result — they're different

\(2x^2-5 \neq 4x^2+4x-2\). Composition is generally not commutative — which function goes first genuinely changes the outcome, unlike ordinary multiplication.

Common mistake

Computing (f∘g)(x) by doing f first, or reading it as f(x)·g(x). Neither is right. (f∘g)(x) always means "g happens first, then f happens to the result" — the function written second, closest to the x, is applied first.

Try it yourself

If f(x) = x−3 and g(x) = x², what is f(g(3))?

Practice

Using f(x) = x-3, g(x) = x² for problems 1–2:

  1. Find f(g(3)).
    \(g(3)=9\), \(f(9)=6\)
  2. Find g(f(3)).
    \(f(3)=0\), \(g(0)=0\)
  3. If f(x) = √x and g(x) = x+7, find f(g(2)).
    \(g(2)=9\), \(f(9)=3\)
  4. If f(x) = 3x and g(x) = x+2, find (f∘g)(x) in general.
    \(3(x+2)=3x+6\)
  5. For the same f, g, find (g∘f)(x) in general, and confirm it's different from problem 4.
    \(3x+2\) — different from \(3x+6\).
  6. If f(x)=x² and g(x)=x-1, compute (f∘g)(4) correctly (g first), then compute the "wrong order" version (f first, then g) — confirm they differ.
    Correct: \(g(4)=3\), \(f(3)=9\). Wrong order: \(f(4)=16\), \(g(16)=15\). \(9\neq15\).
  7. bonus — If f(x)=1/x and g(x)=x-2, find (f∘g)(x) and state its domain restriction.
    \(1/(x-2)\), \(x\neq2\)
  8. bonus — For the same f, g, find (g∘f)(x) and its domain.
    \(1/x - 2\), \(x\neq0\)
  9. bonus — If f(x)=√x and g(x)=x²-9, find (f∘g)(x) and its domain.
    \(\sqrt{x^2-9}\), domain \(x\le-3\) or \(x\ge3\)
  10. bonus — Find a pair of (nonzero, non-identity) functions f and g where (f∘g)(x) = (g∘f)(x) actually holds.
    e.g. \(f(x)=x+1\), \(g(x)=x+2\): both give \(x+3\) — addition happens to commute here.
  11. challenge — Express h(x) = (3x-1)² as a composition f(g(x)) for some simpler f and g (decompose it into an inner and an outer piece).
    Let \(g(x)=3x-1\) (inner) and \(f(x)=x^2\) (outer): \(f(g(x))=(3x-1)^2=h(x)\).
