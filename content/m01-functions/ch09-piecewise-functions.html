Chapter 9 · concept:piecewise-functions

Piecewise Functions

One function, different rules on different parts of the domain. This chapter's open/closed dot convention is a direct preview of one-sided limits in Calculus I.

Why this matters

Plenty of real quantities genuinely behave by different rules in different ranges — a tax bracket, shipping cost by weight, a speed limit that changes at a certain road. A piecewise function is just honest notation for "it depends which zone you're in." The bookkeeping skill here (which rule applies, and what happens exactly at the boundary) is precisely what one-sided limits will formalize later.

Definition — Piecewise function
\[ f(x) = \begin{cases} x+2 & x < 0 \\ x^2 - 1 & x \geq 0 \end{cases} \]
(1.9.1)

Each line is one "piece": an output rule, paired with the condition on x that decides when it applies. To evaluate at a specific input, first find which condition that input satisfies, then use only that piece's rule.

Worked example

Using (1.9.1), find f(-3) and f(0).

Step 1 — f(-3): which condition does -3 satisfy?

\(-3 < 0\), so use the first piece: \(x+2\)

Step 2 — evaluate

\(f(-3) = -3+2 = -1\)

Step 3 — f(0): which condition does 0 satisfy?

\(0 \geq 0\) — the second piece, not the first, even though 0 feels like a boundary case. The "≥" belongs to the second rule.

Step 4 — evaluate

\(f(0) = 0^2-1 = -1\)

The open circle marks a value the first piece approaches but never actually reaches at x=0 (it stops being used there); the filled circle marks where the second piece actually starts.

Common mistake

Rushing past the boundary condition and grabbing whichever piece looks "closer." ≤ and < are not interchangeable — they decide, precisely, which single piece owns the boundary point. Read the condition on the exact input you're evaluating before picking a rule, every time, especially near a boundary.

Try it yourself

For g(x) = {2x if x≤2; x+3 if x>2}, what is g(2)? (careful which piece owns the boundary)

Practice

Using (1.9.1) for problems 1–2:

  1. Find f(-1).
    \(-1+2=1\)
  2. Find f(5).
    \(5^2-1=24\)
  3. For g(x) = {2x if x≤2; x+3 if x>2}, find g(3).
    \(3+3=6\)
  4. For the same g, find g(-4).
    \(2(-4)=-8\)
  5. For the same g, what value does the first piece give as x approaches 2, versus what the second piece gives just past 2? Is there a jump?
    First piece at x=2: 4. Second piece just past 2: approaches 5. Yes — a jump from 4 to 5.
  6. Explain in one sentence why g(2) only has one correct value despite the graph having a jump there.
    The condition x≤2 unambiguously assigns x=2 to the first piece only — a function must have exactly one output per input (Chapter 1), and the piecewise definition guarantees that by construction.
  7. bonus — For h(x) = {|x| if x<3; 2x-3 if x≥3}, find h(-5).
    \(|-5|=5\)
  8. bonus — For the same h, find h(3).
    \(2(3)-3=3\)
  9. bonus — For the same h, find h(0).
    \(|0|=0\)
  10. bonus — Is h continuous (no jump) at x=3? Compare what each piece gives near x=3.
    First piece approaching 3: →3. Second piece at 3: 3. They match — no jump, continuous there.
  11. challenge — Define your own piecewise function using two linear pieces (not the |x| notation) that reproduces the absolute value function exactly, and verify it against |x| at x=-4, 0, and 5.
    \(p(x) = \{-x \text{ if } x<0;\ x \text{ if } x\geq0\}\). Check: \(p(-4)=4=|-4|\), \(p(0)=0=|0|\), \(p(5)=5=|5|\) ✓.
