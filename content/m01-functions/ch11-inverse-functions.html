Inverse Functions

A function that undoes another function. This exact idea, applied to exponentials, is how logarithms get defined in Module 3.

Why this matters

Addition undoes subtraction. Squaring (sort of) undoes a square root. An inverse function is that same "undo" relationship made formal and general. Logarithms — the whole subject of Module 3 — are defined as nothing more than "the inverse of an exponential function," so this chapter's algebra (swap and solve) is the exact procedure that will define them.

Definition — Inverse function
\[ f(f^{-1}(x)) = x \qquad f^{-1}(f(x)) = x \]
(1.11.1)

f⁻¹ ("f inverse") is the function that reverses whatever f did. Feed a value through f, then through f⁻¹, and you get your original value back.

Common mistake

The -1 in f⁻¹(x) is not an exponent. f⁻¹(x) ≠ 1/f(x). For f(x)=2x+3: \(1/f(x) = 1/(2x+3)\), but the actual inverse (worked out below) is \((x-3)/2\) — completely different functions. Read f⁻¹ as its own symbol, "the inverse of f," not as "f to the power -1."

Method — Finding an inverse algebraically
  1. Write the function as y = ...
  2. Swap x and y
  3. Solve the result for y — that's f⁻¹(x)
Worked example

Find the inverse of f(x) = 2x + 3.

Step 1 — write as y = ...

\(y = 2x+3\)

Step 2 — swap x and y

\(x = 2y+3\)

Step 3 — solve for y

\(x-3 = 2y \Rightarrow y = \dfrac{x-3}{2}\)

Step 4 — verify using the definition

\(f(f^{-1}(x)) = 2\left(\dfrac{x-3}{2}\right)+3 = (x-3)+3 = x\) ✓

Result
\[ f^{-1}(x) = \frac{x-3}{2} \]
(1.11.2)
f(x) = 2x+3f⁻¹(x)

The dashed line is y=x. f and f⁻¹ are always mirror images of each other across it — because swapping x and y is exactly what reflecting over y=x does to a point.

One catch — not every function has an inverse that's a function

Just like the vertical line test decided whether a graph was a function of x, a "horizontal line test" decides whether that function has an inverse that's also a function: if any horizontal line crosses the graph more than once, the outputs repeat, and swapping x/y would break the function definition (one input, one output) for the inverse. f(x)=x² fails this — \(f(2)=f(-2)=4\) — which is exactly why Module 3's inverse (the logarithm) is built from exponential functions, which don't have this problem.

Try it yourself

If f(2) = 9, what must f⁻¹(9) equal? (no algebra needed — use the definition directly)

Practice

  1. Find the inverse of f(x) = x + 5.
    \(f^{-1}(x)=x-5\)
  2. Find the inverse of f(x) = 3x - 1.
    \(f^{-1}(x)=(x+1)/3\)
  3. Find the inverse of f(x) = -2x + 6.
    \(f^{-1}(x)=(6-x)/2\)
  4. Verify your answer to problem 1 satisfies f(f⁻¹(x)) = x.
    \((x-5)+5=x\) ✓
  5. If f(4) = -1, what is f⁻¹(-1)?
    4
  6. Does f(x) = x² (full domain, all real numbers) have an inverse that's a function? Why not?
    No — it fails the horizontal line test (e.g. f(2)=f(-2)=4), so swapping x,y wouldn't give one output per input.
  7. bonus — Find the inverse of f(x) = x³.
    \(f^{-1}(x)=\sqrt[3]{x}\) (cube root — x³ passes the horizontal line test, unlike x²)
  8. bonus — Find the inverse of f(x) = (2x-1)/3.
    \(f^{-1}(x)=(3x+1)/2\)
  9. bonus — If the point (3, 7) is on the graph of f, what point must be on the graph of f⁻¹?
    \((7,3)\) — coordinates swap.
  10. bonus — Explain, using coordinate-swapping, why the graph of f⁻¹ is always the reflection of f's graph over the line y=x.
    Reflecting a point (a,b) over y=x gives (b,a) — exactly the coordinate swap that defines the inverse. Every point transforms the same way, so the whole graph reflects.
  11. challenge — Find the inverse of f(x) = 1/(x-2), and state any domain restriction on f⁻¹ itself.
    \(y=1/(x-2) \Rightarrow x=1/(y-2) \Rightarrow y-2=1/x \Rightarrow y=2+1/x\). So \(f^{-1}(x)=2+\dfrac1x\), with \(x\neq0\).
