What Is a Function?

On the diagnostic this whole area came back "I don't know anything." That's fine — nothing here builds on shaky ground. This is the actual starting point.

Why this matters

Almost everything from here through the end of Calculus II is "take a function, do something to it." Derivatives are a rule applied to a function; integrals are too. If the idea of a function itself isn't rock solid, everything built on top of it wobbles. So we go slow here, and we go visual — functions are one of the few topics in this curriculum where the picture and the equation genuinely teach different halves of the idea.

Definition — Function

A function is a rule that pairs every input with exactly one output. Give it the same input twice, you always get the same output back. Give it two different inputs, they're allowed to share an output — that's fine — but one input can never split into two different outputs.

Notation — f(x)

f(x) is read "f of x" — it means "the output of the rule f, when you feed it the input x." It is a label for a value, not a multiplication. f is the name of the function (could be any letter — g, h, whatever), and x is whatever you're plugging in.

Common mistake — the single most common one in this whole topic

f(x) does not mean "f times x." There's no multiplication happening. It's function notation: "the value you get from function f when the input is x." If f(x) = 2x - 3 and you're asked for f(5), you are not computing f times 5 — you're computing 2(5) - 3 = 7. The parentheses here mean "applied to," not "multiplied by."

The vertical line test

Rule — Vertical line test

A graph represents a function exactly when no vertical line crosses it more than once. A vertical line at a fixed x represents "all the outputs for that one input" — if it hits the graph twice, that input has two different outputs, which breaks the definition above.

a function — passes

Every vertical line (like the dashed one at x=2) crosses this graph exactly once.

not a function — fails

The dashed vertical line at x=1 crosses the circle twice — one input, two outputs. A circle is a relation, but not a function of x.

Worked example — checking a set of ordered pairs

Is {(1,3), (2,5), (3,3), (4,9)} a function? Is {(1,3), (1,5), (2,3)}?

Step 1 — check the first set for repeated x-values

x-values used: 1, 2, 3, 4 — all different. It doesn't matter that the outputs 3 appears twice (for x=1 and x=3); repeated outputs are fine. Repeated inputs are the problem.

Step 2 — first set is a function

Every input appears once, each with one output. ✓ Function.

Step 3 — check the second set

x=1 appears twice: once paired with 3, once with 5. Same input, two different outputs.

Step 4 — second set is not a function

It's a relation (a set of pairs), but it fails the function definition.

Try it yourself

Is {(2,4), (3,4), (5,7)} a function? (type "yes" or "no")

Practice

  1. Is {(1,2), (2,4), (3,6)} a function?
    Yes — every input is different.
  2. Is {(0,1), (0,-1), (2,3)} a function?
    No — input 0 has two different outputs.
  3. Does the graph of a straight (non-vertical) line always pass the vertical line test?
    Yes — any vertical line crosses a non-vertical line exactly once.
  4. Does a vertical line itself (like x = 3) pass the vertical line test?
    No — the vertical line test fails against itself; it's infinitely many outputs for one input, so x=3 is not a function of x.
  5. Explain in one sentence why y² = x does not describe y as a function of x.
    For most positive x, both y=√x and y=−√x work, so one input x gives two outputs.
  6. True or false: f(x) means "f multiplied by x."
    False — it means "the output of function f when the input is x."
  7. bonus — Is {(-1,5), (0,5), (1,5)} a function? What's unusual about it?
    Yes — repeated outputs (all 5) are fine, only repeated inputs would break it. This is a valid (constant) function.
  8. bonus — A graph is a wide "U" shape (a parabola) opening upward. Does it pass the vertical line test?
    Yes — every vertical line crosses an upward parabola at most once.
  9. bonus — A graph is a sideways "U" (opening to the right, like x = y²). Does it pass the vertical line test?
    No — a vertical line through the open part crosses it twice (once on the top branch, once on the bottom).
  10. bonus — Why is "give it the same input twice, always get the same output" a reasonable thing to require of a function?
    Answers will vary — commonly: it makes the rule predictable/well-defined, e.g. a vending machine code should always dispense the same item.
  11. challenge — A relation contains the points (2,7) and (2,9). Without seeing any other points, can you already conclude it's not a function? Explain.
    Yes — input 2 already has two different outputs (7 and 9), which alone violates the definition regardless of what other points exist.
