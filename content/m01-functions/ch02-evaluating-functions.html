Evaluating Functions

This is the exact skill the diagnostic tested with f(x)=2x²−3, f(−2). One rule, applied carefully.

Why this matters

Evaluating a function is "plug in and simplify" — nothing new mechanically beyond Module 0's order-of-operations and signed-arithmetic chapters. The only new thing is the notation. Get comfortable here and derivatives later (which are built entirely out of repeated function evaluation) will feel like a small step, not a leap.

Rule — Evaluating f(a)

To find f(a), replace every occurrence of x in the rule for f with a, then simplify using order of operations. That's the whole procedure.

Worked example — the exact diagnostic problem

If f(x) = 2x² − 3, find f(−2).

Step 1 — substitute −2 for every x

\(f(-2) = 2(-2)^2 - 3\)

Step 2 — exponent first (order of operations)

\((-2)^2 = 4\) — a negative squared is positive. Not \(-4\).

Step 3 — multiply

\(2(4) = 8\)

Step 4 — subtract

\(8 - 3 = 5\)

Result
\[ f(-2) = 5 \]
(1.2.1)
Common mistake

(−2)² is 4, not −4. The parentheses matter: (−2)² = (−2)(−2) = 4, while −2² = −(2²) = −4 (no parentheses around the negative — the exponent only touches the 2). When you substitute a negative number into a function, wrap it in parentheses every time, exactly as shown above — it removes this ambiguity entirely.

Worked example — evaluating at an expression, not just a number

If g(x) = x² − 3x + 1, find g(3) and g(a+1).

Step 1 — g(3): substitute 3 for x

\(g(3) = 3^2 - 3(3) + 1 = 9 - 9 + 1 = 1\)

Step 2 — g(a+1): substitute the whole expression (a+1) for x, everywhere

\(g(a+1) = (a+1)^2 - 3(a+1) + 1\)

Step 3 — expand and simplify

\((a+1)^2 = a^2+2a+1\), and \(-3(a+1) = -3a-3\). So: \(a^2+2a+1-3a-3+1 = a^2-a-1\)

Why this matters later

Substituting an expression instead of a plain number — like g(a+1), or later f(x+h) — is exactly the move that defines a derivative in Calculus I. This isn't a detour; it's early practice for the single most important calculation in the entire course.

Try it yourself

The exact diagnostic problem, cold: if f(x) = 2x² − 3, what is f(−2)?

Practice

  1. If f(x) = 3x + 5, find f(4).
    \(3(4)+5=17\)
  2. If f(x) = x² + 1, find f(-3).
    \((-3)^2+1=10\)
  3. If h(x) = 2x² - 5x + 1, find h(0).
    \(0-0+1=1\)
  4. If h(x) = 2x² - 5x + 1, find h(-1).
    \(2(1)-5(-1)+1=2+5+1=8\)
  5. If f(x) = √(x+5), find f(4).
    \(\sqrt9=3\)
  6. If f(x) = 2x² - 3, find f(3) and confirm it's different from f(-3). What do you notice about the two results?
    \(f(3)=2(9)-3=15\), \(f(-3)=2(9)-3=15\) — actually the same, because squaring erases the sign. (A preview of "even functions," Chapter 12.)
  7. bonus — If f(x) = x² - 2x, find f(a) in terms of a.
    \(a^2-2a\)
  8. bonus — If f(x) = x² - 2x, find f(a+2), fully expanded.
    \((a+2)^2-2(a+2) = a^2+4a+4-2a-4 = a^2+2a\)
  9. bonus — If f(x) = 1/(x-1), find f(2) and explain why f(1) can't be evaluated.
    \(f(2)=1\); \(f(1)\) would require dividing by 0, which is undefined.
  10. bonus — If g(x) = x³, find g(-2) and explain why the sign carries through here but not for x².
    \(g(-2)=-8\) — an odd power of a negative stays negative, since an odd number of negative factors multiply to a negative.
  11. challenge — If f(x) = x² + 3x - 1, compute f(x+h) - f(x) and simplify fully in terms of x and h (don't cancel yet, just expand and collect like terms).
    \(f(x+h) = (x+h)^2+3(x+h)-1 = x^2+2xh+h^2+3x+3h-1\). Subtracting \(f(x)=x^2+3x-1\): \(f(x+h)-f(x) = 2xh+h^2+3h\).
