Domain and Range

The exact two problems from the diagnostic — domain of 1/(x−4) and √(x−4) — are the two worked examples below. This is where Module 0's "domain restrictions" chapter pays off directly.

Why this matters

Domain is "which inputs are actually allowed." Range is "which outputs are actually possible." You already did the hard part of domain-thinking back in Module 0 (rational expressions can't divide by zero) — this chapter adds exactly one new restriction (square roots of negatives) and then asks you to apply both together.

Definition — Domain and Range

The domain of a function is the complete set of allowed input values (x). The range is the complete set of output values (y) the function actually produces.

Rule — Two restrictions to check, every time
  1. Denominators can't be zero. If x appears in a denominator, exclude any x that makes it zero. (Module 0, Chapter 10.)
  2. You can't take an even root (square root, fourth root, ...) of a negative number and get a real output. If x appears under a square root, whatever's under the root must be ≥ 0.

A function can have neither restriction (most polynomials), one, or both at once — check systematically rather than guessing.

Worked example — the exact diagnostic problems

Find the domain of f(x) = 1/(x−4), and of g(x) = √(x−4).

Step 1 — f(x): denominator can't be zero

\(x - 4 \neq 0 \Rightarrow x \neq 4\)

Step 2 — f(x) domain
\[ \text{domain of } f: x \neq 4 \]
(1.3.1)
Step 3 — g(x): what's under the root must be ≥ 0

\(x - 4 \geq 0\)

Step 4 — solve the inequality

\(x \geq 4\)

g(x) domain
\[ \text{domain of } g: x \geq 4 \]
(1.3.2)

Notice the two answers look similar but mean very different things: f excludes a single point; g excludes an entire half-line.

y = 1/(x−4)y = √(x−4)

Both graphs make the domain visible: the left one has a gap exactly at x=4 (vertical asymptote), the right one simply doesn't exist at all left of x=4 — the plotter can't draw what isn't real.

Worked example — both restrictions at once

Find the domain of h(x) = 1/√(x−1).

Step 1 — the square root needs its inside ≥ 0

\(x - 1 \geq 0 \Rightarrow x \geq 1\)

Step 2 — but it's also in the denominator, so it can't equal 0

\(\sqrt{x-1} \neq 0 \Rightarrow x \neq 1\)

Step 3 — combine: ≥ 1, but not equal to 1

\(x > 1\) — strictly greater, not "greater or equal."

Common mistake

When a square root sits in a denominator, it's easy to write x ≥ 1 (from the root rule) and forget the denominator rule tightens it to x > 1 (strict). Always check both restrictions when both apply, and combine them — don't stop after the first one you spot.

Practice

  1. Find the domain: 1/(x−7)
    \(x \neq 7\)
  2. Find the domain: √(x+3)
    \(x \geq -3\)
  3. Find the domain: 1/(x²−9)
    \(x \neq 3, -3\)
  4. Find the domain: √(10−x)
    \(x \leq 10\)
  5. Find the domain: 1/√(x−1)
    \(x > 1\)
  6. Find the domain: x² + 3x − 1. What's different about this one?
    All real numbers — no denominator, no root. Polynomials never have domain restrictions.
  7. bonus — Find the domain: √(x²−4)
    \(x \leq -2\) or \(x \geq 2\) (need \(x^2 \ge 4\))
  8. bonus — Find the domain: 1/(x²−4)
    \(x \neq 2, -2\)
  9. bonus — Find the range: f(x) = √x
    \(y \geq 0\) — a square root is never negative.
  10. bonus — Find the range: f(x) = -x² + 1
    \(y \leq 1\) — the vertex (highest point) is at y=1, and it only goes down from there.
  11. challenge — Find the domain: √(x−4)/(x−9) (combine a root restriction and a denominator restriction that involve different numbers).
    Need \(x-4\ge0 \Rightarrow x\ge4\), and \(x-9\neq0 \Rightarrow x\neq9\). Combined: \(x\ge4\) and \(x\neq9\).
