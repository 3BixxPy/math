Rational Functions & Asymptotes

Module 0's rational-expression factoring finally meets a graph — and settles, for good, whether a hole in the domain is an asymptote or something else entirely.

Why this matters

An asymptote is a line a graph gets closer and closer to without touching. "What happens as x approaches this value?" and "what happens as x gets huge?" are literally the two questions a limit answers in Calculus I — so reading asymptotes off a rational function now is direct rehearsal for that.

Definition — Rational function

A function of the form P(x)/Q(x) where P and Q are polynomials — same object as Module 0's rational expressions, now graphed.

Rule — Vertical asymptotes

A vertical asymptote occurs at any x where the fully factored and simplified denominator is zero. The word "simplified" is doing real work here — check the next section before trusting a raw denominator zero.

Rule — Horizontal asymptotes (compare degrees)
  • degree of numerator < degree of denominator → horizontal asymptote y = 0
  • degree of numerator = degree of denominator → y = (ratio of leading coefficients)
  • degree of numerator > degree of denominator → no horizontal asymptote (the graph grows without bound; Calculus II's polynomial division reveals what it does instead)
y = 1/(x−4) — vertical asymptote x=4, horizontal asymptote y=0

The vertical asymptote always sits exactly where the shift takes it — domain restrictions move with the graph, same as in Chapter 6.

Worked example — hole or asymptote? The exact diagnostic expression, revisited

Does f(x) = (x²−9)/(x−3) have a vertical asymptote at x=3?

Step 1 — factor the numerator (Module 0, Chapter 7)

\(x^2-9 = (x-3)(x+3)\)

Step 2 — cancel the common factor

\(\dfrac{(x-3)(x+3)}{x-3} = x+3\), for \(x \neq 3\)

Result — it's a hole, not an asymptote

The factor canceled out entirely — the function simplifies to the plain line \(y=x+3\) with a single missing point at \(x=3\). That's called a removable discontinuity (a "hole"): the graph is a perfectly ordinary line everywhere except one missing point, not a curve shooting off toward infinity. A true vertical asymptote only happens when the factor doesn't cancel.

Common mistake

Setting the denominator to zero and calling every solution a vertical asymptote before checking whether it cancels with the numerator. Always fully factor and simplify first (Module 0, Chapters 7–10) — a zero that survives simplification is a true vertical asymptote; a zero that cancels away is only a hole.

Try it yourself

For f(x) = (x+1)/(x²−1), is x = -1 a hole or a vertical asymptote? (hint: factor \(x^2-1\) first)

Practice

  1. Find the vertical asymptote: f(x) = 1/(x+5)
    \(x=-5\)
  2. Find the horizontal asymptote: f(x) = 3/(x-2)
    \(y=0\) (numerator degree 0 < denominator degree 1)
  3. Find both asymptotes: f(x) = (x+1)/(x-6)
    VA \(x=6\); HA \(y=1\) (equal degrees, leading coefficients both 1)
  4. Find both asymptotes: f(x) = (4x-1)/(2x+3)
    VA \(x=-3/2\); HA \(y=4/2=2\)
  5. Is x=3 a hole or a vertical asymptote for f(x) = (x²-9)/(x-3)? (from the worked example — restate the reasoning yourself)
    A hole — the (x-3) factor cancels.
  6. Find the vertical asymptote(s): f(x) = 1/(x²-4)
    \(x=2\) and \(x=-2\) (both survive — no numerator factor to cancel them)
  7. bonus — Find the horizontal asymptote: f(x) = (x²+1)/(3x²-5)
    \(y=1/3\)
  8. bonus — Find the horizontal asymptote: f(x) = (x+2)/(x²-1)
    \(y=0\)
  9. bonus — For f(x)=(x+1)/(x²-1), identify both the hole and the true vertical asymptote (there's one of each).
    Factor: \((x+1)/[(x-1)(x+1)]\). Hole at \(x=-1\) (cancels); true vertical asymptote at \(x=1\) (doesn't cancel).
  10. bonus — For f(x) = (x-2)(x+5)/[(x-2)(x-7)], identify the hole and the vertical asymptote.
    Hole at \(x=2\); vertical asymptote at \(x=7\).
  11. challenge — Construct a rational function that has a vertical asymptote at x=2, a hole at x=-3, and horizontal asymptote y=0.
    One example: \(f(x)=\dfrac{x+3}{(x-2)(x+3)}\) — the \((x+3)\) cancels (hole at \(x=-3\)), \((x-2)\) survives (VA at \(x=2\)), and the original numerator degree (1) is less than the original denominator degree (2), giving HA \(y=0\).
