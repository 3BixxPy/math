Chapter 6 · concept:ftc-part-1

The Fundamental Theorem of Calculus, Part 1

Chapters 1–2 built the antiderivative, entirely without a single mention of area. Chapters 3–5 built the definite integral, entirely as a limit of rectangles, without a single mention of antiderivatives. This chapter is where those two completely separate threads turn out to be the same thing.

Why this matters

Define a new function out of an integral: for a fixed starting point a, let g(x) = ∫[a,x] f(t)dt — the signed area accumulated from a up to x, as a function of where x stops. Nothing about building g ever mentioned an antiderivative; it's pure Chapter 3–5 machinery, rectangles and limits. Now ask the most natural question in the world: what's g′(x)? The answer is genuinely surprising — differentiating this area-accumulation function hands back, exactly, the original function you started with. Area-accumulation and antiderivative-taking are inverse processes. That's not a coincidence being pointed out; it's a theorem, and it's the reason this entire module exists.

Theorem — Fundamental Theorem of Calculus, Part 1

If g(x) = ∫[a,x] f(t)dt, then:

\[ g'(x) = f(x) \]
(8.6.1)

Here's why it's plausible: \(g(x+h)-g(x)\) is the sliver of accumulated area between \(x\) and \(x+h\). For small \(h\), that sliver is nearly a thin rectangle of width \(h\) and height \(f(x)\), so \(g(x+h)-g(x)\approx f(x)\cdot h\), meaning \(\dfrac{g(x+h)-g(x)}{h}\approx f(x)\). That's exactly Module 5 and 6's difference-quotient definition of a derivative — take \(h\to0\), and it becomes \(g'(x)=f(x)\) exactly, not just approximately.

Worked example

Let g(x) = ∫[0,x] (t² + 1)dt. Find g′(x) directly via FTC1 — without ever computing the integral itself.

Step 1 — identify f(t), the integrand

Here \(f(t) = t^2+1\).

Step 2 — apply (8.6.1) directly

\(g'(x) = f(x) = x^2+1\).

Result — no integration happened

\(g'(x)=x^2+1\). Notice what didn't happen: at no point did this require finding an antiderivative of \(t^2+1\) or evaluating the integral defining \(g\). FTC1 reads the integrand straight off — that's the entire theorem.

Common mistake

Trying to evaluate the integral first — attempting to find an antiderivative of \(f\), plug in the bounds, get an explicit formula for \(g(x)\), then differentiate that formula — when FTC1 says all of that work is entirely unnecessary. The whole point of the theorem is that differentiating an accumulation function just gives back the original integrand, immediately, with zero integration required. Reaching for the long way isn't wrong exactly, it's just needless extra work that (8.6.1) exists specifically to skip.

Practice

  1. g(x) = ∫[0,x] 3t² dt. Find g′(x).
    \(3x^2\)
  2. g(x) = ∫[1,x] (5−t) dt. Find g′(x).
    \(5-x\)
  3. g(x) = ∫[0,x] eᵗ dt. Find g′(x).
    \(e^x\)
  4. g(x) = ∫[2,x] sin(t) dt. Find g′(x).
    \(\sin x\)
  5. h(x) = ∫[0,x] (t³ + 2t) dt. Find h′(x).
    \(x^3+2x\)
  6. True or false: to find g′(x) where g(x) = ∫[a,x] f(t)dt, you must first find an antiderivative of f.
    False — FTC1 (8.6.1) gives \(g'(x)=f(x)\) directly, no antiderivative required.
  7. bonus — g(x) = ∫[−1,x] (4t−7) dt. Find g′(3).
    \(g'(x)=4x-7\), so \(g'(3)=12-7=5\).
  8. bonus — If g(x) = ∫[0,x] f(t)dt and g′(x) = x² − 4, what is f(x)?
    \(f(x)=x^2-4\) — read directly off (8.6.1).
  9. bonus — g(x) = ∫[5,x] √t dt (for x > 0). Find g′(x).
    \(\sqrt{x}\)
  10. bonus — In one sentence, explain what g(x) = ∫[a,x] f(t)dt represents as x varies.
    The (signed) area accumulated from \(a\) up to \(x\), as a function of where the accumulation stops.
  11. challenge — Without evaluating any integral, explain why g(x) = ∫[a,x] f(t)dt must be an increasing function everywhere f(x) > 0, using FTC1 together with Module 6/7's derivative-sign test.
    By FTC1 (8.6.1), \(g'(x)=f(x)\). Wherever \(f(x)>0\), that means \(g'(x)>0\) there too — and Module 6/7's increasing-function test says a positive derivative on an interval means the function is increasing on it. So \(g\) increases exactly where \(f\) is positive, with zero integration needed to see it.
