Chapter 11 · concept:trig-integrals

Integrals of Trig Functions

A focused reference chapter: the three trig antiderivatives worth having memorized cold, now combined with Chapter 9's substitution technique.

Why this matters

Module 6 Chapter 8 built the derivatives of sine, cosine, and tangent. Each of those facts has a direct reverse — an antiderivative fact this chapter simply names. The only real subtlety is a sign: cosine's derivative loses one, but sine's antiderivative gains one, and mixing that up is the single most common slip in this chapter.

Rule — Trig Integrals (Reference Table)
\[ \begin{aligned} \int \sin x\,dx &= -\cos x + C \\ \int \cos x\,dx &= \sin x + C \\ \int \sec^2 x\,dx &= \tan x + C \end{aligned} \]
(8.11.1)

Each is the direct reverse of a Module 6 Chapter 8 derivative fact, checkable by differentiating the right-hand side straight back.

Worked example — combined with u-substitution

Evaluate ∫sin(3x) dx.

Step 1 — substitute the inside function

\(u=3x\), \(du=3\,dx \Rightarrow dx=du/3\).

Step 2 — rewrite and integrate using (8.11.1)

\(\displaystyle\int\sin u\cdot\frac{du}{3} = \frac13(-\cos u)+C = -\frac13\cos u + C\)

Result — substitute back

\(-\dfrac13\cos(3x)+C\)

Worked example — a second combination

Evaluate ∫x·sec²(x²) dx.

Step 1 — substitute

\(u=x^2\), \(du=2x\,dx \Rightarrow x\,dx=du/2\).

Result

\(\displaystyle\int\sec^2u\cdot\frac{du}{2} = \frac12\tan u+C = \frac12\tan(x^2)+C\)

Common mistake

Mixing up which trig antiderivative picks up a negative sign. Compare carefully: d/dx[cos x] = −sin x, but ∫sin x dx = −cos x + C — the negative moves from being on the derivative of cosine to being on the antiderivative of sine. Meanwhile d/dx[sin x] = cos x and ∫cos x dx = sin x + C — no sign change either direction. It's tempting to assume the negative "belongs" to whichever function looks like it should carry it, but it's specifically sine's antiderivative that flips sign, not cosine's.

Practice

  1. Evaluate ∫cos(5x) dx.
    \(\dfrac15\sin(5x)+C\)
  2. Evaluate ∫sec²(4x) dx.
    \(\dfrac14\tan(4x)+C\)
  3. Evaluate ∫3sin(x) dx.
    \(-3\cos x+C\)
  4. Evaluate ∫x²sec²(x³) dx.
    \(u=x^3\): \(\dfrac13\tan(x^3)+C\)
  5. Evaluate ∫[0,π/4] sec²(x) dx.
    \(\big[\tan x\big]_0^{\pi/4}=1-0=1\)
  6. Evaluate ∫cos(x)sin⁴(x) dx.
    \(u=\sin x\): \(\dfrac{\sin^5x}{5}+C\)
  7. bonus — Evaluate ∫sin(x)cos(x) dx.
    \(u=\sin x\): \(\dfrac{\sin^2x}{2}+C\) (an equally valid equivalent form, \(-\cos^2x/2+C'\), comes from choosing \(u=\cos x\) instead — both are correct, differing only in which constant absorbs the shift).
  8. bonus — Evaluate ∫4x sin(x²) dx.
    \(u=x^2\), \(4x\,dx=2\,du\): \(-2\cos(x^2)+C\)
  9. bonus — Evaluate ∫sec²(x)tan(x) dx.
    \(u=\tan x\): \(\dfrac{\tan^2x}{2}+C\)
  10. bonus — True or false: ∫cos(x) dx = −sin(x) + C.
    False — \(\int\cos x\,dx=\sin x+C\), no negative. The negative sign belongs to sine's antiderivative, not cosine's (8.11.1).
  11. challenge — Evaluate ∫[0,π] sin(x)cos(x) dx using bound conversion (Chapter 10), and sanity-check the result using symmetry (is sin(x)cos(x) positive, negative, or does it change sign on [0,π]?).
    \(u=\sin x\). Bounds: \(x=0\Rightarrow u=0\); \(x=\pi\Rightarrow u=0\) — both bounds map to the same u-value, so \(\int_0^0u\,du=0\) trivially. Sanity check: \(\sin x\cos x=\tfrac12\sin(2x)\) is positive on \((0,\pi/2)\) and negative on \((\pi/2,\pi)\), and by symmetry the two halves cancel exactly — confirming \(0\) makes sense.
