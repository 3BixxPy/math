The Average Value of a Function

Averaging a handful of numbers is old news — add them up, divide by how many. Averaging a function's value over a continuum of infinitely many inputs needs the integral to make "add them all up" mean anything at all.

Why this matters

The average of \(n\) numbers is \(\frac1n\sum\) of them — a sum divided by a count. A function takes infinitely many values on an interval, so there's no "count" to divide by in the usual sense. But a Riemann sum is a sum, and \((b-a)\) plays the role the count would — this chapter's formula is exactly that averaging idea, carried through the same limit that built the integral in the first place.

Theorem — Average Value of a Function
\[ f_{\text{avg}} = \frac{1}{b-a}\int_a^b f(x)\,dx \]
(8.13.1)

The Mean Value Theorem for Integrals guarantees that, for a continuous f, some point c in [a,b] actually achieves this average: f(c) = f_avg — the function doesn't just average out to this number abstractly, it genuinely equals it somewhere on the interval.

Worked example

Find the average value of f(x) = x² on [0, 3].

Step 1 — evaluate the integral (Chapter 7)

\(\displaystyle\int_0^3 x^2\,dx = \Big[\frac{x^3}{3}\Big]_0^3 = 9\)

Step 2 — divide by (b − a), by (8.13.1)

\(f_{\text{avg}} = \dfrac{1}{3-0}(9) = 3\)

Result — confirming the Mean Value Theorem for Integrals

Somewhere in \([0,3]\), \(f(c)=3\) exactly: \(c^2=3 \Rightarrow c=\sqrt3\approx1.73\), which is indeed in \([0,3]\) ✓.

Common mistake

Confusing average value of a function (this chapter — an integral, divided by interval length) with average rate of change (Module 6 Chapter 1 — a difference quotient, (f(b)−f(a))/(b−a)). They sound alike and both involve dividing by b−a, but they're different questions about different things: one asks "what value does f spend most of its 'time' near," the other asks "how much did f change, on average, per unit of x." Take f(x) = x³ on [0,2]: average value is \(\frac12\int_0^2x^3dx=\frac12(4)=2\), while average rate of change is \(\frac{f(2)-f(0)}{2}=\frac{8}{2}=4\) — genuinely different numbers, from genuinely different formulas.

Practice

  1. Find the average value of f(x) = x on [0, 6].
    \(\frac16\int_0^6x\,dx=\frac16(18)=3\)
  2. Find the average value of the constant function f(x) = 3 on [0, 10].
    \(3\) — a constant function's average value is always just itself.
  3. Find the average value of f(x) = x² on [0, 1].
    \(\frac11\int_0^1x^2dx=1/3\)
  4. Find the average value of f(x) = eˣ on [0, 1].
    \(\frac11(e-1)=e-1\) — since \(b-a=1\) here, the average value equals the integral itself.
  5. Find the average rate of change (not average value) of f(x) = x² on [1, 4].
    \(\dfrac{f(4)-f(1)}{4-1}=\dfrac{16-1}{3}=5\)
  6. True or false: the average value of f on [a,b] always equals f((a+b)/2), its value at the midpoint.
    False in general — only true for linear functions. A curved function spends unequal "amounts" above and below its midpoint value.
  7. bonus — Find the average value of f(x) = 4 − x² on [−2, 2].
    \(\frac14\int_{-2}^2(4-x^2)dx=\frac14\left(\frac{32}{3}\right)=\frac83\)
  8. bonus — Find the average value of f(x) = sin(x) on [0, π].
    \(\frac1\pi\int_0^\pi\sin x\,dx=\frac1\pi(2)=\frac2\pi\)
  9. bonus — For the chapter's own worked example (f(x)=x² on [0,3]), the Mean Value Theorem for Integrals guarantees some c with f(c)=3. Find both real solutions of c²=3, and explain why only one qualifies.
    \(c=\pm\sqrt3\); only \(c=\sqrt3\approx1.73\) lies in \([0,3]\), so that's the one the theorem is pointing to.
  10. bonus — A car's velocity is v(t) = 3t² (m/s) for t in [0, 4]. Find its average velocity over this interval.
    \(\frac14\int_0^4 3t^2\,dt=\frac14\big[t^3\big]_0^4=\frac14(64)=16\) m/s
  11. challenge — Explain why the Mean Value Theorem for Integrals is the "integral-flavored twin" of Module 7's Mean Value Theorem for derivatives — specifically, using FTC2, show that f's average value equals the average rate of change of one of its own antiderivatives.
    Let \(F\) be an antiderivative of \(f\), so \(F'=f\). By FTC2, \(\int_a^bf(x)dx=F(b)-F(a)\), so \(f_{\text{avg}}=\frac{1}{b-a}\int_a^bf(x)dx=\frac{F(b)-F(a)}{b-a}\) — exactly \(F\)'s average rate of change over \([a,b]\). Module 7's MVT guarantees a point where \(F'(c)\) equals that average rate of change; since \(F'=f\), that's precisely \(f(c)=f_{\text{avg}}\) — the same guarantee, viewed through \(F\) instead of \(f\) directly.
