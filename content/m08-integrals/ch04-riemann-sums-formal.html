Riemann Sums — the Formal Limit

Chapter 3 built rectangles by hand and watched the estimate improve as they got thinner. This chapter writes down, precisely, what "thinner and more numerous" means — using the exact limit machinery Module 5 spent twelve chapters building, seemingly for its own sake at the time.

Why this matters

"Use more rectangles" is an instruction, not a number. To turn Chapter 3's improving estimates into one exact value, "more and thinner" has to become a genuine limit — the same kind of limit Module 5 spent an entire module formalizing, applied here to a sum instead of a single expression. This is precisely the moment that machinery was built for.

Definition — Riemann Sum

Partition [a, b] into n equal subintervals of width Δx = (b−a)/n, and pick a sample point xᵢ in each one (the right endpoint, say). The Riemann sum is the total area of the resulting rectangles, written compactly with sigma notation:

\[ \sum_{i=1}^{n} f(x_i)\,\Delta x \]

This is just Chapter 3's left/right-endpoint sums, given a name and a compact notation — nothing new happened yet, only formalizing what was already being computed by hand.

Theorem — The Definite Integral, Defined as a Limit
\[ \int_a^b f(x)\,dx \;=\; \lim_{n\to\infty} \sum_{i=1}^{n} f(x_i)\,\Delta x \]
(8.4.1)

This is the formal definition of the symbol ∫ₐᵇ f(x) dx — not a computation shortcut, the actual definition. As n → ∞, Δx = (b−a)/n → 0 automatically, so "infinitely many, infinitesimally thin rectangles" is exactly what this limit captures. Whatever number this limit settles on (when it exists) is, by definition, the value of the definite integral — Chapter 3's bracketing left/right estimates were sandwiching this exact number the whole time, even before it had a name.

Worked example

Set up (not evaluate) the Riemann sum limit for the area under f(x) = x² on [0, 2] — the exact function and interval from Chapter 3.

Step 1 — find Δx and the sample points (right endpoints)

\(\Delta x = \dfrac{2-0}{n} = \dfrac{2}{n}\). Right endpoints: \(x_i = 0 + i\Delta x = \dfrac{2i}{n}\), for \(i=1,\dots,n\).

Step 2 — write the Riemann sum

\(\displaystyle\sum_{i=1}^n f(x_i)\Delta x = \sum_{i=1}^n \left(\frac{2i}{n}\right)^2 \cdot \frac{2}{n}\)

Result — the full limit expression, by (8.4.1)

\(\displaystyle\int_0^2 x^2\,dx = \lim_{n\to\infty}\sum_{i=1}^n \left(\frac{2i}{n}\right)^2\frac{2}{n}\). This is exact — no approximation left — but evaluating a limit of a growing sum by hand, term by term, is genuinely painful. The rest of this module is about to hand you a shortcut that never requires taking a limit like this directly.

Common mistake

Misindexing the sigma notation — using the wrong x-value for the wrong rectangle. For a right-endpoint sum over n pieces, the sample points are \(x_1,x_2,\dots,x_n\) (starting the count at \(i=1\)); for a left-endpoint sum, they're \(x_0,x_1,\dots,x_{n-1}\) (starting at \(i=0\)). Mixing these up — say, writing \(x_i = a+i\Delta x\) for \(i=1,\dots,n\) but intending left endpoints — silently shifts every rectangle over by one, quietly turning a left-endpoint sum into a right-endpoint one (or vice versa) without changing the notation's appearance. Always double check which endpoint your index is actually landing on before trusting the formula.

Practice

  1. Write the right-endpoint Riemann sum (sigma notation) for f(x) = x³ on [1, 4] with n subintervals — state Δx and xᵢ first.
    \(\Delta x=\frac{3}{n}\), \(x_i=1+\frac{3i}{n}\). Sum: \(\displaystyle\sum_{i=1}^n\left(1+\frac{3i}{n}\right)^3\frac{3}{n}\).
  2. Write the left-endpoint Riemann sum for f(x) = cos(x) on [0, π] with n subintervals.
    \(\Delta x=\frac{\pi}{n}\), \(x_i=\frac{i\pi}{n}\) for \(i=0,\dots,n-1\). Sum: \(\displaystyle\sum_{i=0}^{n-1}\cos\!\left(\frac{i\pi}{n}\right)\frac{\pi}{n}\).
  3. For f(x) = x² on [0, 6], n = 12, what is Δx?
    \(\Delta x = 6/12 = 0.5\)
  4. For f(x) = 1/x on [1, 5], n subintervals, what is the right-endpoint sample point xᵢ in terms of i and n?
    \(x_i = 1 + \dfrac{4i}{n}\)
  5. True or false: increasing n always makes a Riemann sum a better approximation of the exact area.
    True (for the well-behaved functions this course works with) — more, thinner rectangles track the curve more closely, which is exactly why the limit as \(n\to\infty\) is defined to be the exact value (8.4.1).
  6. What does "Δx → 0" correspond to in terms of n?
    \(n\to\infty\) — since \(\Delta x=(b-a)/n\) with \(a,b\) fixed, letting \(n\) grow without bound forces \(\Delta x\) to shrink toward 0.
  7. bonus — Write, but don't evaluate, the definite-integral notation for the limit of the Riemann sum for f(x) = eˣ on [0, 1].
    \(\displaystyle\int_0^1 e^x\,dx\)
  8. bonus — If Δx = (b−a)/n and a = 2, b = 10, n = 16, find Δx.
    \(\Delta x = 8/16 = 0.5\)
  9. bonus — In one sentence each, distinguish a Riemann sum using left-endpoints, right-endpoints, and midpoints.
    Left: each rectangle's height comes from the curve at the left edge of its subinterval. Right: from the right edge. Midpoint: from the point exactly halfway across each subinterval.
  10. bonus — For f(x) = x² on [0, 2], n = 4, list the four right-endpoint sample points x₁,…,x₄ explicitly (values only, don't evaluate f yet).
    \(0.5,\ 1,\ 1.5,\ 2\)
  11. challenge — Explain, using Module 5's vocabulary, why "the Riemann sum as n → ∞" is itself a limit statement, and why its precise meaning is stated as Δx → 0 rather than just "n gets bigger."
    "n gets bigger" describes a process, not a target value — exactly the kind of informal phrasing Module 5 replaced with precise limit language. Since \(\Delta x=(b-a)/n\) for a fixed interval, \(n\to\infty\) forces \(\Delta x\to0\) automatically; writing it as \(\Delta x\to0\) is the version that directly names what's actually shrinking (the rectangles' width) and connects cleanly to the same "approaching a value" idea Module 5 formalized for ordinary limits — this is that same idea, just applied to a sum with a growing number of terms instead of a single expression.
