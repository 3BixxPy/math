Antiderivative Rules

Chapter 1 defined the general antiderivative and its "+C," and found one by guess-and-check. This chapter builds an actual toolkit — direct mirror images of Module 6's own differentiation rules, each one run backward.

Why this matters

Guessing worked for \(x^2\) because the answer was easy to see coming. It won't stay easy once terms pile up. But every rule Module 6 built for taking derivatives can, in principle, be read in reverse — and for the simplest ones (a power, a sum, a constant multiple, and a handful of named functions) reading them backward gives a clean, mechanical rule with no guessing required.

Rule — The Power Rule, Reversed
\[ \int x^n\,dx = \frac{x^{n+1}}{n+1} + C \qquad (n \neq -1) \]
(8.2.1)

Raise the exponent by 1, then divide by that new exponent — exactly the reverse order of Module 6's power rule, which multiplies by the old exponent then lowers it. The \(n\neq-1\) restriction isn't fine print; the mistake block below shows exactly where it bites.

Two more direct reversals round out the basic toolkit, mirroring Module 6 Chapter 5's sum/difference and constant-multiple rules:

\[ \int \big[f(x)\pm g(x)\big]\,dx = \int f(x)\,dx \pm \int g(x)\,dx \qquad\qquad \int c\,f(x)\,dx = c\int f(x)\,dx \]

In plain terms: integrate term by term, and constant factors ride along unchanged. A short reference list of named functions, each the direct reverse of a Module 6 fact (full trig table comes in Chapter 11):

\[ \int \sin x\,dx = -\cos x + C \qquad \int \cos x\,dx = \sin x + C \qquad \int e^x\,dx = e^x + C \]

Worked example

Find the general antiderivative of f(x) = 3x⁴ − 2sin(x) + eˣ, term by term.

Step 1 — split the sum/difference, keep constants along for the ride

\(\displaystyle\int\!\big(3x^4-2\sin x+e^x\big)dx = 3\!\int\! x^4\,dx \;-\; 2\!\int\!\sin x\,dx \;+\!\int\! e^x\,dx\)

Step 2 — apply the power rule (8.2.1) to the first term

\(3\displaystyle\int x^4\,dx = 3\cdot\frac{x^5}{5} = \frac{3x^5}{5}\)

Step 3 — apply the sine and exponential facts to the rest

\(-2\displaystyle\int\sin x\,dx = -2(-\cos x) = 2\cos x\), and \(\displaystyle\int e^x\,dx = e^x\).

Result — combine, one "+C" for the whole family

\(\dfrac{3x^5}{5} + 2\cos x + e^x + C\). Each piece could in principle carry its own constant, but any sum of constants is still just some constant — one "+C" at the end covers the whole family.

Common mistake

Trying to apply the reversed power rule (8.2.1) to \(f(x)=x^{-1}=1/x\). The rule says divide by \(n+1\) — but here \(n=-1\), so \(n+1=0\), and dividing by zero breaks the formula completely; it simply doesn't apply. This case genuinely needs a different rule:

\[ \int \frac{1}{x}\,dx = \ln|x| + C \]

This is worth naming even though its full justification is still a few chapters off (Chapter 7 supplies it) — for now, treat it as the one named exception that the power rule can never cover, no matter how it's rewritten.

Practice

  1. Evaluate ∫x⁶ dx.
    \(\dfrac{x^7}{7}+C\)
  2. Evaluate ∫5x² dx.
    \(\dfrac{5x^3}{3}+C\)
  3. Evaluate ∫(x³ + x) dx.
    \(\dfrac{x^4}{4}+\dfrac{x^2}{2}+C\)
  4. Evaluate ∫cos(x) dx.
    \(\sin x + C\)
  5. Evaluate ∫3eˣ dx.
    \(3e^x+C\)
  6. Evaluate ∫(4x³ − 6x + 1) dx.
    \(x^4-3x^2+x+C\)
  7. bonus — Evaluate ∫1 dx (the constant function 1, i.e. x⁰).
    \(x+C\)
  8. bonus — Evaluate ∫(sin x + cos x) dx.
    \(-\cos x+\sin x+C\)
  9. bonus — In one sentence, explain why n = −1 breaks the power rule.
    The rule divides by \(n+1\); at \(n=-1\) that's division by zero, which is undefined.
  10. bonus — Evaluate ∫(2/x) dx.
    \(2\ln|x|+C\) — constant-multiple rule applied to the \(\ln|x|\) exception.
  11. challenge — Evaluate ∫(x² − 3/x + 4eˣ) dx, combining every rule from this chapter in one problem.
    \(\dfrac{x^3}{3} - 3\ln|x| + 4e^x + C\)
