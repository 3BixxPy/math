Linear Approximation & Differentials

Chapter 8 used the tangent line's slope to guarantee something exists. This chapter uses the tangent line itself — its actual equation — as a stand-in for the curve, close enough to estimate values without a calculator.

Why this matters

Zoom in far enough on any differentiable curve near a point, and it starts looking indistinguishable from its tangent line there — that's essentially what "differentiable" means. Since a line's equation is trivial to evaluate (Module 1's slope-intercept form), this turns into a genuinely practical estimation tool: swap the curve for its tangent line near a point you already know exactly, and read off nearby values.

Theorem — Linear approximation
\[ L(x) = f(a) + f'(a)(x-a) \]
(7.9.1)

This is nothing but the point-slope equation of the tangent line at \(x=a\) (Module 1), repurposed: \(L(x)\approx f(x)\) for \(x\) close to \(a\). The same idea is often written in differential notation: \(dy = f'(x)\,dx\), where \(dx\) is a small change in \(x\) and \(dy\) is the tangent line's corresponding change in height — the linear stand-in for the curve's actual change, \(\Delta y\).

Worked example — estimating √4.1
Step 1 — choose f and a nearby "nice" point a

\(f(x)=\sqrt x\), and \(a=4\) since \(\sqrt4=2\) is exact and easy.

Step 2 — compute f(a) and f′(a)

\(f(4)=2\). \(f'(x)=\dfrac{1}{2\sqrt x}\), so \(f'(4)=\dfrac14\).

Step 3 — plug into (7.9.1) with x=4.1

\(L(4.1) = 2 + \dfrac14(4.1-4) = 2 + \dfrac14(0.1) = 2.025\)

Result

\(\sqrt{4.1}\approx2.025\) — the true value is \(\approx2.02485\), so the estimate is accurate to within \(0.0002\), entirely by hand.

Common mistake

Using linear approximation far from the base point a, where the tangent line has visibly diverged from the actual curve. Estimating √9 using the same tangent line as above (still \(a=4\)): \(L(9)=2+\tfrac14(9-4)=2+1.25=3.25\), while the true value is \(\sqrt9=3\) exactly — off by about \(8\%\), a real, visible error, compared to the earlier estimate's near-perfect accuracy at \(x=4.1\). The technique is only reliable for x genuinely close to a; the further away, the more the tangent line's straightness betrays it, since the actual curve keeps bending away from it.

Try it yourself

Using linear approximation of f(x) = x² near a = 3, estimate f(3.1).

Practice

  1. Estimate √9.1 using linear approximation with a = 9.
    \(f(9)=3\), \(f'(9)=1/6\). \(L(9.1)=3+\tfrac16(0.1)\approx3.0167\)
  2. Estimate (2.02)³ using linear approximation of f(x)=x³ with a=2.
    \(f(2)=8\), \(f'(2)=12\). \(L(2.02)=8+12(0.02)=8.24\)
  3. Estimate 1/4.9 using linear approximation of f(x)=1/x with a=5.
    \(f(5)=0.2\), \(f'(5)=-1/25=-0.04\). \(L(4.9)=0.2-0.04(-0.1)=0.204\)
  4. Estimate √16.2 using linear approximation with a=16.
    \(f(16)=4\), \(f'(16)=1/8\). \(L(16.2)=4+\tfrac18(0.2)=4.025\)
  5. Estimate sin(0.1) using linear approximation of f(x)=\sin x with a=0.
    \(f(0)=0\), \(f'(0)=\cos0=1\). \(L(0.1)=0+1(0.1)=0.1\) — this is exactly the small-angle approximation from trigonometry (Module 2 / Module 5), now derived rather than just asserted.
  6. Estimate (8.1)^{1/3} using linear approximation of f(x)=x^{1/3} with a=8.
    \(f(8)=2\), \(f'(8)=\tfrac13(8)^{-2/3}=1/12\). \(L(8.1)=2+\tfrac1{12}(0.1)\approx2.0083\)
  7. bonus — Use differentials (dA = 2πr\,dr) to estimate the change in a circle's area when its radius grows from 5 to 5.1.
    \(dA=2\pi(5)(0.1)=\pi\approx3.14\)
  8. bonus — Estimate ln(1.05) using linear approximation of f(x)=\ln x with a=1.
    \(f(1)=0\), \(f'(1)=1\). \(L(1.05)=0+1(0.05)=0.05\)
  9. bonus — Estimate √3.98 using a=4, and explain why this is more trustworthy than approximating it using a=1 instead.
    \(L(3.98)=2+\tfrac14(-0.02)=1.995\). This is reliable because \(\Delta x=-0.02\) is tiny; using \(a=1\) would mean \(\Delta x=2.98\), far enough that the tangent line at \(a=1\) has already diverged badly from the curve (see the Common Mistake box).
  10. bonus — Find the linear approximation formula L(x) for f(x)=e^x at a=0, then use it to estimate e^{0.05}.
    \(f(0)=1\), \(f'(0)=1\), so \(L(x)=1+x\). \(L(0.05)=1.05\).
  11. challenge — A cube's side is measured as 5 cm with a possible error of ±0.1 cm. Use differentials (dV=3x²\,dx) to estimate the resulting error in the computed volume, as a percentage of the true volume.
    \(dV=3(25)(0.1)=7.5\) cm³. True volume \(V=125\) cm³. Percent error \(\approx7.5/125=6\%\) — a small measurement error can create a noticeably larger percentage error in a cubed quantity, a real engineering use of differentials.
