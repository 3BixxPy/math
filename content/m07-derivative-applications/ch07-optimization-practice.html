Optimization — More Problems

No new theorem this chapter — Chapter 6's six-step strategy is the whole toolkit. This is where it gets fluent, on two classic setups, plus one genuinely useful technique for keeping the algebra clean.

Why this matters

The strategy from Chapter 6 doesn't get harder with more practice — the word problems just get more varied in how they hide the constraint. An open-top box and a distance-minimization problem look nothing alike on the surface, but both collapse to the exact same six steps once the objective and constraint are identified.

Worked example — the open-top box

An open-top box is made by cutting equal squares of side x from each corner of a 12×12 sheet of cardboard and folding up the sides. What value of x maximizes the box's volume?

Step 1 — set up the volume as a function of x

After folding, the base is \((12-2x)\) by \((12-2x)\), and the height is \(x\): \(V(x) = x(12-2x)^2\).

Step 2 — state the valid domain

Both the cut size and the resulting base need to stay positive: \(0

Step 3 — differentiate (product + chain rule, Module 6) and find critical points

\(V'(x) = (12-2x)^2 + x\cdot2(12-2x)(-2) = (12-2x)\big[(12-2x)-4x\big] = (12-2x)(12-6x)\). Zero at \(x=6\) (excluded — it's the domain's edge, giving zero volume) or \(x=2\).

Step 4 — classify and check the domain

\(x=2\) is comfortably inside \((0,6)\), and \(V\) rises then falls around it (or check \(V''<0\) there) — a local max.

Result

\(x=2\) maximizes volume, giving \(V(2)=2(8)^2=128\).

Worked example — minimum distance to a curve

Find the point on y = x² closest to (0, 3).

Step 1 — write the distance, but minimize its square instead

\(D=\sqrt{x^2+(y-3)^2}\) with \(y=x^2\), so \(D=\sqrt{x^2+(x^2-3)^2}\) — a square root with a fourth-degree polynomial underneath, unpleasant to differentiate. Minimize \(D^2\) instead:

\(D^2(x) = x^2+(x^2-3)^2 = x^4-5x^2+9\)

Step 2 — differentiate the clean polynomial and find critical points

\(\dfrac{d}{dx}[D^2] = 4x^3-10x = 2x(2x^2-5) = 0 \Rightarrow x=0 \text{ or } x^2=2.5\)

Step 3 — compare the candidates

At \(x=0\): \(D^2=9\). At \(x=\pm\sqrt{2.5}\): \(D^2=(2.5)^2-5(2.5)+9=2.75\) — smaller.

Result

Minimum distance occurs at \(x=\pm\sqrt{2.5}\approx\pm1.58\), giving \(D=\sqrt{2.75}\approx1.66\).

Common mistake — and the technique that avoids it

Optimizing the wrong quantity: minimizing D directly instead of D². Differentiating D(x)=\sqrt{x^4-5x^2+9} requires the chain rule wrapped around a messy inner polynomial — technically doable, but error-prone and slow. Minimizing D² instead gives the exact same critical x-values, because squaring is a strictly increasing operation for non-negative numbers: whatever \(x\) makes \(D^2\) smallest also makes \(D=\sqrt{D^2}\) smallest, since the square root preserves order. This isn't a shortcut that risks the wrong answer — it's a deliberate, standard technique. Always minimize the squared distance when the objective is a distance.

Try it yourself

An open-top box is folded from a 6×6 sheet, cutting squares of side x from each corner. What value of x maximizes the volume?

Practice

  1. Open-top box from a 10×10 sheet: find the x that maximizes volume.
    \(V(x)=x(10-2x)^2\), \(V'=(10-2x)(10-6x)=0\Rightarrow x=5/3\) (the other root, \(x=5\), gives zero volume)
  2. Open-top box from a 16×16 sheet: find the x that maximizes volume.
    \(V(x)=x(16-2x)^2\), \(V'=(16-2x)(16-6x)=0\Rightarrow x=8/3\)
  3. Find the point on y = \sqrt{x} closest to (3, 0).
    \(D^2(x)=(x-3)^2+x=x^2-5x+9\) (using \(y^2=x\) to avoid the root entirely). \(\tfrac{d}{dx}D^2=2x-5=0\Rightarrow x=2.5\), \(y=\sqrt{2.5}\)
  4. Find the point on the line y = x + 4 closest to the origin.
    \(D^2(x)=x^2+(x+4)^2=2x^2+8x+16\), \(\tfrac{d}{dx}D^2=4x+8=0\Rightarrow x=-2, y=2\). Minimum distance \(=\sqrt{8}=2\sqrt2\).
  5. A closed box with a square base has fixed volume 32. Minimize its surface area.
    \(V=x^2h=32\Rightarrow h=32/x^2\). \(S=x^2+4xh=x^2+128/x\). \(S'=2x-128/x^2=0\Rightarrow x^3=64\Rightarrow x=4\), \(h=2\)
  6. Find the point on y = x² closest to (0, 5).
    \(D^2(x)=x^2+(x^2-5)^2=x^4-9x^2+25\), \(\tfrac{d}{dx}D^2=4x^3-18x=2x(2x^2-9)=0\). Comparing \(x=0\) (\(D^2=25\)) to \(x=\pm\sqrt{4.5}\) (\(D^2=4.75\)), the minimum is at \(x=\pm\sqrt{4.5}\).
  7. bonus — Open-top box from a 20×20 sheet: find the x that maximizes volume.
    \(V'=(20-2x)(20-6x)=0\Rightarrow x=10/3\)
  8. bonus — Find the point on y = \sqrt{x} closest to (6, 0).
    \(D^2(x)=(x-6)^2+x=x^2-11x+36\), \(\tfrac{d}{dx}D^2=2x-11=0\Rightarrow x=5.5\)
  9. bonus — A closed box with a square base has fixed volume 8. Minimize its surface area.
    \(S=2x^2+32/x\), \(S'=4x-32/x^2=0\Rightarrow x^3=8\Rightarrow x=2\), \(h=8/4=2\) — a cube
  10. bonus — In one sentence, explain why minimizing D² instead of D gives the same critical x-value.
    Squaring a non-negative quantity is order-preserving, so whatever \(x\) minimizes \(D^2\) automatically minimizes \(D=\sqrt{D^2}\) as well — same critical point, far cleaner algebra.
