Chapter 15 · concept:inverse-trig-derivatives

Derivatives of Inverse Trig Functions

The last new differentiation facts in this module — and a genuine three-module synthesis. Chapter 14's inverse-derivative formula, Chapter 8's sine derivative, and Module 2 Chapter 9's Pythagorean identity all combine into one clean result.

Why this matters

Nothing about arcsin x or arctan x looks like it should have a simple derivative — one is an angle-valued function, the other emerged from a domain-restricted piece of tangent. Yet both differentiate down to plain algebraic expressions, no trig functions in the final answer at all. That's not a coincidence to memorize around; it's a direct, traceable consequence of tools already built: Chapter 14 turns "derivative of an inverse" into "reciprocal of the original function's derivative," and the Pythagorean identity (Module 2 Chapter 9) is exactly what converts the leftover trig expression into something purely in terms of x.

Theorem — Two inverse trig derivatives
\[ \frac{d}{dx}\left[\arcsin x\right] = \frac{1}{\sqrt{1-x^2}} \]
(6.15.1)
\[ \frac{d}{dx}\left[\arctan x\right] = \frac{1}{1+x^2} \]
(6.15.2)
Worked derivation — d/dx[arcsin x], step by step

Derive (6.15.1) using Chapter 14's inverse-function formula.

Step 1 — set y = arcsin x, so x = sin y (Module 2 Chapter 13's definition)

By definition, \(y=\arcsin x \iff x=\sin y\), with \(y\) restricted to \([-\pi/2,\pi/2]\).

Step 2 — apply (6.14.1) with f = sin, f' = cos (Chapter 8)

\(\dfrac{dy}{dx} = \left(\arcsin\right)'(x) = \dfrac{1}{f'(f^{-1}(x))} = \dfrac{1}{\cos y}\)

Step 3 — the answer is in terms of y, but it needs to be in terms of x — bring in the Pythagorean identity

\(\sin^2y+\cos^2y=1\) (Module 2, equation 2.9.1) \(\Rightarrow \cos y = \pm\sqrt{1-\sin^2y}\). Since \(x=\sin y\) (Step 1): \(\cos y = \pm\sqrt{1-x^2}\).

Step 4 — resolve the sign using the restricted range

\(y\in[-\pi/2,\pi/2]\) is exactly the range where cosine is never negative (it's 0 only at the two endpoints). So the \(+\) sign is the only one that can be correct here: \(\cos y = +\sqrt{1-x^2}\).

Result

\(\dfrac{dy}{dx} = \dfrac{1}{\cos y} = \dfrac{1}{\sqrt{1-x^2}}\) — equation (6.15.1). Three modules' worth of tools, none of them re-derived from scratch: Module 1's inverse-function idea (Chapter 14's version of it), Module 2's Pythagorean identity, and Module 6's own inverse-derivative formula.

The same idea for arctan, more briefly

Let y = arctan x, so x = tan y. By (6.14.1) with f = tan, f' = sec² (Chapter 8): dy/dx = 1/sec²y. Module 2 Chapter 10's identity (equation 2.10.1) gives sec²y = 1 + tan²y, and since x = tan y, that's 1 + x². So dy/dx = 1/(1+x²) — equation (6.15.2), by the identical strategy, one identity swapped for another.

Worked example — chain rule on an inverse trig function

Differentiate arcsin(2x).

Step 1 — outside/inside (Ch. 9): outside is arcsin(u), inside is u=2x

Outside's derivative, from (6.15.1): \(\dfrac{1}{\sqrt{1-u^2}}\), evaluated at \(u=2x\): \(\dfrac{1}{\sqrt{1-(2x)^2}} = \dfrac{1}{\sqrt{1-4x^2}}\).

Step 2 — multiply by the inside's derivative

\(\dfrac{d}{dx}[2x]=2\)

Result

\(\dfrac{2}{\sqrt{1-4x^2}}\)

Common mistake

Forgetting the chain rule's inner-derivative factor whenever the argument isn't just plain x — exactly Chapter 9's mistake, showing up again in this new family of functions. For arctan(3x), it's tempting to write 1/(1+(3x)²) and stop — but that's only the "outside" piece from (6.15.2); the inside function 3x has its own derivative, 3, that still needs to be multiplied in. The correct derivative is 3/(1+9x²), not 1/(1+9x²). Any time the argument of arcsin, arccos, or arctan is something other than a bare x, the chain rule is in play, no exceptions.

Try it yourself

Find d/dx[arctan x].

Practice

  1. Find d/dx[arcsin x].
    \(1/\sqrt{1-x^2}\)
  2. Find d/dx[arctan(5x)].
    \(\dfrac{5}{1+25x^2}\)
  3. Find d/dx[arcsin(x/2)].
    \(\dfrac{1/2}{\sqrt{1-x^2/4}} = \dfrac{1}{2\sqrt{1-x^2/4}}\)
  4. Find d/dx[3arctan x].
    \(\dfrac{3}{1+x^2}\)
  5. Find d/dx[arctan(x²)].
    \(\dfrac{2x}{1+x^4}\)
  6. Find d/dx[arcsin(x) + arctan(x)].
    \(\dfrac{1}{\sqrt{1-x^2}} + \dfrac{1}{1+x^2}\)
  7. bonus — Find d/dx[x·arctan(x)], using the product rule.
    \(1\cdot\arctan x + x\cdot\dfrac{1}{1+x^2} = \arctan x + \dfrac{x}{1+x^2}\)
  8. bonus — Find d/dx[arcsin(3x-1)].
    \(\dfrac{3}{\sqrt{1-(3x-1)^2}}\)
  9. bonus — Evaluate d/dx[arctan x] at x=0, and explain how that value relates to the slope of tan(y) at y=0.
    \(1/(1+0)=1\). Since arctan and tan are inverses (mirrored over y=x), and tan's own derivative sec²(0)=1 as well, the two curves have matching (reciprocal-of-1-is-1) slopes exactly at the mirrored origin point — consistent with (6.14.1).
  10. bonus — Find d/dx[arctan(1/x)] for x≠0.
    Inner derivative of \(1/x\) is \(-1/x^2\) (Ch. 4). \(\dfrac{-1/x^2}{1+1/x^2} = \dfrac{-1/x^2}{(x^2+1)/x^2} = \dfrac{-1}{x^2+1}\)
  11. challenge — Using the same strategy as this chapter's arcsin derivation (Chapter 14's formula + a Module 2 identity + resolving a sign using the restricted range), derive d/dx[arccos x] = -1/√(1-x²) from scratch. (arccos's range is [0,π], where sine is never negative.)
    Let \(y=\arccos x\), so \(x=\cos y\), \(y\in[0,\pi]\). \(f=\cos\), \(f'=-\sin\) (6.8.2). By (6.14.1): \(dy/dx = 1/(-\sin y) = -1/\sin y\). Pythagorean identity: \(\sin y=\pm\sqrt{1-\cos^2y}=\pm\sqrt{1-x^2}\); on \([0,\pi]\) sine is never negative, so \(\sin y=+\sqrt{1-x^2}\). Result: \(dy/dx = -1/\sqrt{1-x^2}\) — same magnitude as arcsin's derivative, opposite sign, which makes sense since \(\arcsin x+\arccos x\) is a constant (π/2) for all valid x, so their derivatives must be exact opposites.
