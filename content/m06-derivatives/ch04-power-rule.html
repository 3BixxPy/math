Chapter 4 · concept:power-rule

The Power Rule

Chapter 2 ground through the limit definition by hand for f(x)=x² and f(x)=x³. That's not sustainable — real work needs a shortcut. This chapter is that shortcut, and it's the single most-used rule in the rest of this module.

Why this matters

Every worked-example derivative so far came from expanding, canceling, and taking a limit by hand — correct, but slow, and it would only get slower for anything more complicated than x² or x³. The power rule packages that entire limit-definition process into one formula, provably correct (Chapter 2 already showed it works for two specific cases), so that from here on, differentiating a power of x is arithmetic, not a fresh limit computation every time.

Rule — The power rule
\[ \frac{d}{dx}\left[x^n\right] = n\,x^{n-1} \]
(6.4.1)

Valid for any real number n — positive, negative, a fraction, anything. In words: bring the exponent down as a multiplying coefficient, then subtract 1 from the exponent. A full proof for general n is outside this course's scope, but it's not a leap of faith either — it's provable directly from the limit definition (6.2.1), the same way Chapter 2 did it by hand for n=2.

Sanity check — does the formula match Chapter 2's hand computation?

Verify (6.4.1) against the limit-definition results already found for n=2 and n=3.

n = 2

Formula: \(\dfrac{d}{dx}[x^2] = 2x^{2-1}=2x^1=2x\). Chapter 2's worked example, done fully from the limit definition, also got \(f'(x)=2x\). Match.

n = 3

Formula: \(\dfrac{d}{dx}[x^3] = 3x^{3-1}=3x^2\). Chapter 2's bonus problem, done from the limit definition using \((x+h)^3\), also got \(3x^2\). Match — the shortcut isn't a different rule, it's the same limit, pre-computed once and for all n.

Worked example — applying the rule, including the tricky rewrites

Differentiate x⁵, x^(1/2), and 1/x².

x⁵ — direct application

\(\dfrac{d}{dx}[x^5] = 5x^{5-1} = 5x^4\)

x^(1/2) — a radical is a rational exponent (Module 0)

\(\sqrt{x}=x^{1/2}\), so \(\dfrac{d}{dx}\left[x^{1/2}\right] = \dfrac12 x^{1/2-1} = \dfrac12 x^{-1/2} = \dfrac{1}{2\sqrt{x}}\) (rewriting the negative exponent back as a radical at the end, per Module 0's exponent laws).

1/x² — a reciprocal is a negative exponent (Module 0)

\(\dfrac{1}{x^2}=x^{-2}\), so \(\dfrac{d}{dx}\left[x^{-2}\right] = -2x^{-2-1} = -2x^{-3} = -\dfrac{2}{x^3}\)

Common mistake

Trying to apply (6.4.1) directly to √x or 1/x³ without first rewriting them as x^(1/2) or x⁻³. The power rule only "sees" an expression that's literally in the form xⁿ — a radical symbol or a fraction bar isn't automatically recognized as a power until it's rewritten using Module 0's exponent laws (rational exponents for roots, negative exponents for reciprocals). Skipping the rewrite step is the single most common way this rule gets misapplied — always convert first, differentiate second.

Try it yourself

Find d/dx[x⁴].

Practice

  1. Find d/dx[x⁷].
    \(7x^6\)
  2. Find d/dx[x]. (Rewrite as x¹ first.)
    \(1\cdot x^0 = 1\)
  3. Find d/dx[x^(1/3)].
    \(\frac13 x^{-2/3}\)
  4. Find d/dx[1/x].
    Rewrite as \(x^{-1}\): \(-1\cdot x^{-2} = -1/x^2\) (matches Chapter 2's challenge problem, done from the limit definition).
  5. Find d/dx[1/x⁴].
    Rewrite as \(x^{-4}\): \(-4x^{-5} = -4/x^5\)
  6. Find d/dx[x^(3/2)].
    \(\frac32 x^{1/2}\)
  7. bonus — Find d/dx[√[3]{x}] (cube root of x).
    Rewrite as \(x^{1/3}\): \(\frac13 x^{-2/3}\), same as problem 3 — same function, different notation.
  8. bonus — Find d/dx[1/√x].
    Rewrite as \(x^{-1/2}\): \(-\frac12 x^{-3/2}\)
  9. bonus — Find d/dx[x⁰], and explain the result using what x⁰ actually equals.
    \(x^0=1\) is a constant, and the derivative of any constant is 0 (foreshadowing Chapter 5) — also matches the formula formally: \(0\cdot x^{-1}=0\).
  10. bonus — Find d/dx[x^(-1/2)], then rewrite the result without a negative exponent.
    \(-\frac12 x^{-3/2} = -\dfrac{1}{2x^{3/2}} = -\dfrac{1}{2\sqrt{x^3}}\)
  11. challenge — Find d/dx[x^π] (π as a literal real-number exponent), and explain why (6.4.1) still applies even though π isn't rational.
    \(\pi\,x^{\pi-1}\). (6.4.1) is stated for any real \(n\), not just integers or rationals — the rewriting concerns from this chapter (roots, reciprocals) are about recognizing rational exponents in disguise, not a restriction on which real numbers the rule itself allows.
