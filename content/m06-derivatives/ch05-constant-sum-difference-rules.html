Constant, Sum & Difference Rules

The power rule differentiates a single power of x. Three small rules — none of them individually surprising — are what let that rule loose on an entire polynomial, term by term.

Why this matters

Nothing in this chapter is deep on its own — each rule is a short, believable statement. What they do together is powerful: they justify differentiating a polynomial like 3x⁴ − 5x² + 7x − 2 exactly the way it looks like it should work — one term at a time, ignore the rest, add the results. That "obviously it should work like that" instinct is correct, but it needs these three rules to actually be true, not just convenient.

Rule — Constant rule
\[ \frac{d}{dx}\left[c\right] = 0 \]
(6.5.1)

The derivative of a constant is always 0. Makes sense from the definition (6.2.1) directly: if f(x)=c for every x, then f(x+h)−f(x) = c−c = 0 for every h, so the whole difference quotient is 0 before any limit is even taken. Graphically: a constant function is a flat horizontal line, and a flat line's slope — everywhere, including its "tangent" — is 0.

Rule — Constant multiple rule
\[ \frac{d}{dx}\left[c\cdot f(x)\right] = c\cdot f'(x) \]
(6.5.2)

A constant factor just rides along unchanged — differentiate the function part, then multiply by the same constant you started with.

Rule — Sum & difference rules
\[ \frac{d}{dx}\left[f(x)\pm g(x)\right] = f'(x)\pm g'(x) \]
(6.5.3)

The derivative of a sum (or difference) is the sum (or difference) of the derivatives — differentiate each piece separately and combine. Together, (6.5.1)–(6.5.3) mean any polynomial can be differentiated term by term: apply the power rule (Chapter 4) to each power of x, scale by (6.5.2), drop any lone constant term via (6.5.1), and add the results via (6.5.3).

Worked example — a full polynomial, term by term

Differentiate f(x) = 3x⁴ − 5x² + 7x − 2.

Step 1 — 3x⁴: power rule (Ch. 4) then constant multiple rule (6.5.2)

\(\dfrac{d}{dx}[x^4]=4x^3\), so \(\dfrac{d}{dx}[3x^4] = 3\cdot4x^3 = 12x^3\).

Step 2 — −5x²: same pattern

\(\dfrac{d}{dx}[x^2]=2x\), so \(\dfrac{d}{dx}[-5x^2] = -5\cdot2x = -10x\).

Step 3 — 7x: x¹, power rule gives 1, then scale

\(\dfrac{d}{dx}[x]=1\), so \(\dfrac{d}{dx}[7x] = 7\cdot1 = 7\).

Step 4 — −2: constant rule (6.5.1)

\(\dfrac{d}{dx}[-2] = 0\) — it simply drops out.

Result — recombine via the sum/difference rule (6.5.3)

\(f'(x) = 12x^3 - 10x + 7 + 0 = 12x^3-10x+7\)

Common mistake

Treating the derivative of a constant as anything other than 0 — most often by confusing "a lone constant" with "a constant times x." d/dx[5] = 0 (a flat number, no x at all, per 6.5.1), but d/dx[5x] = 5 (a constant multiplying a genuine power of x, per 6.5.2 combined with the power rule). These look superficially similar — both have a "5" sitting there — but they are structurally different terms, and mixing them up (writing 5 where 0 belongs, or vice versa) is one of the most common slips in an otherwise-correct polynomial differentiation.

Find d/dx[5].

Practice

  1. Find d/dx[9].
    \(0\)
  2. Find d/dx[8x].
    \(8\)
  3. Find d/dx[x³ + x²].
    \(3x^2+2x\)
  4. Find d/dx[6x² − 4x + 9].
    \(12x-4\)
  5. Find d/dx[-2x³ + 3x - 1].
    \(-6x^2+3\)
  6. Find d/dx[x⁵ − x⁴ + x³ − x² + x − 1].
    \(5x^4-4x^3+3x^2-2x+1\)
  7. bonus — Find d/dx[7x^(1/2) - 3x].
    \(7\cdot\frac12x^{-1/2}-3 = \frac{7}{2\sqrt{x}}-3\)
  8. bonus — Find d/dx[4/x² + 2x²]. (Rewrite the first term first.)
    \(4x^{-2}+2x^2 \Rightarrow -8x^{-3}+4x = -8/x^3+4x\)
  9. bonus — If f(x) = ax² + bx + c for constants a, b, c, find f'(x) in terms of a, b, c.
    \(2ax+b\) — the same rules apply whether the coefficients are specific numbers or general letters.
  10. bonus — Explain, using (6.5.1) and (6.5.2), why d/dx[7] and d/dx[7x⁰] must be the same number even though they look different.
    \(x^0=1\) for \(x\neq0\), so \(7x^0=7\) is literally the same constant — both differentiate to \(0\) by (6.5.1) (or equivalently, power rule on \(x^0\) gives \(0\cdot x^{-1}=0\), then (6.5.2) scales that 0 by 7, still 0).
  11. challenge — A polynomial's derivative has degree exactly one less than the original polynomial's degree, as long as the leading coefficient is nonzero. Explain why, using (6.4.1) and (6.5.2) together, and state what happens to the derivative of a degree-0 polynomial (a constant) as the one edge case.
    The highest-degree term \(cx^n\) differentiates to \(cn\cdot x^{n-1}\) (power rule + 6.5.2), which is still nonzero whenever \(c\neq0\) and \(n\geq1\), and every lower-degree term drops to an even lower degree — so the new highest-degree term has degree exactly \(n-1\). The edge case: a degree-0 polynomial (a bare constant) differentiates to 0 by (6.5.1), which isn't a polynomial of degree \(-1\) — it's simply the zero function, breaking the "one less" pattern because there's no lower degree to drop to.
