Module 6 Capstone — Mixed Review & Diagnostic Retake

Fifteen chapters, shuffled together, plus a look back at what a totally blank calculus slate has become since Module 5's very first limit.

Why mixed, not grouped by chapter

Same reasoning as every capstone before this one: a problem that doesn't announce its own chapter is the real test of whether a rule moved into durable memory, not just short-term pattern matching against a chapter title. This module in particular has fourteen genuinely distinct rules — power, sum/difference, product, quotient, six trig derivatives, chain, exponential/log, implicit, higher-order, and inverse (trig and otherwise) — and telling them apart on sight, unlabeled, is exactly the skill Module 7 is about to assume you already have.

Mixed review (all of Module 6)

  1. Find the average rate of change of f(x) = x² on [2,5].
    \((25-4)/(5-2)=7\) (Chapter 1)
  2. Using the limit definition, find f'(x) for f(x) = 4x.
    \(\lim_{h\to0}[4(x+h)-4x]/h = 4\) (Chapter 2)
  3. Is f(x) = |x| differentiable at x=0?
    No — continuous there, but not differentiable (Chapter 3)
  4. Find d/dx[x⁶].
    \(6x^5\) (Chapter 4)
  5. Find d/dx[7].
    \(0\) (Chapter 5)
  6. Differentiate x(x-5) using the product rule.
    \(1(x-5)+x(1)=2x-5\) (Chapter 6)
  7. Differentiate 2x/(x+3).
    \(\dfrac{2(x+3)-2x(1)}{(x+3)^2}=\dfrac{6}{(x+3)^2}\) (Chapter 7)
  8. Find d/dx[cos x].
    \(-\sin x\) (Chapter 8)
  9. Differentiate (x+2)⁴ using the chain rule.
    \(4(x+2)^3\) (Chapter 9)
  10. Differentiate x·(x+1)³.
    \(1(x+1)^3+x\cdot3(x+1)^2 = (x+1)^2\left[(x+1)+3x\right]=(x+1)^2(4x+1)\) (Chapter 10)
  11. Find d/dx[e^(2x)].
    \(2e^{2x}\) (Chapter 11)
  12. Implicitly differentiate x² + y² = 16. Find dy/dx.
    \(-x/y\) (Chapter 12)
  13. Find f''(x) for f(x) = x⁴.
    \(f'=4x^3\), \(f''=12x^2\) (Chapter 13)
  14. If f(1) = 6 and f'(1) = 2, find (f⁻¹)'(6).
    \(1/2\) (Chapter 14)
  15. Find d/dx[arcsin x].
    \(1/\sqrt{1-x^2}\) (Chapter 15)
  16. Differentiate x³/(x+2)² — a second combined product/quotient-and-chain problem, same spirit as Chapter 10.
    \(f=x^3,f'=3x^2\); \(g=(x+2)^2,g'=2(x+2)\). Quotient rule: \(\dfrac{3x^2(x+2)^2-x^3\cdot2(x+2)}{(x+2)^4} = \dfrac{(x+2)\left[3x^2(x+2)-2x^3\right]}{(x+2)^4} = \dfrac{3x^3+6x^2-2x^3}{(x+2)^3} = \dfrac{x^3+6x^2}{(x+2)^3} = \dfrac{x^2(x+6)}{(x+2)^3}\)

Synthesis — concepts combining, not just shuffled

Two problems that each need multiple chapters' tools working together, not just one technique per problem.

Synthesis 1
Ch. 6 — product ruleCh. 8 — trig derivativesCh. 9 — chain rule

Differentiate f(x) = cos(x)·(x²+1)³.

Step 1 — outermost structure is a product (Ch. 6): f=cos x, g=(x²+1)³

Skeleton: \(f'g+fg'\).

Step 2 — f' is a trig derivative (Ch. 8)

\(f'=-\sin x\)

Step 3 — g' needs the chain rule (Ch. 9): outside is "cubed," inside is x²+1

\(g' = 3(x^2+1)^2\cdot2x = 6x(x^2+1)^2\)

Result — assemble and factor

\(-\sin(x)(x^2+1)^3 + \cos(x)\cdot6x(x^2+1)^2 = (x^2+1)^2\left[-\sin(x)(x^2+1) + 6x\cos(x)\right]\) — three chapters' rules, each doing exactly the job it was built for, combined by the product rule's skeleton.

Synthesis 2
Ch. 4 — power ruleCh. 12 — implicit differentiation

Find dy/dx for the curve x⁴ + y⁴ = 2, then find the slope of the tangent line at the point (1,1) (check first that this point is actually on the curve).

Step 1 — confirm (1,1) is on the curve

\(1^4+1^4 = 1+1=2\) ✓

Step 2 — differentiate both sides implicitly (Ch. 12), using the power rule (Ch. 4) on each term

\(\dfrac{d}{dx}\left[x^4\right] + \dfrac{d}{dx}\left[y^4\right] = \dfrac{d}{dx}[2] \implies 4x^3 + 4y^3\dfrac{dy}{dx} = 0\)

Step 3 — solve algebraically for dy/dx

\(4y^3\dfrac{dy}{dx} = -4x^3 \implies \dfrac{dy}{dx} = -\dfrac{x^3}{y^3}\)

Result — evaluate at (1,1)

\(\dfrac{dy}{dx}\bigg|_{(1,1)} = -\dfrac{1^3}{1^3} = -1\) — the tangent line at \((1,1)\) has slope \(-1\), found without ever solving the original equation for \(y\) explicitly (which, for a 4th-degree curve like this one, wouldn't have been practical anyway).

Diagnostic retake

The original diagnostic's calculus section came back completely blank — not a single attempt, not even a wrong guess. Module 5 spent twelve chapters turning that blank slate into real limit fluency, specifically so this module's entire toolkit would trace back to something solid. Here it is, tested directly.

1. Using the limit definition (6.2.1), find f'(x) for f(x) = x².

Originally: this idea didn't exist for you yet — no calculus section on the diagnostic, and Module 5's limit machinery hadn't been built yet either.

\(f'(x)=2x\), fully derived by expanding \((x+h)^2\), canceling, and taking a Module 5-style limit as \(h\to0\). See Chapter 2.

2. Differentiate (x-1)² using the chain rule.

Originally: this idea didn't exist for you yet — no calculus section on the diagnostic.

\(2(x-1)\cdot1 = 2(x-1)\). See Chapter 9.

3. Implicitly differentiate x + y = 10. Find dy/dx.

Originally: this idea didn't exist for you yet — no calculus section on the diagnostic.

\(1 + dy/dx = 0 \Rightarrow dy/dx = -1\) — and sure enough, that matches the ordinary slope of the line \(y=10-x\) directly, the same sanity check every implicit-differentiation result in Chapter 12 got. See Chapter 12.
Module 6 complete

Zero to a full differentiation toolkit in sixteen chapters — starting from a secant line's ordinary slope (average rate of change), shrinking that secant to a tangent via exactly the limit machinery Module 5 spent twelve chapters building (the derivative's actual definition), then layering on differentiability vs. continuity, the power/sum/difference rules, the product and quotient rules, all six trig derivatives (derived, not memorized, straight from Module 5's two essential trig limits), the chain rule, combined-rule fluency, exponential and logarithmic derivatives (the payoff for Module 3's e), implicit differentiation, higher-order derivatives, and finally the derivative of an inverse function applied to inverse trig functions — a genuine three-module synthesis to close things out. Every single rule in this module is traceable, in principle, back to one definition: equation (6.2.1), itself nothing more than a limit. Module 7 (Applications of Derivatives) is next — related rates, critical points, curve sketching, optimization, the Mean Value Theorem, and more, all built on exactly the differentiation toolkit this module just finished.
