Mathematical Induction

One last proof technique, and it's the one built for statements about every positive integer at once — infinitely many cases, proved with exactly two finite steps.

Why this matters

This is how hardware engineers actually verify a sequential circuit is correct forever, without simulating infinite clock cycles. Two things get checked: the circuit is correct in its reset state (cycle 0), and the state-transition logic preserves correctness — if the state going into a clock edge was correct, the state coming out is correct too. Those two finite facts together guarantee correctness at cycle 1, which (by the same transition fact) guarantees cycle 2, then 3, forever — an infinite chain from two checks. Mathematical induction is that exact argument, generalized past circuits: prove a base case, prove the "one step forward preserves truth" fact, and conclude the statement holds for every one of infinitely many n.

Theorem — The principle of mathematical induction

To prove a statement P(n) holds for all integers n ≥ 1:

1. Base case: prove P(1) directly (the "reset state").

2. Inductive step: assume P(k) is true for an arbitrary integer k ≥ 1 (the inductive hypothesis), and use that assumption to prove P(k+1) (the "transition preserves correctness").

\[ \Big[P(1) \wedge \forall k{\ge}1\big(P(k)\Rightarrow P(k{+}1)\big)\Big] \Rightarrow \forall n{\ge}1,\ P(n) \]
(4.9.1)

Both parts are required. The base case anchors the chain; the inductive step is the link that makes the chain propagate. Neither one alone proves anything about all n.

Worked example — sum of the first n integers

Prove: 1 + 2 + ... + n = n(n+1)/2 for all n ≥ 1.

Step 1 — base case, n = 1

Left side: just \(1\). Right side: \(1(1+1)/2 = 1\). Equal ✓.

Step 2 — inductive hypothesis

Assume, for some \(k\ge1\): \(1+2+\cdots+k = \dfrac{k(k+1)}{2}\).

Step 3 — inductive step: show P(k+1) using P(k)

\[ 1+2+\cdots+k+(k+1) = \underbrace{\left(1+2+\cdots+k\right)}_{\text{substitute the IH here}} + (k+1) = \frac{k(k+1)}{2} + (k+1) \] Factor out \((k+1)\) — Module 0 algebra doing the real work now: \[ = (k+1)\left(\frac{k}{2}+1\right) = \frac{(k+1)(k+2)}{2} \]

Result

\(\dfrac{(k+1)(k+2)}{2}\) is exactly the formula \(\dfrac{n(n+1)}{2}\) with \(n=k+1\) substituted in. P(k+1) holds. By induction, the formula holds for all n ≥ 1.

Worked example — an inequality: 2ⁿ > n

Prove: 2ⁿ > n for all n ≥ 1.

Step 1 — base case, n = 1

\(2^1 = 2 > 1\) ✓.

Step 2 — inductive hypothesis

Assume, for some \(k\ge1\): \(2^k > k\).

Step 3 — inductive step

\(2^{k+1} = 2\cdot2^k\). Using the IH (\(2^k>k\)) and doubling both sides: \(2\cdot2^k > 2k\). Now: since \(k\ge1\), \(2k = k+k \ge k+1\). Chaining: \(2^{k+1} > 2k \ge k+1\), so \(2^{k+1}>k+1\).

Result

P(k+1) holds. By induction, \(2^n>n\) for all n ≥ 1. Notice the IH was used in an essential way — the "\(2\cdot2^k>2k\)" step is impossible without it.

Common mistake

Two distinct ways an induction proof breaks, both common: (1) skipping the base case — the inductive step alone, however careful, never establishes a starting point; without it you've only shown "if it's ever true, it stays true," never that it's true anywhere at all. (2) writing an inductive step that never actually uses P(k) — for example, "proving" P(k+1) for the sum formula by writing "\(1+2+\cdots+(k+1) = (k+1)(k+2)/2\), which is true by the pattern" without ever substituting in the assumed value of \(1+2+\cdots+k\) from the IH. That's not a proof — it's restating the k+1 case and asserting it, which is exactly what needed proving in the first place. If your inductive-step algebra never touches the assumption "P(k) is true," you haven't built the chain link; you've skipped it and hoped no one checks.

Practice

  1. State the two parts required in a proof by induction, in your own words.
    A base case (verify P(1) directly) and an inductive step (assume P(k), prove P(k+1) follows from it).
  2. Prove by induction: 2 + 4 + 6 + ... + 2n = n(n+1) for all n ≥ 1.
    Base n=1: 2=1·2 ✓. IH: 2+4+...+2k=k(k+1). Step: 2+4+...+2k+2(k+1) = k(k+1)+2(k+1) = (k+1)(k+2), matching the formula at n=k+1.
  3. Prove by induction: 3 divides n³ − n for all n ≥ 1.
    Base n=1: 0 = 1³−1, and 3|0 ✓. IH: 3|(k³−k). Step: (k+1)³−(k+1) = k³+3k²+3k+1−k−1 = (k³−k)+3(k²+k). First term divisible by 3 (IH), second is 3×integer — sum divisible by 3.
  4. Verify only the base case (skip the inductive step) for the claim "n! > 2ⁿ for all n ≥ 4."
    n=4: 4! = 24, 2⁴ = 16. 24 > 16 ✓ — base case (at n=4, not n=1) holds.
  5. In the 2ⁿ > n inductive step, why isn't "\(2^{k+1}=2\cdot2^k>2k\)" alone enough — what extra inequality closes the gap to k+1?
    You still need \(2k \ge k+1\) (true since \(k\ge1\)) to chain \(2^{k+1}>2k\ge k+1\) into \(2^{k+1}>k+1\); "> 2k" by itself doesn't directly say "> k+1" without that extra link.
  6. Prove by induction: 1 + 3 + 5 + ... + (2n−1) = n² for all n ≥ 1.
    Base n=1: 1=1² ✓. IH: sum of first k odds = k². Step: k² + (2(k+1)−1) = k²+2k+1 = (k+1)², matching the formula at n=k+1.
  7. bonus — The classic flawed "proof": Claim — in any group of n horses, all horses are the same color. Base case n=1: trivially true. Inductive step: given k+1 horses, remove one to get a group of k (same color, by IH), remove a different one to get another group of k (same color, by IH); since these groups overlap, all k+1 horses share a color. Find the flaw.
    The "the two groups overlap" claim silently requires the two size-k subgroups to share at least one horse. That's true for k≥2, but fails exactly at k=1 (going from 1 horse to 2): removing one horse from each side of a 2-horse group leaves two single-horse groups with no overlap at all — nothing forces them to match. The chain breaks precisely at the step from n=1 to n=2, which was never actually verified.
  8. bonus — Prove by induction: n³ + 2n is divisible by 3, for all n ≥ 1.
    Base n=1: 1+2=3 ✓. IH: 3|(k³+2k). Step: (k+1)³+2(k+1) = k³+3k²+3k+1+2k+2 = (k³+2k)+3(k²+k+1) — first term divisible by 3 (IH), second obviously so.
  9. bonus — Prove by induction: 1 + 2 + 4 + ... + 2^(n−1) = 2ⁿ − 1 for all n ≥ 1 (the sum of the first n powers of 2 — familiar from binary).
    Base n=1: 1 = 2¹−1 ✓. IH: sum up to 2^(k−1) equals 2^k−1. Step: add 2^k: (2^k−1)+2^k = 2·2^k−1 = 2^(k+1)−1, matching the formula at n=k+1.
  10. bonus — Why must the inductive hypothesis P(k) actually appear inside the derivation of P(k+1)? What's logically missing if a "proof" derives P(k+1) without ever using P(k)?
    Without using P(k), nothing links case k+1 back to case k — you've at best shown P(k+1) as an isolated fact (which you'd then have to prove independently for every n anyway), not that truth propagates forward one step at a time. The chain P(1)→P(2)→P(3)→... only exists because each link genuinely depends on the one before it.
  11. challenge — Prove by induction: n² ≥ 2n + 1 for all n ≥ 3 (note the base case is not n=1 — find where the claim actually starts being true, and start there).
    Base n=3: 9 ≥ 7 ✓ (check n=1: 1≥3 false; n=2: 4≥5 false — the claim genuinely starts at n=3). IH: k²≥2k+1 for some k≥3. Step: (k+1)²=k²+2k+1 ≥ (2k+1)+2k+1 = 4k+2 (using IH). Need 4k+2 ≥ 2(k+1)+1 = 2k+3, i.e. 2k≥1, true since k≥3. So (k+1)² ≥ 2(k+1)+1.
