Module 4 Capstone — Mixed Review & Diagnostic Retake

Nine chapters, shuffled together, plus a look back at day one — this was the one module that wasn't a knowledge gap. The diagnostic already showed real fluency with circuits and truth tables; what's new is the formal apparatus wrapped around it.

Why mixed, not grouped by chapter

Same reasoning as every capstone before this one: a problem that doesn't announce its own chapter is the real test of whether the idea moved into durable memory, not just short-term pattern matching against a chapter title.

Mixed review (all of Module 4)

  1. Let p = T, q = F. Evaluate ¬p ∨ q.
    \(\neg p = F\), so \(F \vee F = F\).
  2. Evaluate p ⇒ q when p = F, q = T.
    \(T\) — a conditional with a false antecedent is vacuously true.
  3. Simplify ¬(p ∧ ¬q).
    De Morgan's: \(\neg p \vee \neg(\neg q) = \neg p \vee q\).
  4. Negate: ∀x, x² ≥ 0.
    \(\exists x,\ x^2 < 0\) (flip the quantifier, negate the inner predicate).
  5. Is 5 ∈ {x | x is even, 0 < x < 10}?
    No — 5 is odd, so it fails the set's defining condition.
  6. Translate x ∈ A ∩ B into a logical statement about x.
    \(x \in A \wedge x \in B\).
  7. To begin a direct proof about an odd integer n, what form do you write n in?
    \(n = 2k+1\) for some integer \(k\).
  8. State the contrapositive of "if n is even, then n² is even."
    "If \(n^2\) is odd, then \(n\) is odd."
  9. State the two parts a proof by induction requires.
    A base case (verify \(P(1)\) directly) and an inductive step (assume \(P(k)\), show \(P(k+1)\) follows).
  10. Let p = T, q = F. Evaluate p ⇒ (q ∧ p).
    \(q \wedge p = F \wedge T = F\), so \(p \Rightarrow (q\wedge p) = T \Rightarrow F = F\).

Synthesis — concepts combining, not just shuffled

Two problems that each need multiple chapters' tools working together, not just one technique per problem.

Synthesis 1
Ch. 4 — quantifier negationCh. 2 — contrapositiveCh. 8 — proof by contrapositive

Consider the quantified claim ∀n, (n² is even ⇒ n is even). (a) Negate it fully. (b) Prove the original claim true, using contrapositive.

Step 1 — negate the quantifier (Chapter 4)

\(\neg\big[\forall n,\ P(n)\Rightarrow Q(n)\big] \equiv \exists n,\ \neg\big(P(n)\Rightarrow Q(n)\big)\)

Step 2 — negate the conditional inside it (Chapter 2's truth condition for ⇒)

A conditional is false only when the antecedent is true and the consequent is false, so \(\neg(P\Rightarrow Q) \equiv P\wedge\neg Q\). The full negation: \(\exists n,\ (n^2\text{ is even}) \wedge (n\text{ is odd})\) — "there exists an \(n\) with \(n^2\) even but \(n\) odd."

Step 3 — prove the original by contrapositive (Chapter 8)

The contrapositive of "\(n^2\) even \(\Rightarrow\) \(n\) even" is "\(n\) odd \(\Rightarrow\) \(n^2\) odd" (Chapter 2's equivalence). Prove that instead: let \(n=2k+1\). Then \(n^2 = 4k^2+4k+1 = 2(2k^2+2k)+1\), which is odd by definition (Chapter 7's odd-integer form).

Result

The contrapositive is proven directly, so the original claim is true — meaning the negation from Step 2 describes a case that can never actually happen. Three chapters, one argument: quantifier negation set up exactly what would have to fail, and the contrapositive/direct-proof machinery showed it can't.

Synthesis 2
Ch. 6 — sets and logic correspondenceCh. 3 — De Morgan's lawsCh. 5 — set notation

Prove the second De Morgan's law for sets: (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ.

Step 1 — translate set membership to logic (Chapter 6)

\(x\in(A\cup B)^c \iff \neg(x\in A\cup B) \iff \neg(x\in A \vee x\in B)\)

Step 2 — apply De Morgan's law (Chapter 3)

\(\neg(x\in A \vee x\in B) \equiv \neg(x\in A) \wedge \neg(x\in B)\)

Step 3 — translate back to set notation (Chapter 5)

\(\neg(x\in A)\wedge\neg(x\in B) \iff x\in A^c \wedge x\in B^c \iff x\in(A^c\cap B^c)\)

Result

Every \(x\) satisfies \(x\in(A\cup B)^c\) exactly when it satisfies \(x\in A^c\cap B^c\), so the two sets are equal: \((A\cup B)^c = A^c\cap B^c\). The "set version" of De Morgan's isn't a new law at all — it's the logical one, wearing set notation, exactly Chapter 6's point.

Diagnostic retake

This module didn't start from zero the way Modules 1, 2, and 3 did — the diagnostic found real, working fluency with circuits and truth tables already in place. What follows isn't "now you can do this," it's "now you can write down, name, and prove what you already did by instinct."

1. Simplify ¬(p ∨ q), and name the rule you used.

Originally: could trace a NOR gate's truth table by hand instantly, but had no symbol or name for the rule underneath it.

\(\neg(p\vee q) \equiv \neg p \wedge \neg q\) — De Morgan's Law. A NOR gate is exactly the circuit "invert both inputs, then AND them." See Chapter 3.

2. Translate into quantifier notation: "every prime number greater than 2 is odd."

Originally: this "just made sense," but there was no way to write it down formally — no ∀, no ⇒.

\(\forall n,\ (n \text{ is prime} \wedge n>2) \Rightarrow n \text{ is odd}\). See Chapters 2 and 4.

3. Prove: the sum of any two even integers is even — from the actual definition, not "everyone knows that."

Originally: obviously true by instinct, but never something that had been written as an actual proof with a definition behind it.

Let \(a=2j\), \(b=2k\) for integers \(j,k\). Then \(a+b=2j+2k=2(j+k)\), which is even by definition, since \(j+k\) is an integer. See Chapter 7.
