Conditionals & Biconditionals

Chapter 1 gave you ∧, ∨, ¬ — the gates. This chapter gives you the connective that almost every theorem in mathematics is built from: "if p then q." It isn't a primitive gate on its own, but by the end of the module (Chapter 3) you'll see it's built entirely out of gates you already have.

Why this matters

Think of a fault-monitor circuit: p = "the smoke detector triggers," q = "the alarm sounds." The circuit has a fault exactly when the detector triggers but the alarm stays silent — fault = p ∧ ¬q. Everything working correctly means "no fault," i.e. ¬(p ∧ ¬q). That expression is the conditional p ⇒ q — "if p then q" just means "the fault condition never occurs." Once you see a conditional as "no fault," the one weird truth-table row (false ⇒ anything is always true) stops being weird: if the detector never triggers, there's no possible way for a "triggered but silent" fault to occur, so the conditional holds automatically — trivially, but genuinely.

Definition — Conditional (implication)

p ⇒ q ("if p, then q" — p is the hypothesis, q is the conclusion) is false in exactly one case: p true and q false — the "fault" case above. Every other combination is true.

p q p ⇒ q
TTT
TFF
FTT
FFT
\[ (p \Rightarrow q) = F \iff (p=T) \text{ and } (q=F) \]
(4.2.1)

The bottom two rows — p false — are the "vacuously true" rows: with no detector trigger, there's no way to fail.

Definition — Biconditional

p ⇔ q ("p if and only if q," read "p iff q") is true exactly when p and q have the same truth value. If you've built an XNOR gate, you already know this table — the biconditional is XNOR: output high when both inputs match.

p q p ⇔ q
TTT
TFF
FTF
FFT

You'll see p ⇔ q constantly in definitions ("a number is even iff it's divisible by 2") — a definition is always meant both directions, which is exactly why iff is the connective for stating one.

Definition — Converse, inverse, contrapositive

Starting from p ⇒ q, three related statements get their own names:

Converse: q ⇒ p (swap the two sides).
Inverse: ¬p ⇒ ¬q (negate both sides, keep the order).
Contrapositive: ¬q ⇒ ¬p (swap and negate both sides).

\[ (p \Rightarrow q) \equiv (\neg q \Rightarrow \neg p) \]
(4.2.2)

This one is worth committing to memory right now: the contrapositive is always logically equivalent to the original conditional — same truth value in every row, no exceptions. The converse and inverse are not generally equivalent to the original (next section shows why that matters). Chapter 3 gives you the tool (De Morgan's laws) to actually verify equation 4.2.2 yourself instead of taking it on faith; Chapter 8 puts it to work as a proof technique.

Worked example — truth table for p ⇒ q, from scratch

Confirm equation 4.2.1 by building the table directly from the definition "false only when p=T, q=F."

Step 1 — list all 4 rows

TT, TF, FT, FF — same 4-row structure as any 2-input truth table.

Step 2 — mark the one false row

Only TF is p=T,q=F → that row is F. Every other row is T by definition.

Result

T, F, T, T for rows TT, TF, FT, FF — matches the table above.

Worked example — converse, inverse, contrapositive of a real statement

Let p = "it rains" and q = "the ground is wet." Original: "If it rains, the ground is wet."

Step 1 — converse (q ⇒ p)

"If the ground is wet, it rains." Not necessarily true — a sprinkler could wet the ground with no rain.

Step 2 — inverse (¬p ⇒ ¬q)

"If it doesn't rain, the ground isn't wet." Also not necessarily true, same sprinkler counterexample.

Step 3 — contrapositive (¬q ⇒ ¬p)

"If the ground is not wet, it did not rain." This one is guaranteed true whenever the original is — dry ground rules out rain, given the original claim holds.

Result

Converse and inverse can independently be false even when the original is true; the contrapositive can't. That's equation 4.2.2 in action, not just an abstract rule.

Common mistake — affirming the consequent

Assuming that because p ⇒ q is true, its converse q ⇒ p must be true too. It usually isn't — this is one of the most common reasoning errors there is, common enough to have a name. "If it rains, the ground is wet" (true) does not license "the ground is wet, so it rained" — the sprinkler counterexample above breaks it immediately. The fix: only the contrapositive is free; the converse has to be checked (or proved) completely independently, as its own claim.

What is the truth value of F ⇒ T?

Practice

  1. Evaluate: T ⇒ F
    False
  2. Evaluate: F ⇒ F
    True (vacuously)
  3. Evaluate: T ⇔ F
    False
  4. Write the converse of "if a number is divisible by 4, it is divisible by 2."
    "If a number is divisible by 2, it is divisible by 4." (False in general — e.g. 6.)
  5. Write the contrapositive of "if n is prime and n > 2, then n is odd."
    "If n is not odd, then n is not prime or n ≤ 2." (Equivalently: if n is even, then n is not prime or n ≤ 2.)
  6. Is "you get a discount if and only if you have a coupon" better modeled as ⇒ or ⇔? Why?
    ⇔ — the "if and only if" is explicit: coupon guarantees discount, and discount guarantees you had a coupon, both directions.
  7. bonus — Write the inverse of "if x > 5, then x² > 25." Is the inverse true?
    "If x ≤ 5, then x² ≤ 25." False — e.g. x = -10 ≤ 5 but x² = 100 > 25.
  8. bonus — Give your own real-world example of a true conditional whose converse is false (not the rain example).
    Any valid one works, e.g. "if an animal is a dog, it is a mammal" (true) — converse "if an animal is a mammal, it is a dog" (false, e.g. cats).
  9. bonus — A circuit's fault condition is defined as p ∧ ¬q. Under what p,q row does the corresponding conditional p⇒q fail?
    p=T, q=F — the same single row that makes p∧¬q true, by construction.
  10. bonus — Build the full truth table for (p ⇒ q) ⇔ (¬q ⇒ ¬p) and confirm every row is T (this is exactly equation 4.2.2, verified directly).
    All 4 rows give T for the outer ⇔, since p⇒q and ¬q⇒¬p have identical truth tables (T,F,T,T) — confirming they're equivalent.
  11. challenge — "If you didn't study, you will fail" is claimed true. Someone fails the exam and concludes "so they didn't study." Which of converse/inverse/contrapositive did they implicitly use, and is the conclusion actually forced?
    Let p = "didn't study," q = "will fail." The claim is p⇒q. "Failed, so didn't study" is q⇒p — the converse, not guaranteed. The conclusion is not forced: they could have studied and still failed for another reason.
