Set Notation

A short detour from propositions into sets — but not really a detour. By the end of Chapter 6 you'll see sets and logic are the same idea wearing different notation, and this chapter's vocabulary (∈, ⊆, ∪, ∩) is what makes that translation possible.

Why this matters

Fix a finite universe of possible elements and any subset of it is exactly a bitmask — one bit per element, 1 if it's "in," 0 if it's "out." That's not a metaphor, it's literally how sets get implemented in low-level code and hardware: permission flags, feature masks, register bits. Once you see a set that way, the whole vocabulary below has a bitwise-operation twin: union is bitwise OR of the masks, intersection is bitwise AND, complement is bitwise NOT. Chapter 6 makes that connection exact.

Definition — Set, element-of, subset

A set is an unordered collection of distinct objects, called its elements or members. Written with curly braces: {1, 2, 3}. Order and repetition don't matter — {1,2,3} = {3,2,1} = {1,1,2,3}, all the same set.

x ∈ A means "x is an element of A"; x ∉ A means it isn't. This relates an element to a set.

A ⊆ B ("A is a subset of B") means every element of A is also an element of B. This relates two sets to each other — a different kind of relationship from ∈. A ⊂ B ("proper subset") means A ⊆ B and A ≠ B — B has at least one element A doesn't.

The empty set, ∅, has no elements at all. It is a subset of every set, vacuously — the same "vacuously true" flavor as Chapter 2's false-hypothesis conditionals: every element of ∅ (there are none) trivially satisfies "is in B."

Definition — Set-builder notation
\[ \{x \mid P(x)\} = \text{"the set of all } x \text{ satisfying } P(x)\text{"} \]
(4.5.1)

The bar | reads "such that." {x | x is even} is the set of all even numbers — no need to list every element, just the condition that defines membership. This is exactly a predicate from Chapter 4 wearing set clothing: P(x) defines the set the same way it defined a quantified statement.

Definition — Union, intersection, complement
\[ A \cup B = \{x \mid x \in A \text{ or } x \in B\} \]
(4.5.2)
\[ A \cap B = \{x \mid x \in A \text{ and } x \in B\} \]
(4.5.3)
\[ A^c = \{x \in U \mid x \notin A\} \]
(4.5.4)

Union (4.5.2) collects everything in either set. Intersection (4.5.3) collects only what's in both. Complement (4.5.4) — read relative to some agreed-on universal set U (e.g. "all integers") — collects everything in U that isn't in A. Notice each definition is spelled with "or"/"and"/"not" — Chapter 6's whole point, one chapter early.

Worked example — union and intersection

Let A = {1, 2, 3, 4} and B = {3, 4, 5, 6}. Find A ∪ B and A ∩ B.

Step 1 — union: everything appearing in either set, no duplicates

\(A \cup B = \{1,2,3,4,5,6\}\) — 3 and 4 appear in both but are listed once.

Step 2 — intersection: only what's shared

\(A \cap B = \{3,4\}\)

Common mistake

Confusing ∈ (element-of) with ⊆ (subset-of) — they relate different kinds of things. 2 ∈ {1,2,3} is correct: 2 is a single element sitting inside the set. But 2 ⊆ {1,2,3} is wrong — 2 is a number, not a set, so it can't be "a subset of" anything; ⊆ needs a set on both sides. The fix: {2} ⊆ {1,2,3} is correct — wrap the element in braces to turn it into a (singleton) set first, and then the subset relation makes sense.

Practice

  1. Is 5 ∈ {2, 4, 6, 8}?
    No (False)
  2. Is {1, 2} ⊆ {1, 2, 3}?
    Yes — both elements of the left set are in the right set.
  3. List the elements of {x | x is a positive integer less than 6}.
    \(\{1,2,3,4,5\}\)
  4. Let A = {2, 3, 5, 7}, B = {1, 3, 5, 7, 9}. Find A ∩ B.
    \(\{3,5,7\}\)
  5. Let A = {2, 3, 5, 7}, B = {1, 3, 5, 7, 9}. Find A ∪ B.
    \(\{1,2,3,5,7,9\}\)
  6. With universal set U = {1,2,...,10} and A = {2,4,6,8,10}, find Aᶜ.
    \(\{1,3,5,7,9\}\)
  7. bonus — Is ∅ ⊆ {1,2,3}? Justify it using the definition of ⊆.
    Yes — vacuously true: ∅ has no elements, so "every element of ∅ is in {1,2,3}" has nothing to check and fails to fail.
  8. bonus — Is {1,2,3} ⊆ {1,2,3}? Is {1,2,3} ⊂ {1,2,3}?
    ⊆ yes (every set is a subset of itself). ⊂ no (proper subset requires the sets be unequal).
  9. bonus — Write {3, 6, 9, 12, ...} (all positive multiples of 3) in set-builder notation.
    \(\{x \mid x = 3k \text{ for some positive integer } k\}\) (equivalently \(\{x \mid x \text{ is a positive multiple of } 3\}\))
  10. bonus — A capability bitmask has bit 0 = "read," bit 1 = "write," bit 2 = "execute." If a process's permission set is {read, execute}, describe the complement relative to U = {read, write, execute}.
    \(\{write\}\) — exactly the permissions not granted, same as flipping the unset bits in the mask.
  11. challenge — Is it possible for A ∩ B = A without A = B? Give an example or explain why not, using the definition of ∩.
    Yes — exactly when \(A \subseteq B\). E.g. \(A=\{1,2\}\), \(B=\{1,2,3\}\): \(A\cap B = \{1,2\} = A\), but \(A \ne B\). \(A\cap B=A\) means every element of A is also in B, which is precisely \(A\subseteq B\) — not full equality.
