Proof by Contrapositive & Contradiction

Chapter 7's direct proofs go forward: hypothesis to conclusion, no detours. Some claims resist that route. This chapter gives you two indirect ones — and both are built entirely from Chapters 2–4's negation machinery, put to real use.

Why this matters

Debugging a circuit rarely means simulating forward from every input. More often you reason backward from a bad output pin: "the output is wrong, so trace back — which input must have been at fault?" That's contrapositive reasoning: instead of showing p forces q, you show ¬q forces ¬p, which (Chapter 2, equation 4.2.2) proves the exact same thing. Contradiction is the other classic debugging move: assume a wiring is correct, follow the logic, and discover it would force some wire to be simultaneously 0 and 1 — an impossible short. Since that's impossible, the assumption must have been wrong. Both techniques are things you've done at a keyboard; this chapter just names them.

Theorem — Proof by contrapositive

To prove p ⇒ q, it is enough to prove ¬q ⇒ ¬p instead. This is valid precisely because Chapter 2 (equation 4.2.2) established (p⇒q) ≡ (¬q⇒¬p) — proving one automatically proves the other, since they're the same statement. Use it whenever the forward direction is awkward but reasoning from "q failed" backward to "p must have failed" is cleaner.

Definition — Proof by contradiction

To prove a statement S (any statement, not just a conditional) by contradiction: assume ¬S, then reason validly from that assumption until you reach something impossible — a statement of the form r ∧ ¬r, or anything already known false. Since valid reasoning can only produce an impossible conclusion if it started from a false premise, the assumption ¬S must be false — so S is true.

When S itself is a conditional p ⇒ q, the assumption to start from is ¬(p⇒q), and — using Chapter 3's De Morgan's law on Chapter 3's exercise result p⇒q ≡ ¬p∨q — that negation works out to p ∧ ¬q. In plain terms: assume the hypothesis is true and the conclusion is false, both at once, then hunt for the impossible consequence. This is a genuinely different move from taking the contrapositive: contrapositive keeps the statement's truth value the same (it's an equivalent restatement); contradiction assumes the opposite truth value on purpose, planning to blow it up.

Worked example — contrapositive, reusing Chapter 7 directly

Prove: if n² is even, then n is even.

Step 1 — try the direct route and notice it's awkward

Starting from "n² = 2k" and trying to algebraically extract "n = 2j" requires taking a square root mid-proof and arguing it's an integer — solvable, but clunky. Try the contrapositive instead.

Step 2 — state the contrapositive

Original: (n² even) ⇒ (n even). Contrapositive: (n not even) ⇒ (n² not even), i.e. if n is odd, then n² is odd.

Step 3 — recognize this exact claim

This is word-for-word Chapter 7's second worked example, already proved: n=2k+1 ⟹ n²=2(2k²+2k)+1, odd.

Result

The contrapositive is proved, and by the theorem above, that is a proof of "if n² is even, then n is even" — no new algebra needed, just the equivalence and a chapter of reuse.

Worked example — √2 is irrational, by contradiction

Prove: √2 is irrational (not expressible as a ratio of integers).

Step 1 — assume the negation

Assume, for contradiction, that √2 is rational. Then \(\sqrt2 = a/b\) for integers a, b with no common factor (the fraction is fully reduced), b≠0.

Step 2 — clear the square root

\(2 = a^2/b^2 \implies a^2 = 2b^2\). So a² is even.

Step 3 — use this chapter's own first result

By the contrapositive result just proved above, a² even ⟹ a is even. So \(a = 2k\) for some integer k.

Step 4 — substitute back and find the same fact about b

\(a^2 = 2b^2 \implies (2k)^2 = 2b^2 \implies 4k^2 = 2b^2 \implies b^2 = 2k^2\). So b² is even too, hence (same result again) b is even.

Result — the contradiction

a and b are both even, so they share a common factor of 2 — directly contradicting the assumption that a/b was fully reduced. The assumption "√2 is rational" must be false. Therefore √2 is irrational. Notice this single proof reused Chapter 7's definitions, this chapter's own contrapositive result, and the contradiction technique together — exactly the kind of multi-chapter synthesis the rest of this course keeps demanding.

Common mistake

Negating the target statement incorrectly when setting up a contrapositive or contradiction proof. Two specific ways this goes wrong, both real: (1) confusing the contrapositive (¬q⇒¬p, equivalent to the original — swap and negate both sides of the conditional) with the inverse (¬p⇒¬q, generally not equivalent — Chapter 2's mistake, resurfacing); (2) when setting up a contradiction proof of p⇒q, negating only the hypothesis or only the conclusion instead of the whole conditional. The correct start is always p ∧ ¬q — hypothesis stays true, only the conclusion flips — never "¬p and ¬q" and never "¬p ⇒ ¬q." Get the setup wrong and every step after it is proving the wrong claim.

Try it yourself

True or False: to prove "if n is even, then n² is even" by contradiction, the correct assumption to start from is "n is even and n² is odd."

Practice

  1. Write the correct starting assumption to prove "if x > 0, then x² > 0" by contradiction.
    Assume x > 0 and x² ≤ 0 (p ∧ ¬q — hypothesis kept true, conclusion negated).
  2. Write the contrapositive of "if n is divisible by 6, then n is divisible by 3."
    "If n is not divisible by 3, then n is not divisible by 6."
  3. Prove by contrapositive: if 3n is even, then n is even.
    Contrapositive: if n is odd, then 3n is odd. n=2k+1 ⟹ 3n=6k+3=2(3k+1)+1, odd (form 4.7.2). Contrapositive proved ⟹ original proved.
  4. True or False: to prove "if n is even, then n² is even" by contradiction, assume n is even and n² is odd. (Restated from the checker — justify your answer this time.)
    True — that's exactly p ∧ ¬q for this conditional: keep the hypothesis, negate the conclusion.
  5. Prove by contradiction: there is no largest even integer.
    Assume, for contradiction, there is a largest even integer N. Then N=2k, and N+2=2(k+1) is also even, with N+2 > N — contradicting N being largest. So no largest even integer exists.
  6. Write both the contrapositive and the negation of "if a triangle is equilateral, then it is isosceles," and state in one sentence how they differ.
    Contrapositive: "if a triangle is not isosceles, it is not equilateral" (equivalent to the original — true). Negation: "a triangle is equilateral and it is not isosceles" (the opposite claim — false, since it's actually impossible). Contrapositive restates; negation opposes.
  7. bonus — Prove by contradiction: if n² is odd, then n is odd.
    Assume n² is odd and n is even. Then n=2k, so n²=4k²=2(2k²), even — contradicting the assumption that n² is odd. So the assumption is false; n must be odd.
  8. bonus — Prove √3 is irrational, mirroring the √2 worked example. (You may use, without reproving, that a² divisible by 3 ⟹ a divisible by 3.)
    Assume √3=a/b in lowest terms. Then 3=a²/b² ⟹ a²=3b², so a² is divisible by 3, hence a is divisible by 3: a=3k. Then 9k²=3b² ⟹ b²=3k², so b is also divisible by 3. a and b share a factor of 3, contradicting "lowest terms." So √3 is irrational.
  9. bonus — Write the contrapositive of "if a and b are both odd, then a+b is even." (The hypothesis is itself a conjunction — use De Morgan, Chapter 3, when you negate it.)
    "If a+b is odd, then a is even or b is even" — negating "a odd ∧ b odd" via De Morgan gives "a not odd ∨ b not odd," i.e. "a even ∨ b even."
  10. bonus — A student proving "if n is prime and n > 2, then n is odd" by contradiction starts: "Assume n is not prime or n ≤ 2." What's wrong with this setup, and what should they have written?
    They negated only the hypothesis (via De Morgan) instead of assuming p∧¬q. Correct setup: "assume n is prime and n > 2 (hypothesis true), and n is even (conclusion false)," then derive a contradiction from that.
  11. challenge — Prove by contradiction: there is no smallest positive real number.
    Assume, for contradiction, there is a smallest positive real number x. Then x/2 is also a positive real number, and x/2 < x — contradicting x being smallest. So no smallest positive real number exists. (Notice this proof needed nothing about even/odd — contradiction works over any domain.)
