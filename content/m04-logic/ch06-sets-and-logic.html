Chapter 6 · concept:sets-logic-correspondence

Sets and Logic — The Same Structure

This is the reductionist payoff of the module so far. Chapter 1 gave you circuits ↔ ∧/∨/¬. Chapter 5 gave you sets ↔ ∪/∩/complement. This chapter proves those aren't two things — they're one structure, described three ways.

Why this matters

You already carry three separate-looking vocabularies: gate logic (AND/OR/NOT), formal propositional logic (∧/∨/¬), and now set operations (∪/∩/complement). They're not three things to remember — they're one idea with three skins. Union is OR, intersection is AND, complement is NOT, and a bitmask is a subset, literally. Once this clicks, "prove a set identity" and "prove a logical equivalence" become the same task wearing different clothes, and you can freely translate between whichever notation makes a given problem easiest.

Theorem — set membership is logic
\[ x \in (A \cup B) \iff (x\in A) \vee (x \in B) \]
(4.6.1)
\[ x \in (A \cap B) \iff (x\in A) \wedge (x \in B) \]
(4.6.2)
\[ x \in A^c \iff \neg(x \in A) \]
(4.6.3)

These aren't new facts to memorize — they're literally Chapter 5's definitions of ∪, ∩, and complement, just written with the ∨/∧/¬ symbols instead of the words "or"/"and"/"not" that were already sitting inside them. "x is in A or B" was always a disjunction. Now it's official.

Worked example — proving the "set De Morgan's law"

Prove: (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ. Strategy: translate to logic (4.6.1–4.6.3), apply Chapter 3's De Morgan's law, translate back — never just assert set equalities by pattern-matching the name.

Step 1 — start from membership in the left side

\(x \in (A\cap B)^c \iff \neg\big(x \in (A\cap B)\big)\) — by 4.6.3, complement is negation.

Step 2 — unpack the intersection using 4.6.2

\(\iff \neg\big((x\in A) \wedge (x\in B)\big)\)

Step 3 — apply De Morgan's law (Chapter 3, equation 4.3.1) — this is the actual logical content

\(\iff \neg(x\in A) \vee \neg(x\in B)\)

Step 4 — translate each negated membership back into a complement, using 4.6.3

\(\iff (x \in A^c) \vee (x\in B^c)\)

Step 5 — translate the disjunction back into a union, using 4.6.1

\(\iff x \in (A^c \cup B^c)\)

Result

\(x \in (A\cap B)^c \iff x \in (A^c\cup B^c)\) for an arbitrary x — meaning the two sets contain exactly the same elements, so \((A\cap B)^c = A^c \cup B^c\). Nothing here was assumed; every step cited either a Chapter 5 definition or Chapter 3's proven theorem.

Common mistake

Seeing "(A∩B)ᶜ = Aᶜ∪Bᶜ" called "De Morgan's law for sets" and accepting it as obviously true purely because the name sounds familiar, without actually checking it. The name is a hint about why it's true, not a substitute for showing it. The worked example above is the actual proof — translate to membership statements, invoke the logical De Morgan's law you already proved in Chapter 3, translate back. Skipping straight to "yeah, that's De Morgan's, must be right" is exactly the habit Chapter 7 (Direct Proof) is about training out of.

Try it yourself

Fill in the connective: x ∈ (A ∩ B) ⟺ (x∈A) ___ (x∈B)

Practice

  1. Translate to a logical statement: x ∈ Aᶜ
    \(\neg(x\in A)\)
  2. Translate to a set statement: (x∈A) ∨ (x∈B)
    \(x \in (A\cup B)\)
  3. With A = {1,2,3}, B = {2,3,4}: verify directly that 2 ∈ A∩B matches (2∈A)∧(2∈B) being true.
    2∈A is true, 2∈B is true, so (2∈A)∧(2∈B)=True, matching 2∈{2,3}=A∩B. ✓
  4. State the set-theory identity that corresponds to the logical equivalence p ∨ p ≡ p (idempotence), for a single set A.
    \(A \cup A = A\)
  5. State the set-theory identity that corresponds to p ∧ ¬p ≡ F (a proposition can't be both true and false).
    \(A \cap A^c = \emptyset\)
  6. What logical equivalence corresponds to the set identity A ∪ ∅ = A?
    \(p \vee F \equiv p\)
  7. bonus — Using the same three-step translation method as the worked example, prove (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ.
    \(x\in(A\cup B)^c \iff \neg(x\in A\cup B) \iff \neg((x\in A)\vee(x\in B)) \iff \neg(x\in A)\wedge\neg(x\in B)\) (De Morgan, 4.3.2) \(\iff (x\in A^c)\wedge(x\in B^c) \iff x\in(A^c\cap B^c)\).
  8. bonus — What logical connective does "AND-reduce over a bitmask" correspond to, and which set operation does it correspond to, if the bitmask represents "which of these n conditions hold"?
    ∧ (conjunction) — and, viewed as sets of "which conditions hold across which cases," it's the generalized intersection of the corresponding truth-sets.
  9. bonus — Is A ⊆ B the same claim as ∀x, (x∈A) ⇒ (x∈B)? Explain in one sentence why, using Chapter 5's definition of ⊆.
    Yes — "every element of A is also in B" (the definition of ⊆) is exactly "for all x, being in A forces being in B," which is the conditional, quantified.
  10. bonus — Translate A ∩ B = ∅ ("A and B are disjoint") into a statement using ∀ and ¬, quantified over x.
    \(\forall x,\ \neg\big((x\in A)\wedge(x\in B)\big)\) — no x is in both.
  11. challenge — Using the membership-translation method, prove A ∩ (B ∪ C) = (A∩B) ∪ (A∩C) (distributivity) by expanding both sides into a logical statement about x and comparing.
    \(x\in A\cap(B\cup C) \iff (x\in A)\wedge\big((x\in B)\vee(x\in C)\big)\). Logical distributivity gives \(\iff \big((x\in A)\wedge(x\in B)\big)\vee\big((x\in A)\wedge(x\in C)\big) \iff x\in(A\cap B) \vee x \in (A \cap C) \iff x \in (A\cap B)\cup(A\cap C)\). Same elements both sides ⟹ equal sets.
