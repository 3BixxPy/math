Propositions & Logical Connectives

Every module so far has targeted a gap the diagnostic found — trig, logs, functions, all closer to zero than to fluent. This one is different: the diagnostic flagged a genuinely strong transferable skill here, boolean logic and digital-circuit design. Module 4 isn't teaching you to reason — you already can. It's teaching you the symbols mathematicians use for the reasoning you've been doing in gates and truth tables for years.

Why this matters

You already know this chapter. An AND gate is ∧. An OR gate is ∨. A NOT gate (inverter) is ¬. If you've ever drawn a truth table to check a circuit before wiring it, you've already done everything this chapter asks — the only thing new is that mathematicians write p ∧ q instead of drawing two wires into an AND gate, and call the wires' 0/1 values "false/true" instead of "low/high." Same structure, different notation. The payoff for learning the notation: it's how every proof, every set-theory statement, and every "for all / there exists" claim for the rest of this course (and every math course after it) gets written down.

Definition — Proposition

A proposition is a statement that has a definite truth value — it is either true or false, never both, never neither. "7 is prime" is a proposition (true). "2 + 2 = 5" is a proposition (false). "This pizza is good" is not a proposition — it's an opinion with no fixed truth value. Propositions are usually named with lowercase letters: p, q, r, exactly like you'd name input wires A, B, C on a circuit diagram.

Definition — Logical connectives (∧, ∨, ¬)

Connectives combine propositions into new ones, and each one is defined by nothing more than its truth table — exactly how you'd verify a gate.

Conjunction, p ∧ q ("p and q") — your AND gate. True only when both inputs are true.

FTF
FFF
\[ p \wedge q = T \iff (p = T) \text{ and } (q = T) \]

Negation, ¬p ("not p") — your inverter. Flips the value.

Rule — order of operations for connectives

¬ binds tightest, then ∧, then ∨ — exactly the order a circuit evaluates: inverters run first on individual wires, then AND gates combine, then OR gates combine those. So p ∧ ¬q means p ∧ (¬q), never ¬(p ∧ q); use parentheses whenever there's any doubt, same as you would in a schematic.

Worked example — full truth table for p ∧ (¬q)

Build the complete truth table for the compound proposition p ∧ (¬q).

Step 1 — list every combination of p and q

Two inputs, two values each → \(2^2=4\) rows, same as any 2-input circuit's full truth table: TT, TF, FT, FF.

Step 2 — compute ¬q for each row

¬q is just q flipped: T,F,T,F → F,T,F,T for the four rows above.

Step 3 — AND that with p, row by row

Row 1: p=T, ¬q=F → T∧F = F. Row 2: p=T, ¬q=T → T∧T = T. Row 3: p=F, ¬q=F → F∧F = F. Row 4: p=F, ¬q=T → F∧T = F.

Result
p q ¬q p ∧ (¬q)
TTFF
TFTT
FTFF
FFTF

Notice this is only true in exactly one row — the same "one-hot" pattern you'd recognize instantly from a circuit that's supposed to fire on a single specific input combination.

Worked example — evaluating a compound proposition

Let p = T and q = F. Evaluate ¬(p ∧ q) ∨ q.

Step 1 — innermost parentheses first: p ∧ q

\(p \wedge q = T \wedge F = F\)

Step 2 — negate that result

\(\neg(p \wedge q) = \neg F = T\)

Step 3 — OR with q

\(T \vee q = T \vee F = T\)

Result

¬(p ∧ q) ∨ q evaluates to True for p=T, q=F — work it left-to-right through the gate structure, same as tracing a signal through a schematic.

Common mistake

Reading ∨ as the everyday English "or." "Soup or salad" at a restaurant means pick exactly one — that's exclusive or (XOR), false when both are chosen. Logical ∨ is always inclusive — true when at least one side is true, including when both are. If you've built XOR gates before, you already know this distinction cold: ∨ in math is the OR gate, never the XOR gate, unless a problem says "exclusive or" explicitly.

Try it yourself

What is the truth value of T ∧ F?

Practice

  1. Evaluate: T ∨ F
    True
  2. Evaluate: ¬T
    False
  3. Evaluate: F ∧ F
    False
  4. Let p=F, q=T. Evaluate p ∨ ¬q.
    \(\neg q = F\), so \(F \vee F = \) False
  5. Let p=T, q=T. Evaluate ¬p ∧ q.
    \(\neg p = F\), so \(F \wedge T = \) False
  6. Build the full truth table for ¬p ∨ q (4 rows).
    TT→T, TF→F, FT→T, FF→T (only false when p=T and q=F)
  7. bonus — Let p=F, q=F, r=T. Evaluate (p ∨ q) ∧ r.
    \(p\vee q = F\), so \(F \wedge T = \) False
  8. bonus — Is "I'll have coffee or tea" (as usually meant) an inclusive or exclusive or, in everyday use? What about "you can have cake and ice cream"?
    "Coffee or tea" is usually exclusive in everyday speech (pick one). "Cake and ice cream" isn't an ∨ at all — it's a ∧ (both).
  9. bonus — Build the truth table for p ∧ (q ∨ ¬p). (Hint: it simplifies — compare it row by row to a simpler expression.)
    TT→T, TF→F, FT→F, FF→F — identical to the table for p ∧ q. (When p=F, ¬p=T makes the OR true, but the outer ∧ with p=F still forces F.)
  10. bonus — A 2-input circuit outputs HIGH only when both inputs are HIGH. Write this as a logical expression in p and q.
    \(p \wedge q\)
  11. challenge — How many rows does the full truth table for a compound proposition with 4 distinct propositional variables have? Justify it from the circuit picture (how many rows would a 4-input truth table have on a chip datasheet?).
    \(2^4 = 16\) rows — each of the 4 inputs independently takes 2 values, exactly like a 4-input gate's full truth table has 16 rows.
